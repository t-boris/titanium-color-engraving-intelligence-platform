# Первичная проверка возможностей лазера на титане

Это пять самостоятельных проектов LightBurn для JPT YDFLP-E-60-M7-M-R 60 W, серийный номер MC2BDJD71684, с линзой F-Theta 174 мм. Каждый файл помещается в поле не более 100 × 100 мм и уже содержит порядок слоёв и параметры. Во встроенных заметках зафиксированы лазер, линза и титан; точную марку/сплав и партию титана нужно связать с записью эксперимента.

## Обязательная чистка и метки

Во всех файлах слой C00 первым проходит всю область рисунка: Fill/Scan, 20%, 48 кГц, 2000 мм/с, Q-Pulse 200 нс, интервал 0,05 мм, один проход слоя и один общий проход, двунаправленно, cross-hatch включён. Перекрёстная штриховка даёт второй проход под прямым углом. Область чистки совпадает с внешними границами всей пластины.

Следом идёт C01 `Markers and labels` с настройками из присланного окна: Fill/Scan, 25%, 60 кГц, 150 мм/с, Q-Pulse 200 нс, интервал 0,01 мм, один проход слоя и один общий проход, двунаправленно выключено. Он наносит подписи и QR/ArUco-маркеры чёрным рецептом. Фактический оттенок зависит от поверхности и требует проверки на этом титане.

## Плейты

1. **[01 · Мощность × скорость](01_titanium_power_speed_envelope_100mm.lbrn2)** — 56 длинных штрихов LightBurn Line. Семь уровней мощности: 5, 10, 20, 30, 50, 75, 100%; восемь скоростей: 500, 1000, 1500, 2000, 3000, 5000, 7500, 10000 мм/с. Частота и импульс закреплены на F48 кГц и PW200 нс. Штрихи длиной 53 мм дают сканатору участок для разгона. По результату ищем порог видимого устойчивого следа и максимальную командную скорость с непрерывной линией. Это отклик титана на заданную мощность; фактические ватты проверяются измерителем мощности.

2. **[02 · Диапазон частоты](02_titanium_frequency_range_100mm.lbrn2)** — 18 длинных линий на частотах 1–4000 кГц. Мощность 20%, скорость 2000 мм/с, импульс 2 нс. Проверяется отклик по всему заявленному диапазону частоты повторения для короткого импульса. Частота меняет энергию импульса и вид следа, поэтому это карта частотного отклика, а не независимое измерение мощности.

3. **[03 · Импульсы и частота среза](03_titanium_pulse_cutoff_response_100mm.lbrn2)** — для каждой из 16 импульсных ступеней 2–500 нс нанесены по три линии на 0,8×, 1× и 1,2× частоты среза из паспорта устройства; отдельно есть контрольная линия CW/1 нс при 48 кГц. Постоянные параметры: 20%, 900 мм/с, один проход. Этот плейт проверяет, проявляется ли на титане ожидаемое изменение отклика возле частоты среза выбранной длительности импульса.

4. **[04 · Ширина следа и разрешение](04_titanium_line_resolution_100mm.lbrn2)** — десять групп по пять параллельных линий с шагом между центрами 20, 30, 40, 50, 60, 80, 100, 150, 200 и 300 мкм. Параметры линии: 20%, F48 кГц, 2000 мм/с, PW200 нс. Под микроскопом можно измерить ширину дорожки и минимальный шаг, при котором линии ещё отделяются. Ширина прожжённой дорожки зависит от фокуса, титана и порога окисления; это не прямое измерение оптического диаметра пятна. Для диаметра пятна нужен профилометр пучка или подтверждённый метод burn-threshold.

5. **[05 · Шаг заливки](05_titanium_hatch_interval_100mm.lbrn2)** — только пять небольших залитых образцов с интервалом 0,01 / 0,025 / 0,05 / 0,10 / 0,20 мм. Остальные параметры одинаковые: 20%, F48 кГц, 2000 мм/с, PW200 нс, один проход, без cross-hatch. Это вторичный тест плотности/перекрытия штрихов и нагрузки сканирования, а не попытка определить мощность или пределы импульса лазера.

## Как сравнивать снимки

Сначала сравнивай наличие и непрерывность следа. Для теста частоты среза сопоставляй три соседние линии одного Q-Pulse; для разрешения измеряй линию и просвет под микроскопом с масштабом. Чтобы фото давало измеримый размер, положи рядом линейку/калибровочную шкалу в той же плоскости и снимай перпендикулярно. Отмечай фактические лазер, линзу, сплав/марку, партию, состояние поверхности и фокус; без этих связей два снимка могут показать разный результат по причинам вне настроек лазера.

Все режимы Line записаны как LightBurn `Cut`, а не как заливочные прямоугольники. В наборах нет цветовой карты. Повторно создать файлы можно командой:

```bash
PYTHONPATH=src ~/.titanium-platform-app/bin/python tools/generate_laser_selfcheck.py
```
