## 1. Цель

Одна выгравированная пластина и одно фото дают заполненные параметры лазера в паспорте устройства.
В паспорт попадает только то, что фото действительно доказывает, и только после проверки качества снимка.
Всё остальное остаётся вопросом к оператору, а не угадывается.

Пластина должна:
1. выгравировать сведения о лазере: модель, серийный номер, линза, дата, идентификатор пластины;
2. проверить, при каких настройках метка на титане видна (лестница видимости маркера);
3. проверить масштаб: рамка известного размера на реальном поле;
4. дать оценку диаметра пятна по ряду тонких линий (отдельный макро-снимок);
5. после загрузки фото предложить значения для паспорта. Оператор применяет их кнопкой.

## 3. Принципы (не нарушать)

- Измеренное побеждает расчётное, введённое оператором побеждает всё остальное.
- Результат фото никогда не затирает подтверждённое значение молча. Показываем разницу, оператор нажимает «Применить».
- Если качество снимка не прошло проверку, значение не предлагается вообще, а причина объясняется.
- Каждая запись в паспорте ссылается на проверку: фото, пластина, дата, линза.
- Метод, который нельзя проверить по фото, в пластину не включаем (см. раздел 4).
- Новые решения сначала записываются в MarkView (REQ/DEC), статусы вручную не ставим.

## 4. Что можно и что нельзя узнать по фото

| Параметр | Можно? | Как и с какой оговоркой |
|---|---|---|
| Масштаб и размер поля | Да | Выгравированная рамка номинального размера против четырёх маркеров. Отклонение, %, и предложение поправить масштаб гальво. Само значение в EZCAD не меняем. |
| Метка видна при настройках X | Да | Лестница из слоёв с растущей мощностью/частотой. Контраст ΔL по каждой ступени. Порог видимости задаём по реальным фото. |
| Диаметр пятна | Только оценка | Нужен отдельный макро-снимок. Общее фото выпрямляется в `photo.py` до 20 пикс/мм (50 мкм на пиксель), реальное разрешение вашей камеры я не знаю. При таком масштабе линия 50–70 мкм занимает 1–1,4 пикселя, то есть меряется плохо. Результат помечаем «оценка», в расчёты по умолчанию не идёт. |
| M² | Косвенно | Только из измеренного пятна: M² = π·D·d/(4·λ·f). Накладывает ошибки пятна и фокуса, поэтому предлагаем как оценку, с диапазоном. |
| Реальная мощность | Нет | Фото её не меряет. Нужен измеритель мощности. Остаётся значением из протокола. |
| Длительность импульса | Нет | Косвенно через цвет/глубину, но это уже калибровка модели, а не проверка лазера. Не включаем. |
| Фокус (положение по Z) | Позже | Нужна серия при разных Z. Отдельная задача, не в первой версии. |

## 6. Этапы

### A. Спецификация в MarkView (сначала)

- [ ] REQ «Пластина самопроверки лазера»: состав пластины, слои, ограничения 255 слоёв LightBurn, размер не больше поля линзы.
- [ ] REQ «Анализ фото самопроверки»: что измеряется, какие проверки качества, что возвращается.
- [ ] REQ «Применение результатов к паспорту»: только по кнопке, с разницей, с историей.
- [ ] DEC: текст на пластине рисуется прямоугольниками из встроенного пиксельного шрифта (как QR). Так `export_lbrn2` не зависит от шрифтов LightBurn.
- [ ] DEC: пятно оценивается по макро-снимку, отдельно от общего; результат всегда «оценка».
- [ ] Q: порог видимости метки (ΔL), допустимая ошибка масштаба, минимальное разрешение макро-снимка.
- Критерий: у каждой задачи ниже есть REQ/DEC, проверка `markview_get_feature` показывает их.

### B. Генератор пластины и `.lbrn2`

Предлагаемый модуль: `selfcheck.py` (имя уточнить в DEC). Возвращает план в том же формате, что `plans`, чтобы работали выгрузка, маркеры и снимок линзы.

- [ ] Блок с текстом: модель, серийный номер, линза (f, поле), дата, идентификатор. Рисуется прямоугольниками.
- [ ] Лестница видимости: N ступеней, каждая своим слоем (мощность/частота растут), подписанные номера. В плане не больше 255 слоёв плюс слой маркеров с индексом 0 (`MAX_LAYERS` в `plans.py`).
- [ ] Рамка известного размера (масштаб). Размер выбирается по полю линзы, плита больше поля отклоняется с понятным сообщением (как сейчас).
- [ ] Блок для макро-снимка: небольшой кластер тонких линий с собственной шкалой 1 мм. Маркер ArUco 8 мм может не поместиться в макро-кадр (зависит от вашей камеры), поэтому у кластера своя мини-шкала.
- [ ] Четыре маркера ArUco и QR с идентификатором, как у обычных пластин.
- [ ] Все параметры слоёв берутся из подтверждённых данных лазера (мощность, частоты в диапазоне Min/Max PWM). Не подтверждённые значения не используются.
- [ ] **Риск R1:** как LightBurn заливает прямоугольник уже межстрочного интервала. Тест в `pytest` этого не проверит, нужно открыть файл в LightBurn. Запасной вариант: одиночные линии в режиме Line вместо заливки (потребует расширить писатель `.lbrn2`).
- Критерии: `.lbrn2` разбирается существующим `lightburn.parse_bytes`; число слоёв и размеры совпадают с планом; слишком большая или слишком плотная пластина отклоняется; файл у вас открывается в LightBurn и выглядит как задумано.
