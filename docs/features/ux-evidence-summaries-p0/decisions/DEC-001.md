## Context

Findings can offer several remedies with different consequences. Their existing order defines availability, not recommendation.

## Alternatives

1. A: Recommend checking the cause before corrective changes.
2. B: Promote the first available action in the existing order.

## Decision

Recommend remeasuring the photograph for an actionable measurement anomaly. When the next corrective step is ambiguous, recommend opening the supporting evidence.

## Reason

Checking the cause supports evidence-based decisions before excluding measurements or changing the calculation baseline.

## Consequences

Other available remedies remain accessible through disclosure; existing action eligibility and confirmation flows are preserved.
