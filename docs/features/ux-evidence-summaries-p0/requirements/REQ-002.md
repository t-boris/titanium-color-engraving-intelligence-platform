## Statement

Present findings as a decision queue with one recommended next action that prioritizes checking the cause, while retaining existing remedies and queue controls.

## Acceptance Criteria

- [x] Each finding row shows the problem, affected work or context, and one recommended next action.
- [x] For a measurement anomaly with remeasurement available, the recommended action is to remeasure the photograph. When the corrective choice is ambiguous, the recommended action opens supporting evidence.
- [x] Other available actions remain accessible through disclosure. Recommendation does not change existing eligibility restrictions, consequence previews, or confirmation flows; historical runs do not gain corrective actions.
- [x] Preserve attention and acknowledged states, hiding until substantive changes, notes, and pinning. New measurements return a finding to attention when its substance changes under the existing rules.
- [x] Calculation history, scheduling, and exclusions remain accessible through secondary disclosure. Photo findings follow the same queue principle.
- [ ] Verify the changed flow in the real browser and Electron interface, including investigating a discrepancy, keyboard and screen-reader access, enlarged text, narrow screens, and action failures. Compare task completion, time, and erroneous actions before and after; retain applicable n55–n58 domain guarantees.
