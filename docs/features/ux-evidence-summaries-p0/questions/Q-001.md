## Question

Как выбирать одно рекомендуемое действие, если для вывода доступны несколько способов исправления?

## Why it matters

В findings.py уже определены доступные действия и порядок кнопок, но правило рекомендации отсутствует. Например, аномалия допускает перемеривание, исключение измерения и расчёт с последней гравировки — с разными последствиями.

## Options

- **A**: Рекомендовать проверку причины: для аномалии — перемерить фото, при неоднозначности — открыть основания; остальные решения доступны в раскрытии.
- **B**: Выделять первое доступное действие в текущем порядке: для аномалии — «Убрать измерение», затем остальные варианты в раскрытии.

## Recommended

A — Проверка причины лучше соответствует цели достоверности; доступность действия ещё не означает, что оно рекомендовано.

## Answer

A. Рекомендовать проверку причины: для аномалии — перемерить фото, при неоднозначности — открыть основания; остальные решения доступны в раскрытии.
