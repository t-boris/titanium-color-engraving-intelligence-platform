## Statement

Основное действие «Скачать LightBurn» показывает готовность файла и объясняет блокировки.

## Acceptance Criteria

- [x] Перед скачиванием видны размер, время, число слоёв и причина ограничения.
- [x] Блокировка ведёт к конкретной области или отсутствующим данным; полный рецепт и предыдущие файлы доступны в раскрытии.
- [x] Не требуется обязательный промежуточный экран плана; сохранены проверки достижимости цветов, слоёв и очистки; файл не отправляется в лазер.
