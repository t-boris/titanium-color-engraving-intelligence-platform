## Statement

Сравнение относится к выбранной гравировке и её сохранённому прогнозу, отдельно от текущего пересчёта.

## Acceptance Criteria

- [x] Пользователь выбирает гравировку и сравнивает ожидание/фото в одинаковом масштабе с крупнейшими отличиями.
- [x] Новые измерения меняют текущий прогноз, но не переписывают обещание ранее выгравированного файла.
- [x] Оценки цвета и фотографии независимы; замена текущих цветов отменяется.
