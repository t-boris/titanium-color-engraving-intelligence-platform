## Statement

Работа и эксперимент показывают цепочку от подготовки до проверенного результата.

## Acceptance Criteria

- [ ] Видна цепочка «Подготовлено → Файл получен → Результат добавлен → Проверено» с действием текущего этапа.
- [ ] После принятия фото есть возврат к исходной работе с краткими изменениями прогноза.
- [ ] История файлов и связанная версия результата сохраняются при повторном экспорте и правке.
