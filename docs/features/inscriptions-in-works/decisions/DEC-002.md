## Context

Nothing in the platform reads fonts, lays out text or makes boolean operations on polygons (the vector work is a planar map of shared arcs; photo zones cut pictures by rasterising loops). Text in Hebrew is written right to left, kerning and ligatures need the font's OpenType tables, and the letters must be cut out of vector regions exactly.

## Alternatives

1. fontTools alone (kerning from simple tables only, no ligatures, no Hebrew or Arabic)
2. OpenCV raster masks instead of polygon booleans (the cut would follow pixels, not the letters)

## Decision

Three dependencies are added. fontTools (MIT) reads the catalogue: names, styles, the scripts a font covers, variable fonts' named instances. uharfbuzz (HarfBuzz, MIT) shapes every run of text (kerning, ligatures, marks, right-to-left scripts) and draws the glyph outlines, the variable axes of a chosen style applied. shapely 2 (GEOS, BSD) unions the letters, makes the gap and the backing (buffers) and cuts the letters out of the regions.

## Reason

Approved by the operator on 2026-10-23 («Да, все три»); all three install as wheels for Python 3.12 on this Mac. HarfBuzz is the reference shaper (browsers use it), so the outline in the file is the text as fonts mean it to be set.

## Consequences

pyproject.toml, the deploy's import check and README name the three libraries; the app environment installs them with the wheel.
