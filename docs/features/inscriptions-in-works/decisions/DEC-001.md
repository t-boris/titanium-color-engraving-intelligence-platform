## Context

The operator needs "a very rich set of fonts". The Mac has about 350 visible font families (/System/Library/Fonts, Supplemental, /Library/Fonts, ~/Library/Fonts). Google Fonts has 1950 families (2.5 GB in all) under the OFL and similar open licences, 294 with Cyrillic and 62 with Hebrew, with a category each (serif, sans serif, display, handwriting, monospace).

## Alternatives

1. Only the Mac's fonts and the operator's files (no internet; licences of Apple fonts unclear for sale)
2. About 300 Google families bundled into the wheel (+300 MB, updated only by a release)

## Decision

The font catalogue lists three sources. (1) The Mac's installed fonts: read in place, never copied. (2) The operator's own files (TTF, OTF, TTC): added on the screen and kept in the data folder (fonts/own). (3) Google Fonts: every family is listed from Google's public metadata, and a family is downloaded into the data folder (fonts/google) the first time it is shown or chosen, or in bulk by script or category on request. The catalogue is cached by file stamps, so only new or changed files are read again. A face is known by an id derived from its source, path and index; an inscription also keeps the family and style names, so a font that moved can be found again by name.

## Reason

Operator's choice of 2026-10-23 («Mac + свои + Google»). Apple's fonts are available at once but are not always licensed for commercial engraving, while Google's are; downloading on demand keeps the app small and the 2.5 GB collection out of the wheel.

## Consequences

The first listing reads every font file once (seconds); a Google family needs the internet the first time; a work whose font is gone says so and its file is refused until another font is chosen.
