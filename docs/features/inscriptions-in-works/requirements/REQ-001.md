## Statement

The system shall offer every font of the Mac, of the operator's own files and of Google Fonts in one catalogue, searchable and filtered by script, kind and source, showing the operator's own text in each font as the outline that will be engraved.

## Acceptance Criteria

- [x] The catalogue lists the Mac's visible font families (hidden system fonts and fonts without outlines left out) with their styles, and the operator's own font files added on the screen.
- [ ] Every Google Fonts family is listed with its category; a family not yet downloaded is downloaded when it is shown or chosen; a bulk download by script or category runs in the background with its progress shown.
- [ ] Search by name; filters by script (Latin, Cyrillic, Hebrew, Arabic, Greek and others the fonts cover), by kind (serif, sans serif, handwriting, display, monospace) and by source; favourites stay marked.
- [ ] Each font in the list shows the inscription's text (or a sample while it is empty) drawn from the same outline the file gets; a font lacking a letter of the text says so.
- [x] A second listing reads only new or changed font files (cached by file stamps).
