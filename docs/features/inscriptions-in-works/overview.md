# Inscriptions in works

## Idea

The laser workshop gets inscriptions: the operator types a text, chooses a font from a very rich set while seeing the text written in each font, sizes, stretches, rotates and bends it, lays it on an arc, around a circle or along any path, and picks the titanium colour it is engraved in from the measured colours. The inscription is placed into the picture of a work: in a photo engraving the letters (with a gap) are cut out of the picture and engraved as a fill of their colour; in a vector work the letters are cut into the vector regions, which are trimmed around them. Scope: vector works of a photograph and photo engraving works; the preview, the time and the LightBurn file follow the inscriptions; every change can be undone.
