## Context

After the release of the business-card editor (0.41.0) the operator found its Engraving settings empty and unclear: blank number boxes, with no hint of what to enter, and fewer fields than the engravings the workshop already did. Stated by the operator on 2026-11-07.

## Alternatives

1. Keep the blank form and add hints next to the boxes.
2. Ship fixed default numbers for every device (rejected: invented values).

## Decision

A settings set of a card is never shown empty. It shows either settings proposed or chosen from what the workshop knows, or the plain statement that they are unknown for the card's device, lens and material, with what is missing.

## Reason

An empty form tells the operator nothing and invites guessing numbers. The workshop's own rule is that parameters are never invented (main feature REQ-015 and REQ-021), so the honest alternatives are a proposal from known results or an explicit \"unknown\".

## Consequences

The card editor needs the setup (device, lens, material) of the card to look values up, and every settings set carries an origin. Cards saved by 0.41.0 with empty sets show the new state when opened.
