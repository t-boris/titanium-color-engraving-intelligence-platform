## Context

Q-003 (copy or live link) was not put to the operator in the dialog of 2026-11-07; the assistant said it would use the copy and the operator did not object. The question stays open for the person to answer.

## Alternatives

1. A live link to the source so the set follows its updates.

## Decision

Choosing a source copies its values into the set and stores the source (kind, label, laser, lens, material, evidence, date) as a note. The set never follows later changes of the source by itself; the editor offers \"choose again\" when the source has newer results.

## Reason

A saved card and the file exported from it must not change under the operator when a result is re-measured.

## Consequences

The set carries a self-contained origin record. Proposed only until the person answers Q-003.
