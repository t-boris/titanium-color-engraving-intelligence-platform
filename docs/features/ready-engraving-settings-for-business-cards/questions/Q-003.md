## Question

When the operator chooses a source, is the set a copy of its values, or a live link to the source?

## Why it matters

A card file must not change under the operator when a photo result or a colour recipe is re-measured later.

## Options

- **A**: Copy the values into the set and keep the source as a note; offer "choose again" when the source has newer results.
- **B**: Link the set to the source so that it follows the source's updates.

## Recommended

A: copy with a note of the source. The saved card and its exported file stay exactly as the operator last saw them.
