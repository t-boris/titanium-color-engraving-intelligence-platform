## Question

Should a new card's first settings set start with the best known proposal, or with a prompt to choose?

## Why it matters

The operator wants settings never left empty. A proposal saves a step, but the operator must still see it is a proposal and not a decision.

## Options

- **A**: Pre-fill the first set with the best known proposal for the card's setup, marked "proposed", and require the operator to confirm it before export.
- **B**: Do not pre-fill; show the set as "choose settings" with the nearest choices at hand, and "unknown" when there are none.

## Recommended

A: pre-fill with a marked proposal that must be confirmed before export; when nothing is known, say \"unknown\".
