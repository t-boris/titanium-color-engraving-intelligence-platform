## Statement

The system shall let the operator engrave a picture of a card as a raster photo instead of traced vector shapes, using the photo engraving setting (dither mode, DPI, dot width, minimum power and the numeric parameters) chosen for the card's own laser, lens and material.

## Acceptance Criteria

- [x] A picture has a choice between traced shapes (as today, the default) and raster photo.
- [x] A raster picture is engraved with a photo setting chosen from the photo choices of the card's setup; its raster fields come from that choice.
- [x] The preview shows the dithered result at the card's physical size.
- [x] The exported side holds the picture as an image layer with the dither mode, DPI and dot width of the chosen setting, checked by reading the file back with the project's LightBurn reader.
- [x] A raster picture without a chosen photo setting is reported as not ready and names the choice to make.
- [x] Vector elements and pictures engraved as traced shapes are not affected by the raster fields.
