## Statement

The system shall carry into the LightBurn layer of a card the fields of the chosen source setting that a layer supports, so that the card is engraved the way the source engraving was.

## Acceptance Criteria

- [ ] A set records the fields of its source beyond the six it has today, as far as the open question on the fields decides (for example global passes, bidirectional scan, cross hatch, scan angle).
- [ ] The exported layer of a set equals its source setting in those fields, checked by reading the file back with the project's LightBurn reader.
- [ ] The fields of a source that a card cannot use are listed with the choice, so the operator knows they are dropped.
