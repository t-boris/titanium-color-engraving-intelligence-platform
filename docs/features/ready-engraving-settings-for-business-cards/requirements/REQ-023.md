## Statement

The system shall carry into the LightBurn layer of a card the fields of the chosen source setting that a layer supports, so that the card is engraved the way the source engraving was.

## Acceptance Criteria

- [ ] A set records the fields of its source beyond the six it has today: global passes, bidirectional scan, cross hatch, scan angle, minimum power, dither mode, DPI and dot width.
- [ ] The exported layer of a set equals its source setting in the fields that layer supports, checked by reading the file back with the project's LightBurn reader.
- [ ] The fields of a source that do not apply to an element (raster fields for a vector element) are listed with the choice, so the operator knows they are not used.
