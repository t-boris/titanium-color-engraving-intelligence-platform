## Statement

When the workshop knows nothing for the card's device, lens and material, the system shall say that the settings are unknown, name what would make them known, and still offer the nearest known choices marked as such; it shall never fill invented numbers.

## Acceptance Criteria

- [ ] With no device, lens or material chosen, the editor says which one is missing and offers nothing as measured.
- [ ] With a device but no measurement for what the element needs, the editor says "unknown" and lists the nearest known choices (another lens, material or titanium), each labelled with how it differs.
- [ ] No value appears in a set that was not read from a source or typed by the operator.
- [ ] Export stays blocked for a set whose required values are unknown, and the message names the choice to make.
