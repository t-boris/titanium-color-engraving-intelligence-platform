## Statement

When the workshop has no measurement for the card's own laser, lens and material, the system shall say that the settings are unknown and name what has to be measured; it shall not offer settings measured on any other laser, lens or material, and it shall never fill invented numbers.

## Acceptance Criteria

- [x] With the card's laser, lens or material missing, the editor says which one is missing and offers nothing as measured.
- [x] With a complete setup but no measurement for what the element needs, the editor says "unknown" and names what to measure (for example a colour recipe or a photo kind); it lists no choices from other setups.
- [x] No value appears in a set that was not read from a source or typed by the operator.
- [x] Export stays blocked for a set whose required values are unknown or not confirmed, and the message names the choice to make.
