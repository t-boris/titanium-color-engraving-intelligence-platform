## Statement

The system shall never show an engraving settings set of a business card as empty: every set shall show either known settings that were proposed or chosen, or the plain statement that the settings are unknown for the card's device, lens and material.

## Acceptance Criteria

- [x] A new card work opens with its first settings set showing a proposal made from known settings, or the statement "unknown" with the reason; no required value is shown as a bare dash.
- [x] A settings set added later behaves the same way.
- [x] "Unknown" always names what is missing: no device, lens or material chosen, or nothing measured for the chosen setup.
- [x] The per-side readiness review names the choice still to make, not the missing numbers.
- [x] A card work saved by 0.41.0 with empty sets shows the same choice or unknown state when opened, and no saved data is lost.
