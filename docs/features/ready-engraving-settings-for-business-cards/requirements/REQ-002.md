## Statement

The system shall offer, for a settings set, a choice of ready settings from the sources the workshop already holds, grouped by source, each with its origin and evidence, and shall fill the set from the chosen entry.

## Acceptance Criteria

- [ ] The choices are grouped by source (as decided in the open question on sources), shown compactly with a count per group and a search, never as one long list.
- [ ] Each choice shows where it comes from: source, device, lens, material and the evidence status of the result.
- [ ] Choosing fills power, speed, frequency, line interval, passes and pulse width as far as the source has them, and the set remembers its source.
- [ ] A field the source does not have stays visibly unknown; no value is guessed.
- [ ] Choosing another entry replaces the set's values completely, so a set is never half filled from two sources.
