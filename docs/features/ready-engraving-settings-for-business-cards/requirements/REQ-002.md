## Statement

The system shall offer, for a settings set, a choice of ready settings from the measurements the workshop holds for the card's own laser, lens and material, starting with the type of engraving (colour, photo, lines and text), grouped by source, each with its origin and evidence, and shall fill the set from the chosen entry.

## Acceptance Criteria

- [x] The choice starts with the type of engraving: colour, photo, lines and text, and the types the workshop has no data for (for example deep engraving), which are listed as unknown.
- [x] The choices of a type are grouped by source, shown compactly with a count per group and a search, never as one long list.
- [ ] Each choice shows where it comes from: source, laser, lens, material and the evidence status of the result.
- [x] Only measured and validated results are offered; the film-model prediction and the grey-scale power span are not offered in this version (Q-001).
- [x] Choosing fills power, speed, frequency, line interval, passes and pulse width as far as the source has them, and the set remembers its source.
- [x] A field the source does not have stays visibly unknown; no value is guessed.
- [x] Choosing another entry replaces the set's values completely, so a set is never half filled from two sources.
