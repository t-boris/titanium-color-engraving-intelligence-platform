## Statement

The system shall offer typing settings by hand (Custom) only after the choices, as the last resort, and shall mark such a set as entered by the operator.

## Acceptance Criteria

- [x] "Custom" is the last entry of the choice and is described as the last resort; the choices are shown before it.
- [x] A set typed by hand shows "Custom" as its origin.
- [x] Editing a number of a set that came from a source turns it into Custom and keeps the original source in a note, so the operator can go back to it.
- [x] The existing validation of the numbers (positive values, power up to 100, line interval up to 10, passes 1 to 100) still applies.
