## Statement

Validate the proposed primary sections—«Работы», «Эксперименты», «Цвета и режимы», «Оборудование» and «Мастерская»—on representative operator tasks before adoption. Adopt only supported groupings while preserving access to every existing function, workflow and address.

## Acceptance Criteria

- [ ] Test a prototype with operators using representative tasks covering all five proposed sections, including finding capture settings, repeatability assessment, materials and photo markers.
- [ ] Compare the current interface and prototype on the same tasks, recording unaided completion, navigation time, backtracking and errors. Record observed results separately from assumptions; establish numerical targets after the baseline.
- [ ] Document which labels and placements the observations support. Revise and retest unsupported groupings before adopting them; selecting the prototype approach does not approve the proposed structure.
- [ ] Provide a discoverable path for every existing navigation entry and settings tab. Test planning, findings and AI research under Experiments; vector and photo engraving under Works; network and laboratories under Workshop, preserving existing workflows and distinct editors.
- [ ] Existing addresses retain object identifiers, arguments and query parameters and open the same content. Direct links, browser back/forward and active-section indication work within the adopted grouping.
- [ ] Verify affected navigation in the real browser and Electron interface using keyboard, screen reader, enlarged text, narrow and low windows. Preserve applicable domain guarantees from research nodes n55–n58, including preview/export consistency, separate quality assessments and file/measurement history.
