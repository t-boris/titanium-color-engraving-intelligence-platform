## Statement

Основная навигация группирует функции в «Работы», «Эксперименты», «Цвета и режимы», «Оборудование», «Мастерская» после проверки понятности структуры.

## Acceptance Criteria

- [ ] Старые адреса, id объектов, аргументы и query открывают тот же документ; назад/вперёд и активный раздел работают.
- [ ] Планировщик, выводы и AI доступны из экспериментов; сеть и лаборатории — из мастерской.
- [ ] Съёмка доступна из оборудования, оценка повторов — из цветов и режимов, материалы и метки — из ресурсов мастерской; для каждого прежнего пункта задан путь.
