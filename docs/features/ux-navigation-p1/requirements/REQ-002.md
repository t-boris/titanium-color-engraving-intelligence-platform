## Statement

Пользователь узнаёт текущий раздел и может вернуться из документа в каталог.

## Acceptance Criteria

- [ ] На широком окне можно закрепить меню с названиями; компактный режим сохраняется как выбор.
- [ ] В редакторе видны раздел, название работы и постоянный возврат к каталогу.
- [ ] Статичная роль «Исследователь / мастер» убрана; полезные статусы и версия сохранены.
