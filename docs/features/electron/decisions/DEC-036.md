## Context

The first distributed desktop beta needs an explicit support matrix.

## Alternatives

1. Include Intel Macs in the first distributed beta.
2. Include Linux in the first distributed beta.

## Decision

Target macOS on Apple Silicon and Windows x64 for the first distributed beta. Select minimum supported OS versions after D0 validation on available clean machines. Intel Macs and Linux are outside this beta's support matrix.

## Reason

Concentrate initial packaging and release validation on two target platforms.

## Consequences

Minimum supported OS versions remain unresolved until D0 clean-machine validation.
