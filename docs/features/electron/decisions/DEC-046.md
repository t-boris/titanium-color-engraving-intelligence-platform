## Context

DEC-022 requires the change of the main feature's REQ-043/DEC-020 contract (one Python process started from a console entry point) to be agreed before implementation.

## Alternatives

1. Desktop only: the console mode becomes a developer tool and the installed application replaces the running service

## Decision

Keep both modes. The Python package and its `titanium-platform` console command remain and keep working as today (including the operator's service on port 8765). The desktop application starts the same package as a hidden child process bound to loopback with a per-launch session secret. The browser mode additionally checks Host and Origin so that an unrelated web page cannot change the workshop.

## Reason

The owner chose "both modes" on 2026-10-24.

## Consequences

The main feature records the same change against REQ-043/DEC-020. Desktop-only protections (session cookie) are enforced only when the core runs under the desktop shell; LAN access is a separate, explicitly enabled server (DEC-033).
