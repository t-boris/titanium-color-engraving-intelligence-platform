## Context

DEC-032 says the nominal colour of cleaned titanium is computed from the measured witnesses and not published as a number. Colours relative to clean titanium (the camera-relative basis) depend on it, so a recipient must get the same nominal colour the author's workshop had, with nothing extra in the file.

## Alternatives

1. Publish the nominal colour as a number: DEC-032 refuses it, and it would go stale when the algorithm changes.
2. Use the recipient's own nominal colour for the release: the release's relative colours would shift by the difference of two workshops' cleaning.

## Decision

A release carries the cleaning witnesses as measurements with the role cleaning_witness (stated by the operator, or the first measurement of the cleaning layer found from the photograph's file), never a nominal colour. The recipient computes the nominal clean titanium from the release's own witnesses with the same code as for its own measurements, inside the release's snapshot; the recipient's own witnesses never enter it, and the release's witnesses never enter the recipient's own nominal colour.

## Reason

The same witnesses and the same code give the same nominal colour, so the parity holds and the sources stay separate as REQ-085 demands.
