## Context

Пользователь явно выбрал Electron и запуск на macOS и Windows; переписывание вычислительного ядра не запрашивалось.

## Alternatives

1. Обязательный запуск Python-сервера из терминала.
2. Переписать приложение на JavaScript или нативные UI-фреймворки.
3. Tauri с тем же Python-sidecar.

## Decision

Разрабатывать настольную оболочку Electron вокруг существующего интерфейса и управляемого локального Python-backend. Целевые семейства ОС — macOS и Windows; конкретные версии и архитектуры уточняются отдельным решением.

## Reason

Позволяет переиспользовать UI и научные библиотеки и убрать установку Python из пользовательского пути.

## Consequences

Уточняет прежний контракт одного Python-процесса из REQ-043/DEC-020 основной фичи; согласовать изменение формулировки до реализации. Нужны контроль child-процесса, совместимость версий и упаковка нативных зависимостей.
