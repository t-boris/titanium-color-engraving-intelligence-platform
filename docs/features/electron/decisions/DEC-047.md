## Context

DEC-033 leaves the LAN transport and pairing model to be specified before the public beta; REQ-082 requires pairing over protected transport and persistent, revocable devices (Q-007 B).

## Alternatives

1. A self-signed certificate only: the tablet accepts the browser warning (Safari may ask again after a restart)

## Decision

When LAN access is enabled, the workshop creates its own certificate authority and an HTTPS certificate for its LAN addresses. The tablet installs the authority once as a profile, or accepts the browser warning after comparing the fingerprint shown on the computer. It then enters a 6-digit pairing code shown on the computer and receives a long-lived device token in a Secure HttpOnly cookie. The owner sees the device list and can revoke a device.

## Reason

The owner chose the workshop certificate authority on 2026-10-24.

## Consequences

The authority's private key stays in the workshop folder and is never exported in releases, backups shared as labs, or diagnostics. Device tokens are stored as hashes; revocation ends access on the next request. The LAN server never accepts the desktop session secret.
