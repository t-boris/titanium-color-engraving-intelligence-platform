## Context

REQ-080 and DEC-039 distribute the public beta only with owner-controlled platform signing. This Mac holds «Developer ID Application: Boris Tsekinovsky (3M68DG8S7N)» but no notarization credentials; there is no Windows code-signing certificate.

## Alternatives

1. Azure Trusted Signing for Windows on the owner's account
2. Notarize macOS with a notarytool profile or an app-specific password

## Decision

Sign macOS builds with the owner's Developer ID certificate without notarization, and build Windows x64 unsigned. These builds are an internal beta; the public-beta criterion of REQ-080 (verified installers and updates with platform signing) stays open until notarization credentials and a Windows signing service exist.

## Reason

The owner chose "unsigned for now" for Windows and "no notarization for now" for macOS on 2026-10-24.

## Consequences

GitHub pre-releases are labelled as an internal beta. macOS shows a Gatekeeper warning on first launch; Windows shows SmartScreen. Signing keys stay outside the repository; the build reads the identity from the keychain.
