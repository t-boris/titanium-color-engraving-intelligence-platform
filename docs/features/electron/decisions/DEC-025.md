## Context

Текущие colormap/palette/prediction_store читают связанные pair и локальные файлы. Создание фиктивных фотографий ради импорта нарушит происхождение и статистику.

## Alternatives

1. Вставлять внешние измерения в собственную observation с фиктивными pair.
2. Поддерживать вторую копию алгоритмов для внешних данных.
3. Объединять все подключённые наборы в одну палитру автоматически.

## Decision

Ввести EvidenceSource с локальным и опубликованным адаптерами. Внешние снимки хранятся отдельно, доступны только для чтения и нормализуются в общий вычислительный контракт. Работа выбирает один источник и его совместимую установку/материал.

## Reason

Сохраняет существующее ядро и предотвращает смешивание оборудования, измерительных основ и статистики повторов.

## Consequences

Служебные признаки слоёв и способ калибровки готовятся при экспорте. Прогноз по внешнему источнику не читает файлы автора. Локальные сценарии проверяются регрессией, без обязательного массового переписывания Store.
