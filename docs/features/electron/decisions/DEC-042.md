## Context

DEC-037 (Q-002 B) requires authors to choose usage terms from a small approved list but leaves the list undefined (implementation plan I-2). Re-publishing imported data is already excluded in v1 by Q-006.

## Alternatives

1. Only CC BY 4.0 and CC BY-NC 4.0
2. A custom list written by the owner

## Decision

The approved list has three terms, each referenced in a release by a stable id and version: (1) `CC-BY-4.0` — commercial use, modification and redistribution with attribution; (2) `CC-BY-NC-4.0` — the same without commercial use; (3) `tce-own-engravings-1` «Только для своих гравировок» — the recipient may use the data to engrave and sell engraved products, but may not pass the file or its data on. Releases reference a term by id and version; the card shows its name and summary.

## Reason

The owner chose the three-term list on 2026-10-24 when asked during implementation.

## Consequences

The export preview requires choosing one term; the import and the lab card show it. Releases whose term forbids redistribution cannot be re-exported (Q-006 already forbids re-publishing in v1). Unknown term ids are shown as unknown and never treated as permissive.
