## Context

Cloud ownership and private reader access require authentication; local work remains account-free.

## Alternatives

1. Build and maintain custom authentication and account recovery.

## Decision

Use a managed authentication provider for cloud sign-in and account recovery.

## Reason

The owner selected managed authentication.

## Consequences

Provider selection remains an implementation task requiring validation of desktop sign-in and recovery.
