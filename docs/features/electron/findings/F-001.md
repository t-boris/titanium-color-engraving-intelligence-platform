## Finding

DEC-038 explicitly includes public and invitation-only private laboratories in the first online beta, with reader authentication and server-side authorization. REQ-084 and REQ-086 instead defer private laboratories and restrict account requirements to authors; DEC-027 and DEC-028 also retain the superseded public-only scope. Implementing those requirements would omit an expressly selected beta capability. Align the requirements and cloud API description with DEC-038, preserving anonymous access for public releases and authenticated, invitation-authorized access for private releases.

> Private laboratories and participant contributions are deferred to later stages after access rights are decided; the first online beta does not offer either capability.

## Resolution

Включить публичные и закрытые лаборатории в первую онлайн-бету согласно уже принятому решению. — see DEC-041.
