## Statement

The system shall publish immutable, complete laboratory releases atomically and support safe retries and concurrent publication without requiring the author's computer to remain online.

## Acceptance Criteria

- [x] Only the owner's confirmed numerical projection is uploaded. The server validates ownership, schema, resource limits and the complete content hash before making a release available to its authorized audience.
- [x] Incomplete uploads remain invisible to readers. Upload requests comply with limits verified against the deployed service and support the validated large-library envelope.
- [x] Retrying an interrupted publication with the same idempotency key returns the same result without creating a duplicate release.
- [x] Finalization checks the expected previous release. Concurrent publishers receive consistent sequential versions or an explicit conflict, without overwriting a release.
- [x] After successful publication, another authorized client can retrieve the complete release while the author's computer is turned off.
