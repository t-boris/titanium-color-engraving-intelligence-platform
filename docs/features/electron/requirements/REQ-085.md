## Statement

The system shall use explicitly selected external palettes and tonal profiles locally, preserve reproducible work and support separate validation experiments on the recipient's equipment.

## Acceptance Criteria

- [x] Users explicitly select own measurements or a specific external laboratory release together with physical setup, lens and material. The active source remains visible; missing or incompatible conditions are shown before calculation. Sources are never silently substituted or combined.
- [x] External vector palettes expose measured Lab/sRGB, complete recipes, measurement basis, independent engraving count, available variability and quality concerns. Existing manual and supported automatic selection modes work without the author's files.
- [x] Questionable, withdrawn and unsuitable records follow visible eligibility rules. Line recipes are not presented as measured area-fill colors; existing LightBurn layer-count and cleaning-order constraints remain enforced.
- [x] Supported photo prediction processes the recipient's image locally using numerical profiles selected by mode, physical setup, lens, material and all essential settings. Import does not make weakly supported or fill-overlaid profiles eligible.
- [x] Prediction retains current limits on extrapolation, identifies unpredicted pixels and rejects unsupported modes. The interface shows source release and measurement basis and does not promise physical equivalence on another laser.
- [x] Saved work retains exact laboratory and release identities, content hash, selected recipes, algorithm version and the data needed to reproduce its confirmed result. Subscription removal, catalogue removal and newer releases do not alter that result.
- [x] When the required algorithm is incompatible, the confirmed result is preserved and recalculation limitations are explained without silent recomputation.
- [x] A foreign recipe can start a separate own transfer experiment linked to its source release and observation. Own equipment limits are checked before export; incompatible settings cause an explicit refusal rather than bypassing constraints.
- [x] Transfer measurements retain actual own equipment and conditions, can be compared with the source using Lab/ΔE, and neither modify the author's observation nor increase its independent repeat count.
- [x] Palette use and prediction send neither recipient images nor local project and recipe-usage information to the cloud or laboratory author.
