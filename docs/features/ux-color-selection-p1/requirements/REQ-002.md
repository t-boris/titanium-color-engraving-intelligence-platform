## Statement

Кандидаты показывают близость, время, стабильность и применимость к выбранному оборудованию.

## Acceptance Criteria

- [ ] Рецепты можно сравнить по образцу и отсортировать по близости, времени и стабильности.

- [ ] Непригодные, отозванные или несовместимые измерения сохраняют предупреждения и правила выбора.
