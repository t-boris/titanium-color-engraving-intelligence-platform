## Statement

Целевой цвет можно выбрать визуально, взять из изображения или задать точно.

## Acceptance Criteria

- [ ] Пипетка показывает взятый образец и соответствующие подходящие рецепты.
- [ ] Lab остаётся точным дополнительным вводом; исходный образец не выдаётся за измеренный цвет титана.
- [ ] Одинаковые элементы выбора доступны в карте, кисти, фототочках и надписях.
