## Statement

The system shall show every list that can grow past one screen as compact one-line rows with details opened on demand, a sort choice, filters with counts, an optional search and paging, through one shared component.

## Acceptance Criteria

- [x] `App.list` (ui/list.js) renders one line per item; clicking a row opens its details under the row, one at a time, rendered only when opened
- [x] It shows at most one page (20 by default) and «Показать ещё N»; a counter says «показано N из M»
- [x] Filter chips show the number of items each would show; a sort select reorders the items; an optional search narrows them
- [x] The chosen sort, filters and page survive a re-render of the screen
- [x] Per-row actions run without opening the details
- [x] Node tests cover sorting, filter counts, search, paging and opening details
