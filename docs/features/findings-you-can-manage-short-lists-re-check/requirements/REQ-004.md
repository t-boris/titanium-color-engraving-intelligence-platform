## Statement

The system shall re-measure every accepted photograph with today's measurement in a background job started from «Выводы», after a full workshop backup, recalculate the conclusions once at the end and report what changed.

## Acceptance Criteria

- [x] A confirmation says how many photographs, the rough time, the backup folder and the space needed
- [x] A full workshop backup (database and files) is made first; if it fails, nothing is re-measured
- [x] Every accepted photograph is re-measured; the old measurement stays when the new one is not whole, with the reason
- [x] Progress shows «k из N» and the photograph being measured; «Остановить» stops between photographs
- [x] The analysis runs once at the end with the trigger «после перепроверки всех работ», and the works' reviews are refreshed
- [x] The report lists per photograph replaced, kept or failed with the largest colour change, and the findings that appeared, disappeared or changed, with links
- [x] Only one re-check runs at a time; while it runs, accepting, re-measuring and deleting a photograph are refused
- [x] The last report can be opened again after a restart
