## Statement

The system shall show no screen with a list longer than one page by default: every list that can exceed about twenty items uses the compact list.

## Acceptance Criteria

- [x] Colour model of a laser and lens: search, filters (stage, questioned, task), sort, pages of 20
- [x] Experiment «Результат» and analysis «Измеренные элементы»: one row per layer, worst first, details on click, paged
- [x] Workshop recovery copies: newest first, pages of 10
- [x] Experiments list and the laser's experiments: search, filters, sort and paging (the laser page gets the filters)
- [x] Plan layers, vector work colours/layers/variants, grey-scale cards and RAW «Все слои» use the compact list
- [x] Ingest review layers, vector job regions and history, designer parameter sets and lab lists use it before they grow
- [x] Colour-map search results keep their sources folded
- [x] Checked on a copy of the live workshop: no screen shows more than one page of rows by default
