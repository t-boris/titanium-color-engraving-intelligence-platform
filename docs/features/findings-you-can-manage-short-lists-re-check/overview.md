# Findings you can manage, short lists, re-check of all works

## Idea

The «Выводы» screen is one endless list of full cards (about 100 findings, then the photo-engraving cards below); the operator cannot hide, mark, annotate, sort or even see them, and nobody scrolls to the end. Long lists elsewhere (colour model 669 rows, matrix layers 100, recovery copies 70, experiments 25) have the same problem. And after the measurement changed there is no way to re-check every existing work and draw conclusions from it. Scope: one compact list pattern for the whole app, operator marks on findings that survive recalculation (hide until it changes, «учтено», note, pin), and a background «Перепроверить все работы» that backs up, re-measures every accepted photo, recalculates once and reports what changed.
