## Statement

Документ явно показывает ожидание, расчёт, сохранение, сохранённость или ошибку.

## Acceptance Criteria

- [ ] Ошибка остаётся рядом с объектом до исправления/закрытия; успех может быть кратким уведомлением.
- [ ] Неуспешный запрос не теряет локальный ввод; доступны повтор и отличие от подтверждённого состояния.
- [ ] Поздний ответ не помечает новое изменение сохранённым и не отменяет его.
