## Statement

The system shall list every exclusion the operator made in one short list on «Выводы», each with «Вернуть».

## Acceptance Criteria

- [x] «Выводы» shows «Убрано оператором N» when N > 0
- [x] It opens a compact list (one line each: what — photo and layer or recipe, when, note; details on click; paging)
- [x] «Вернуть» on a line undoes that exclusion and recalculates
