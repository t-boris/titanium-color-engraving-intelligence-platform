## Statement

The system shall let the operator re-measure the photograph an anomaly stands on from the finding itself, and show what changed.

## Acceptance Criteria

- [x] An anomaly finding offers «Перемерить фото»; it runs the existing re-measure of that photograph with a busy state
- [x] The result shows, per layer, the colour before and after, or why the old measurement was kept
- [x] The findings are recalculated and the list shows the new run
