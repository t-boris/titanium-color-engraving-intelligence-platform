## Context

Equipment setup and a starter test can interrupt work creation while engraving and photography happen outside the application.

## Alternatives

1. Preserve interrupted creation only during the current application session.
2. Allow interrupted creation to resume after closing and restarting the application.

## Decision

Allow work creation interrupted by setup or a starter test to resume after the application is closed and restarted.

## Reason

The user selected cross-session continuation without repeated input.

## Consequences

Unfinished input must persist across application restarts and remain distinguishable from a completed work or explicitly discarded task.
