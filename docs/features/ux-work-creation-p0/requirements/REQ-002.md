## Statement

Allow missing laser, lens, material or photography setup and a starter test to be completed while preserving the original creation task, with continuation available after closing and restarting the application.

## Acceptance Criteria

- [x] After equipment or photography setup, the user can return to the original creation task with its image, name, physical size, selected result and other entered fields preserved.
- [x] Closing and restarting the application during setup or a starter test allows the user to resume the same unfinished task without selecting the image or entering its parameters again.
- [x] When measurements are absent, offer a concrete starter test and explain which result becomes available after its measurements are accepted.
- [x] Cancelling setup preserves the original task input and does not leave a partially created work.
- [x] Closing the application does not count as explicitly discarding the unfinished task; a completed or explicitly discarded task is not offered as unfinished.
- [ ] Verify continuation through setup, the starter test and application restart in the actual interface, including keyboard access and focus when returning to the task.
