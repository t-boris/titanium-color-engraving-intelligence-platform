## Statement

The system shall export an EngravingPlan to LightBurn by quantizing the plan into N bands, each band becoming one LightBurn layer with its own fixed power, frequency and speed taken from the calibrated model. The same export path serves Discrete Color Engraving (one layer per chosen titanium color) and Continuous Photo Engraving (N bands along the transfer function). N is a parameter of the plan; the plan records, per band, the parameter set and the predicted color with its confidence, expected error and stability. The LightBurn per-layer capability assumption is an external fact that shall be verified against the user's LightBurn version.

## Acceptance Criteria

- [ ] Exporting a continuous plan with N=32 produces a LightBurn file with 32 layers, each carrying its own power, frequency and speed
- [ ] Exporting a discrete plan produces one layer per distinct titanium color used in the plan
- [ ] The user can change N and preview the banding before export
- [ ] The EngravingPlan stores, for each band/layer, the parameter set and predicted color with confidence, expected error and stability
- [ ] The exported file imports into LightBurn without manual re-assignment of layer parameters
