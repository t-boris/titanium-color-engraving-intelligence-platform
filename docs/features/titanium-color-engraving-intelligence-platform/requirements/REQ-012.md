## Statement

The system shall export an EngravingPlan to LightBurn by quantizing the plan into N bands, each band becoming one LightBurn output layer with its own fixed settings. LightBurn exposes 30 output colors, 00–29; T1/T2 are tool layers and shall never be used for laser output. The export shall count cleaning, registration and engraving layers against this 30-layer limit and refuse an oversized job before the file is offered. A plate with cleaning and registration may therefore use at most 28 test-setting layers.

## Acceptance Criteria

- [x] Every exported LightBurn project uses only output layer indices 00–29 and never assigns engraving geometry to T1/T2
- [x] Cleaning and registration layers count toward the output limit; generated capability plates contain no more than 28 test-setting layers
- [x] A Material-Test-style experimental matrix can vary any two of power, speed, frequency, Q-Pulse, line interval and passes while holding other process settings fixed; line interval is tested with filled patches and vector-line response is available separately
- [x] Matrix grids use no more than 28 test cells, fit within 100 × 100 mm including registration, and export with cleaning as the first LightBurn operation
- [x] A default 5 × 5 matrix minimizes stock use: approximately 60 × 61 mm, with compact corner registration and the QR placed in the top band; the cleaning region covers that footprint only
- [x] A plan exceeding the available output layers is refused with an explanation before export
- [x] Exporting a discrete plan produces one layer per distinct titanium color used in the plan
- [x] The user can change N and preview the banding before export
- [x] The EngravingPlan stores, for each band/layer, the parameter set and predicted color with confidence, expected error and stability
- [ ] The exported file imports into LightBurn without manual re-assignment of layer parameters
