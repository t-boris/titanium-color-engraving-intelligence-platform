## Statement

The system shall support two independent engraving workflows producing an internal EngravingPlan: Discrete Color Engraving (map desired image colors to validated/production titanium colors and their laser parameters) and Continuous Photo Engraving (luminance/grayscale → calibrated transfer function → continuously varying parameters, with Tonal and Color-path sub-modes). In Discrete Color Engraving each image color is matched to the nearest validated/production titanium color only if the expected color error is within a user-configurable ΔE threshold; otherwise the color is marked 'unreachable' and the user must choose a substitute from the titanium palette or exclude the color before the plan is finalized.

## Acceptance Criteria

- [ ] Each workflow produces an EngravingPlan in the internal format from an input image
- [ ] Each color in a Discrete plan shows the matched titanium color, its ΔE, confidence and stability
- [ ] Colors whose best match exceeds the ΔE threshold are marked 'unreachable' and the plan cannot be finalized until each is substituted or excluded by the user
- [ ] The ΔE threshold is adjustable by the user and its current value is visible in the conversion screen
- [ ] Continuous Photo Engraving offers Tonal and Color-path sub-modes on one pipeline
