## Statement

The system shall support two independent engraving workflows producing an internal EngravingPlan: Discrete Color Engraving and Continuous Photo Engraving. Discrete Color Engraving shall map desired image colors to validated/production titanium colors and their laser parameters. Each image color shall be matched to the nearest eligible validated/production titanium color only if the expected color error is within a user-configurable ΔE threshold; otherwise the color shall be marked 'unreachable', and the user must choose a substitute from the eligible titanium palette or exclude the color before the plan is finalized. Continuous Photo Engraving shall map luminance/grayscale through a calibrated transfer function to continuously varying laser parameters and shall support Tonal and Color-path as sub-modes of a single pipeline. Both sub-modes shall use one transfer-function abstraction with distinct calibration and evaluation strategies: Tonal shall map luminance to a monotonic parameter curve and be judged by brightness/contrast; Color-path shall map luminance to a user-chosen trajectory in titanium color space and be judged by ΔE along the path. Post-engraving analysis shall support both corresponding comparison metrics. Discrete and Color-path plans shall exclude questioned production parameter sets by default; the user must explicitly include such parameter sets for a specific plan before they become eligible for that plan, and inclusion shall not carry over to other plans. Tonal plans may use questioned production parameter sets with a visible warning and access to the associated observations, without separate confirmation. Plan generation in either workflow or Continuous sub-mode shall leave the questioned flag and knowledge stage unchanged.

## Acceptance Criteria

- [x] Each workflow produces an EngravingPlan in the internal format from an input image.
- [x] Discrete Color Engraving matches each desired image color to the nearest eligible validated/production titanium color only if its expected color error is within the user-configurable ΔE threshold.
- [x] Each matched color in a Discrete plan shows the matched titanium color, its ΔE, confidence and stability.
- [x] Colors whose best eligible match exceeds the ΔE threshold are marked 'unreachable', and the plan cannot be finalized until the user substitutes each such color with a color from the eligible titanium palette or excludes it.
- [x] The ΔE threshold is adjustable by the user, and its current value is visible in the conversion screen.
- [x] Continuous Photo Engraving offers Tonal and Color-path as sub-modes of a single pipeline using one calibrated transfer-function abstraction to map luminance/grayscale to continuously varying laser parameters.
- [x] Tonal calibration produces a monotonic parameter curve driven by luminance; Tonal evaluation assesses brightness and contrast.
- [x] Color-path calibration maps luminance to a user-chosen trajectory in titanium color space; Color-path evaluation measures ΔE along that trajectory.
- [x] Post-engraving analysis supports brightness/contrast comparison for Tonal and ΔE comparison along the chosen trajectory for Color-path.
- [x] Discrete and Color-path plans exclude questioned production parameter sets by default.
- [x] A questioned production parameter set becomes eligible for a Discrete or Color-path plan only when the user explicitly includes it for that specific plan; inclusion does not carry over to other plans.
- [x] Tonal plans may use questioned production parameter sets without separate confirmation.
- [x] When a Tonal plan uses questioned production parameter sets, Tonal planning displays a visible warning and provides access to the associated observations.
- [x] Plan generation in Discrete, Tonal and Color-path modes leaves each parameter set's questioned flag and knowledge stage unchanged.
