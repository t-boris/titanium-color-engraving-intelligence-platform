## Statement

The universal observation input shall remain a LightBurn project file paired with a fixed-rig photograph containing the reference chart. The importer shall reconstruct an EngravingPlan, align and color-correct the photograph, and measure each readable layer within its shapes with edges excluded. Parameters available in the file shall remain authoritative, including pulse width, line interval and passes. Missing required settings shall remain unknown unless supplied explicitly with provenance. Calibration-plate mismatches shall require correction or explicit confirmation of the file actually used. Different valid job settings shall form separate comparable groups rather than a profile-mismatch exclusion. All sources shall use the same measurement-quality and repetition rules.

## Acceptance Criteria

- [x] A LightBurn file and fixed-rig photograph with the reference chart are required for every artefact type; no separate legacy tier exists.
- [x] Import reconstructs layer geometry and reads power, frequency, speed, pulse width, line interval and passes wherever supported by the file.
- [x] Different pulse widths, line intervals or pass counts are assigned to their own comparable groups rather than rejected for differing from a former profile.
- [x] Missing or unsupported required parameters are visibly flagged; affected layers do not enter models or validation counts through invented defaults.
- [x] Calibration-plate parameter mismatches block acceptance until the pair is corrected or the operator explicitly confirms that the attached file was used; discrepancies and confirmation are retained.
- [x] Alignment uses markers when available or four manually selected corners; the operator can review overlaid masks before acceptance.
- [x] A photograph without a detected reference chart produces no color observations. Accepted photographs are chart-corrected and yield one observation per readable layer using its shape union with edges excluded.
- [x] All artefact types use the same quality and independent-engraving eligibility rules; re-photographs never add independent repetitions.
