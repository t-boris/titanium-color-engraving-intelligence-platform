## Statement

The universal observation input shall be the pair «LightBurn project file (.lbrn/.lbrn2) + photograph taken on the fixed rig with the reference chart». This applies equally to system-generated calibration plates and to finished artworks/photo engravings. Calibration plates shall be a special case of this workflow, using system-generated LightBurn files with registration markers and an experiment identifier. The system shall parse the layers with their power, frequency and speed and fill geometry from the LightBurn file, reconstruct an EngravingPlan, rasterize a mask per layer in plan coordinates, align the photograph automatically via registration markers when present, otherwise manually by the four image corners as in REQ-013, color-correct it via the reference chart, sample the color inside each layer mask excluding region edges, and store one observation per layer region with the parameters taken from the file and the alignment method recorded. The LightBurn file shall be the parameter source in all cases, including calibration plates. For calibration plates, the plate definition shall be retained for experiment identity and geometry linkage. In accordance with DEC-017, the system shall compare power, frequency and speed from the paired LightBurn file with the corresponding parameters in the linked plate definition. If any of those parameters differ, the system shall block observation acceptance until the operator corrects the pair so that the mismatch is resolved or explicitly confirms that the attached LightBurn file was used for the physical engraving. The discrepancy shall be recorded with any subsequently accepted observation, together with the operator's explicit confirmation when acceptance relies on that confirmation. After either resolution, power, frequency and speed shall still be sourced from the paired LightBurn file. Laser profile shall be the only mandatory observation context. Material profile, material batch/sheet ID, focus, date and notes shall be optional and default to 'unknown'; the UI shall offer quick optional fields with 'same as last plate' defaults where previous values are available. Missing optional metadata shall not prevent ingestion or reduce repetition eligibility. LightBurn files do not record focus, material batch or laser-profile constants. Stability analysis shall explicitly state that deviations can be attributed to batch or focus only where those fields were supplied. Photographs without a detectable reference chart shall be rejected or flagged, produce no observations and be excluded from model updates, regardless of artefact type, per REQ-009. Observations obtained through this workflow shall be regular controlled observations and inform the color-space model and AI Experiment Designer; no separate 'legacy/uncontrolled' tier shall exist. Comparable observations from the same parameter set across works and plates shall be pooled. In accordance with DEC-015 and DEC-016, observations from system-generated calibration plates, finished engravings and imported works shall be assessed under the same observation-quality and repetition-independence criteria for eligibility toward the REQ-005 repetition thresholds for automatic promotion to 'validated'. Whether the system created the work shall not determine eligibility, and no source-specific validation-repetition exclusion shall apply. Eligible observations shall count equally across artworks, photo engravings and plate cells. Shared observation-quality and repetition-independence criteria shall be defined separately before implementing automatic validation; DEC-016 does not establish specific thresholds. Layers with unsupported parameter axes shall be imported with a warning and marked as not comparable to the active laser profile. Independence of a validation repetition is defined by DEC-021: each separate physical engraving counts as one independent repetition, whether on a new piece or a new area of the same sheet, with the sheet link kept as context; a re-photograph of the same engraving never counts and only measures rig repeatability. Per DEC-022, pulse width and line interval recorded in a LightBurn layer are compared with the constants of the linked laser profile version; a layer whose values differ is imported with a warning, marked not comparable, and kept out of the color-space model and the repetition counts.

## Acceptance Criteria

- [ ] Every observation, whether from a calibration plate, artwork or photo engraving, requires a LightBurn project file (.lbrn or .lbrn2), a photograph taken on the fixed rig with the reference chart and an identified laser profile.
- [ ] Importing a .lbrn or .lbrn2 file lists its layers with power, frequency and speed, flags layers whose parameters cannot be read, and reconstructs an EngravingPlan from the parsed layer parameters and fill geometry.
- [ ] Laser parameters for every observation are sourced from the LightBurn file, including for system-generated calibration plates; the plate definition or experiment identifier does not replace the file as the parameter source.
- [ ] For calibration plates, the linked plate definition is retained for experiment identity and geometry linkage.
- [ ] For calibration plates, the system compares power, frequency and speed read from the paired LightBurn file with the corresponding parameters in the linked plate definition.
- [ ] If calibration-plate power, frequency or speed differs between the paired LightBurn file and the linked plate definition, observation acceptance is blocked until the operator corrects the pair so that the mismatch is resolved or explicitly confirms that the attached LightBurn file was used for the physical engraving.
- [ ] When a calibration-plate parameter mismatch is detected, its discrepancy record is retained with any subsequently accepted observation, together with the operator's explicit confirmation when acceptance relies on that confirmation.
- [ ] After mismatch resolution or explicit operator confirmation, the accepted observation still sources power, frequency and speed from the paired LightBurn file.
- [ ] System-generated calibration files include registration markers and an experiment identifier and are ingested through the same file-and-photograph workflow as finished works.
- [ ] A photograph without a detectable reference chart is rejected or flagged, produces no observations and is excluded from model updates, regardless of artefact type.
- [ ] Accepted photographs are color-corrected using the reference chart before color sampling.
- [ ] The system rasterizes a mask per layer in plan coordinates and aligns the photograph automatically using registration markers when present, otherwise manually using the four image corners as in REQ-013.
- [ ] After alignment, the UI overlays the layer masks on the photograph for user verification before saving.
- [ ] Each layer region produces one observation linking its corrected color, sampled inside the mask with region edges excluded, to the parameters read from the LightBurn file and records the alignment method as 'markers' or 'manual'.
- [ ] Observations from artworks, photo engravings and calibration plates are stored as regular controlled observations without a separate 'legacy/uncontrolled' tier.
- [ ] Comparable observations from the same parameter set across works and plates are pooled and inform the color-space model and AI Experiment Designer.
- [ ] Observations from system-generated calibration plates, finished engravings and imported works are assessed under the same observation-quality and repetition-independence criteria for eligibility toward the REQ-005 repetition thresholds for automatic promotion to 'validated'.
- [ ] Whether the system created a work does not determine validation-repetition eligibility, and no source-specific validation-repetition exclusion is applied.
- [ ] Eligible observations count equally toward the REQ-005 repetition thresholds regardless of whether they originate from artworks, photo engravings or calibration plate cells.
- [ ] Automatic validation is not implemented until shared observation-quality and repetition-independence criteria have been defined separately; DEC-016 does not establish specific thresholds.
- [ ] Material profile, material batch/sheet ID, focus, date and notes are optional observation metadata and default to 'unknown' when not supplied; missing optional metadata does not prevent ingestion or reduce repetition eligibility.
- [ ] The UI offers quick optional metadata fields with 'same as last plate' defaults where previous values are available.
- [ ] The specification and stability-analysis UI state that LightBurn files do not record focus, material batch or laser-profile constants, and that deviations can be attributed to batch or focus only for observations with the corresponding metadata supplied.
- [ ] Layers with unsupported parameter axes, such as a different pulse width, are imported with a warning and marked as not comparable to the active laser profile.
- [ ] A validation repetition is a separate physical engraving, on a new piece or a new area of the same sheet (DEC-021); a re-photograph of the same engraving is never counted as a repetition and only feeds rig repeatability.
- [ ] Pulse width and line interval read from a layer are compared with the linked laser profile constants; a layer that differs is imported with a warning, marked not comparable, and excluded from model updates and repetition counts (DEC-022).
