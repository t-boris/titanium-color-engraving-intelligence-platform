## Statement

The system shall maintain task-conditioned, evidence-backed knowledge with explicit maturity, uncertainty and production approval, treating physical measurements as the source of truth.

## Acceptance Criteria

- [ ] Knowledge relates task intent, source/geometry features, complete operation settings, hardware and material context to observed outcomes. Supported tasks include text, vector lines, filled regions, tonal images and color images, with an extensible vocabulary.
- [ ] Task-specific goals can include target color, tonal behavior, line width and text legibility. Every reported quality metric identifies its measurement method and calibration basis; unsupported metrics are unavailable.
- [ ] Knowledge progresses through measured, candidate, repeated, validated and production. Automatic promotion stops at validated; production promotion requires explicit operator approval.
- [ ] Automatic validation uses configurable repetition requirements and separately specified observation-quality and repetition-independence rules. These rules must be defined before automatic validation is enabled.
- [ ] Calibration plates, finished works and imported works use the same quality and independence rules. Source origin alone neither excludes an observation nor establishes an independent repetition; multiple photographs of one physical engraving are not presented as independent engravings.
- [ ] Retrieval filters by task and relevant operating context, separates observations from predictions, and links recommendations to supporting observations with sample counts, repeatability, confidence and missing context.
- [ ] Every predicted parameter set includes confidence, expected color error and stability, displayed beside the prediction. Unsupported metrics are explicitly unavailable rather than fabricated.
- [ ] Requests outside measured color coverage are identified explicitly. Unlike tasks, modes, lenses or titanium stocks do not silently contribute to a shared prediction or summary.
- [ ] Stability reports distinguish known contextual groups and explain when unknown batch or focus prevents attribution of deviations.
