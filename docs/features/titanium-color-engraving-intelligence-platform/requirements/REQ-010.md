## Statement

The first version shall support one material profile family (titanium) and one laser profile with three variable axes — power, frequency, speed — while pulse width, hatch/line interval, passes and focus are stored as constants of the profile. The profile model shall allow adding further axes later without migrating existing experiment data.

## Acceptance Criteria

- [ ] Calibration plates are generated as grids over power × frequency (× speed as a plate series or third dimension) with the profile constants recorded with the experiment.
- [ ] Every measurement stores the full parameter vector including constants, so later axes can be added without data loss.
- [ ] Changing a profile constant creates a new profile version; data from different versions are not merged silently.
