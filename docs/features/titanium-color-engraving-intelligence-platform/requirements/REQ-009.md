## Statement

Color measurement in the first version shall use the universal observation input of a LightBurn project file paired with a photograph taken on a fixed rig (camera on a stand, controlled lighting and viewing angle, RAW capture) with a color reference chart in every frame. This applies equally to system-generated calibration plates, finished artwork/photo engravings and imported works, with parameters sourced from the LightBurn file under REQ-016 and no separate legacy/uncontrolled provenance tier. The system shall detect the chart and use it to color-correct each photograph before measuring regions. Photographs without a detectable chart shall be flagged and excluded from model updates regardless of source. All observations shall be assessed under the same observation-quality criteria for model-update eligibility, with reference-chart detection mandatory. Observations that meet the shared observation-quality criteria shall enter the color-space model and feed the AI Experiment Designer on equal footing regardless of source. Eligibility for validation repetitions shall additionally require the same repetition-independence criteria for all sources; whether the system created the work shall not determine eligibility. Eligible observations shall count toward repetition thresholds for automatic promotion to validated on equal footing, without source-specific exclusions. Shared observation-quality and repetition-independence criteria shall be defined separately before implementing automatic validation; this requirement does not establish specific thresholds. Calibration plates shall be a special case of the same input path, using system-generated LightBurn files with registration markers and an experiment identifier. Photographs without registration markers shall fall back to manual corner alignment under REQ-013 without waiving the chart requirement. Rig measurement repeatability shall be tracked and shown as part of stability data. Independence of a validation repetition is defined by DEC-021: each separate physical engraving counts as one independent repetition, whether on a new piece or a new area of the same sheet, with the sheet link kept as context; a re-photograph of the same engraving never counts and only measures rig repeatability.

## Acceptance Criteria

- [ ] Every ingested observation consists of a LightBurn project file paired with a photograph of the corresponding calibration plate, finished artwork/photo engraving or imported work.
- [ ] Every ingested photograph is associated with a capture setup record documenting the fixed rig, camera stand, controlled lighting and viewing angle, and is captured in RAW format with a color reference chart in the frame.
- [ ] The system detects the reference chart and applies chart-based color correction before measuring any region.
- [ ] Region colors are reported in a device-independent color space after chart-based correction.
- [ ] Photographs without a detectable reference chart are flagged and excluded from model updates, regardless of observation source.
- [ ] System-generated calibration plates, finished engravings and imported works are assessed under the same observation-quality criteria for model-update eligibility; reference-chart detection is mandatory.
- [ ] No separate legacy/uncontrolled provenance tier or source-specific validation-repetition exclusion is used.
- [ ] Whether the system created the work does not determine eligibility for validation repetitions.
- [ ] Parameters associated with measured regions are sourced from the paired LightBurn project file in all cases, as specified in REQ-016.
- [ ] Photographs without registration markers fall back to manual corner alignment under REQ-013; this fallback does not waive the reference-chart requirement.
- [ ] Calibration plates use the same observation input path as finished engravings and imported works, with a system-generated LightBurn project file containing registration markers and an experiment identifier.
- [ ] Observations from finished artwork/photo engravings and imported works that meet the shared observation-quality criteria enter the color-space model and feed the AI Experiment Designer on equal footing with calibration plate cells.
- [ ] Observations from all sources that meet the shared observation-quality and repetition-independence criteria count toward repetition thresholds for automatic promotion to validated on equal footing.
- [ ] Shared observation-quality and repetition-independence criteria are defined separately before automatic validation is implemented; this requirement does not establish specific thresholds.
- [ ] Measurement repeatability of the rig is tracked by re-photographing the same artefact and is shown as part of stability data.
- [ ] A validation repetition is a separate physical engraving, on a new piece or a new area of the same sheet (DEC-021); a re-photograph of the same engraving is never counted as a repetition and only feeds rig repeatability.
