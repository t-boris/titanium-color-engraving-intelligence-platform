## Statement

The system shall offer, on the Result tab of every vector work, the link "Загрузить фото для этой работы" that opens the upload form for that work with its laser, lens and titanium filled in, link the photograph to the work, and say so on the form and on the pair page; when the LightBurn file names another work than the one chosen, its own identifier decides and the check warns.

## Acceptance Criteria

- [ ] The Result tab of a work shows the link both before any photograph was accepted and after, and it opens /ingest?plan=<work id>&material=<work titanium id>.
- [ ] The upload form opened that way names the work with a link back to it, and takes the work's laser, lens and titanium (the operator can still change them).
- [ ] A pair made that way is linked to the work; the pair page names the work and says the conclusion will be written into it.
- [ ] A LightBurn file whose identifier names another work is linked to that work, and the check warns which work the file belongs to and which one was chosen.
- [ ] A file without an identifier falls back to the chosen work.
- [ ] A form opened for a plate or without a plan does not mention a work.
