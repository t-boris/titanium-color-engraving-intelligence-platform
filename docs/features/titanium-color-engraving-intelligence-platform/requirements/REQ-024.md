## Statement

The system shall align the photograph of an unmarked finished work to its LightBurn file by matching individual elements, fitting the transform to the reliable matches only, predicting every other element from the file geometry, and detecting the visible window of a frame so that hidden parts are inferred and excluded from measurement.

## Acceptance Criteria

- [ ] All 8 orientations (four rotations, with and without mirror) are scored; the result is refused when the best orientation does not beat the second by the required margin
- [x] Each element is searched independently around its prediction; only elements with a close and distinctive match are anchors
- [x] The transform is fitted to the anchors only, with outlier rejection, and refined with a shrinking search window
- [ ] Fewer anchors than the minimum, anchors concentrated in one area, or an anchor residual above the limit refuse the registration and leave manual four-corner placement available
- [x] Every element gets a status: anchor, confirmed, computed, partly hidden or hidden; the counts, the orientation margin and the anchor residual in mm are stored in the alignment record
- [x] The frame window polygon is stored; pixels outside it are excluded from every layer mask and an element entirely outside it is not measured
- [ ] Hidden margins of the plate (mm per side) and the bootstrap uncertainty of the prediction are reported as estimates
- [x] The reference-chart requirement of REQ-009 is unchanged: no chart, no observations
- [x] On a synthetic framed and perspective-distorted work the recovered transform agrees with the true one within 0.3 mm inside the window
