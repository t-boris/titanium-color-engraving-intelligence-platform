## Statement

The system shall provide one experiment-centered workspace and a traceable color map for inspecting evidence, finding recipes and comparing engraving time.

## Acceptance Criteria

- [x] One experiment list represents generated plates, imported works and finished engravings, including experiments awaiting photographs. Each entry shows its latest photograph, state, laser, lens and titanium.
- [x] An experiment contains its plate or work, LightBurn files, all photographs and checks, measured layers and conclusions. Opening it immediately shows the photograph and overlay, with selectable checks, brightness adjustment and contour controls.
- [x] Existing plate, work and check entry points link to their experiment. Material-level conclusions remain accessible from the experiment list.
- [x] Deleted records do not appear as active experiments or map evidence. Removing a plate definition does not discard retained finished-work observations and checks.
- [x] A general color map shows measured colors from retained experiments, filterable by laser, lens, material and measurement basis. Each point exposes complete recipe settings, experiment, layer, photograph, date and source links.
- [x] Wanted colors can be selected from a palette, entered as Lab or sampled from the map. Search returns one result per recipe, with color distance, independent engraving count, repeatability and source experiments.
- [x] Chart-corrected and camera-relative colors are distinguished. Colors without a clean reference are counted and omitted by default; service layers, including identifiable cleaning layers in earlier works, are excluded.
- [x] Every recipe shows an estimated engraving time in the applicable units: time per square centimetre for fills and time per centimetre for lines. Estimates account for speed, line interval where applicable, passes, repeats, cross-hatch and turnaround allowance.
- [x] The color map and vector workflow support a maximum estimated time per area. Within the selected color-error tolerance, search and initial color assignment prefer the fastest eligible recipe and disclose that ordering.
