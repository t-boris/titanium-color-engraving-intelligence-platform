## Statement

The system shall maintain an auditable observation record linking physical engravings, source artefacts, reconstructed geometry, complete process settings and measured outcomes, with explicit provenance and no invented historical values.

## Acceptance Criteria

- [ ] Each observation retains the original photograph, available source image, LightBurn project, physical engraving identity, laser device, historical lens context, task, geometry, settings and their provenance.
- [ ] LightBurn-recorded settings are authoritative. Missing settings remain visibly unknown unless explicitly supplied by the operator with provenance; defaults and the currently installed lens are never silently asserted as historical facts.
- [ ] Import preserves all layer settings, ordered sub-layer settings, bitmap processing settings, embedded pictures and effective geometry after nested transforms. Unsupported shapes or settings are reported per layer.
- [ ] Path import preserves separate outlines, holes and per-subpath closure, including mixed straight and curved edges. Curve approximation error is at most 0.02 mm; bounds and measurement masks include the resulting geometry correctly.
- [ ] Equivalent numeric representations produce the same recipe identity. All applicable operation settings affect recipe identity; layer execution priority does not.
- [ ] For a generated calibration plate, acceptance compares the attached LightBurn file with the plate definition. Discrepancies block acceptance until corrected or the operator confirms that the attached file was used; discrepancies and confirmation remain recorded.
- [ ] A complete photographed parameter matrix may be imported without an original LightBurn file. The system proposes one experiment per complete matrix, reconstructs cell settings from fixed settings and row/column values, and requires complete operator-confirmed settings before acceptance.
- [ ] Matrix import shows recognized labels and uncertain or inconsistent values, rejects incomplete matrices and photographs without a usable matrix, and regenerates its derived LightBurn file and checks after corrections. Reconstructed settings are identified as operator-confirmed reconstruction rather than original-file evidence.
- [ ] Material identity, batch/sheet, focus, date and notes can be recorded, remain unknown when absent, and support explicit reuse of previous values. Missing optional batch or focus alone does not disqualify a repetition.
