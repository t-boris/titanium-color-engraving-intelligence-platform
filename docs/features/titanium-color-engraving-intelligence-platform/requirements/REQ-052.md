## Statement

The system shall write the LightBurn file of a vector work so that LightBurn's canvas shows the picture upright, and so that no curved edge of any region is drawn with a handle LightBurn has to guess.

## Acceptance Criteria

- [ ] The file of a vector work carries MirrorY=True, as the files of the plates do, and the plan records it so that a file LightBurn saves back with MirrorY=False and reflected shapes is read against it
- [ ] Every Bezier edge of every region has both of its handles written, also when one of them lies on its vertex (a corner)
- [ ] The geometry of the regions, read back, is the same as before
- [ ] On the real work 22 the four one-sided edges that LightBurn drew as two long slivers across the faces are gone
