## Statement

The system shall, when the photograph of an engraving linked to a vector work is accepted, set the colour each layer of the work's file promised against the colour the photograph measured for the layer of the same settings, keep that review in the work, and tell the operator which layers of their works no longer have the colour their last file promised and what measured colour could replace it.

## Acceptance Criteria

- [ ] Each LightBurn file made from a work keeps, per layer, its settings, the colour shown in the preview and its basis, its area and its regions
- [ ] Layers of the engraved file and of the exported file are matched by their settings (LightBurn rounding tolerated), never by layer number; layers that match nothing are listed on both sides, and a file that matches no layer says so
- [ ] The review gives, per matched layer, the promised and measured colour, ΔE, and the shifts of lightness, chroma and hue; a layer is beyond when ΔE exceeds the larger of 5 and the photograph's chart residual; the summary weighs ΔE by area
- [ ] The review names only what the measurements show (a clipped highlight, a different measurement basis, a photograph without a chart, a poor chart, one shift of most layers); a layer with none has no cause
- [ ] The review is kept in the work, one per engraving (a new measurement of the same engraving replaces it, deleting the only photograph removes it), is shown on the work's Result tab with the work drawn in promised and in measured colours, in the list of works and in the report of the photograph
- [ ] After an acceptance, a re-measurement or a deletion the layers of every work of that laser and lens whose recipe colour moved more than 5 ΔE from the last file's promise are counted and shown in the list; a recipe the work no longer uses is not counted; a work never exported has none
- [ ] For each source colour of a moved layer the closest measured colour is proposed when it is at least 1 ΔE nearer; the operator applies it as an ordinary undoable edit and nothing is applied by the system
- [x] A file made before promises were kept is reconstructed from the work's layers while the colouring is unchanged and is marked approximate; after a recolouring nothing is claimed
- [ ] The work's screen, the list of works and the report stay under 0.5 s
