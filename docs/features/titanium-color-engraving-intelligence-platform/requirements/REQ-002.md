## Statement

The system shall never assume a requested color can be reproduced exactly. Every predicted engraving parameter set shall include a confidence value, an expected color error and a stability indicator.

## Acceptance Criteria

- [x] No parameter prediction can be emitted without all three fields: confidence, expected color error, stability.
- [x] When a requested color lies outside the measured color space, the prediction indicates this explicitly instead of returning an unqualified parameter set.
- [x] The UI/plan output shows these three values next to each predicted parameter set.
