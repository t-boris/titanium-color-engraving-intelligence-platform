## Statement

The system shall let the operator give any experiment another name from its page, and only the name shall change.

## Acceptance Criteria

- [ ] The experiment page has a pencil beside its title; it opens «Переименовать эксперимент» with the current name in a field.
- [ ] An experiment made from a plate or a work is renamed through its plan; a finished work without a plate is renamed through its engraving's title, which all its photographs share.
- [ ] The name is stripped of spaces at both ends; a blank name is refused (422) and an unknown experiment answers 404.
- [ ] Naming an experiment as it is already named writes nothing; a rename writes one audit row experiment_renamed with the key, the old and the new name.
- [ ] The new name is shown at once in the page head and in the list of experiments; nothing else about the experiment, its checks or its measurements changes.
