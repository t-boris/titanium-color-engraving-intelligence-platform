## Statement

The system shall write every picture's LightBurn file (a photo work's file and «Картинка на шкале») with the laser's cleaning recipe over the picture's rectangle on C00, run first, and the picture on C01, count the cleaning in the work's time, and open a work's file in the preview with the work's laser, lens and titanium.

## Acceptance Criteria

- [ ] The file's first layer is C00 CLEAN-CROSSHATCH-… (the laser's cleaning recipe), a rectangle exactly over the picture; the picture is the image layer on C01
- [ ] The work's time equals the file's time and says «из них чистка ≈ …»
- [ ] The photograph of the engraving takes C00 for the pre-test cleaning witness and measures C01 as the picture
- [ ] «Файл в предпросмотре» on a work opens «Предпросмотр фотогравировки» with the work's file chosen and its laser, lens and titanium set, and predicts it
