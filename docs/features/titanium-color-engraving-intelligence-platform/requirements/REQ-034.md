## Statement

The system shall colour the regions of a vector work with measured titanium colours of its laser, lens and titanium, let the operator change any colour by hand or recolour the whole work automatically, show the result in titanium colours, and only then generate a LightBurn file that fully defines how the work is engraved.

## Acceptance Criteria

- [ ] Each source colour is first given the measured titanium colour chosen by the speed rule of DEC-075 (fastest recipe within the delta E tolerance, else the nearest); every colour shows how it was measured, how many independent engravings gave it and its recipe
- [ ] The operator can change the titanium colour of a whole colour group or of a single region, choosing from the measured colours of this laser, lens and titanium
- [ ] Automatic recolouring offers: closest to the original, keep tonality (the lightness order of the original colours is kept), random (another variant on request, earlier variants restorable) and fewer layers (near colours merged); each variant is previewed and can be kept or undone
- [ ] A preview shows the work in its titanium colours beside the original and the split result
- [ ] The LightBurn file is generated only from a coloured work: cleaning first, then one output layer per recipe used with its complete settings (at most 29), every region as a closed Path made of the shared borders, nothing exported without a recipe
- [ ] The exported file parses back with the same regions, layers and settings, and its regions leave no gaps
- [ ] The colouring and every variant are kept in the work record with the file that was exported
