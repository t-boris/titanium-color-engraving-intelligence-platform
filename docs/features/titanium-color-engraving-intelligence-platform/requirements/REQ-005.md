## Statement

Knowledge shall progress through explicit stages: measured → candidate → repeated → validated → production. The system shall promote knowledge automatically up to and including 'validated' when the configured repetition threshold is met; promotion to 'production' requires explicit user approval. The system shall never demote a 'production' color automatically. When new observations (post-engraving analysis or a repeated calibration plate) show that a production color is unstable or deviates beyond the configured tolerance, the system shall flag it as 'questioned', keep its stage unchanged, and present the supporting evidence. A questioned color is excluded from new engraving plans by default; the user may explicitly include it in a plan, confirm it (clear the flag) or demote it manually.

## Acceptance Criteria

- [ ] Each knowledge entry has exactly one maturity stage from the ordered set measured, candidate, repeated, validated, production.
- [ ] Automatic promotion stops at 'validated'; moving to 'production' is possible only through an explicit user action.
- [ ] No automatic action ever changes the stage of a 'production' entry downward.
- [ ] When a production color fails the stability/deviation check, it receives a 'questioned' flag and the evidence (observations, measured deviations) is viewable by the user.
- [ ] Discrete Color Engraving and Color-path Photo Engraving do not use questioned colors unless the user explicitly includes them for that plan.
- [ ] The user can clear the flag (confirm) or demote the entry manually; both actions are recorded with the observations that triggered the flag.
