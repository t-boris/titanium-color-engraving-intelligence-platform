## Statement

Knowledge shall progress through explicit stages: measured → candidate → repeated → validated → production. The system shall promote knowledge automatically up to and including 'validated' using a configurable repetition threshold; promotion to 'production' requires explicit user approval. Observations from system-generated calibration plates, finished engravings and imported works shall be assessed under the same observation-quality and repetition-independence criteria for eligibility as validation repetitions. Whether the system created the work shall not determine eligibility. Shared observation-quality and repetition-independence criteria shall be specified separately before automatic validation is implemented; this requirement does not establish specific eligibility thresholds. Maturity transitions shall have a history log and support rollback. The system shall never demote a 'production' color automatically, including through rollback. When new observations (post-engraving analysis or a repeated calibration plate) show that a production color is unstable or deviates beyond the configured tolerance, the system shall flag it as 'questioned', keep its stage unchanged, and present the supporting evidence. Questioned production parameter sets are excluded from new Discrete Color Engraving and Color-path Photo Engraving plans by default; the user may explicitly include them in a specific plan. Tonal plans may use questioned production parameter sets with a visible warning and access to the associated observations, without separate user confirmation. Plan generation shall leave the questioned flag and knowledge stage unchanged in all three modes. The user may confirm a questioned entry (clear the flag) or demote it manually. Confirmation and manual demotion shall be recorded with the observations that triggered the flag. The system shall support a universal ingestion workflow accepting a LightBurn file (.lbrn/.lbrn2) together with a rig photograph of the finished engraving, including historical works. Layer parameters (power, frequency, speed) and fill geometry shall be parsed to reconstruct an EngravingPlan, and the photograph shall be aligned manually by image corners. Each layer region shall yield observations stored in the experiment database. Imported observations shall inform the color-space model and AI Experiment Designer and shall be eligible for validation repetitions under the shared observation-quality and repetition-independence criteria, without a legacy/uncontrolled tier or source-specific exclusions. Independence of a validation repetition is defined by DEC-021: each separate physical engraving counts as one independent repetition, whether on a new piece or a new area of the same sheet, with the sheet link kept as context; a re-photograph of the same engraving never counts and only measures rig repeatability.

## Acceptance Criteria

- [x] Each knowledge entry has exactly one maturity stage from the ordered set measured, candidate, repeated, validated, production.
- [x] The repetition threshold is configurable; automatic promotion follows measured → candidate → repeated → validated and stops at validated.
- [x] Shared observation-quality and repetition-independence criteria are specified separately before automatic validation is implemented; this requirement establishes no specific eligibility thresholds.
- [x] Observations from system-generated calibration plates, finished engravings and imported works are assessed under the same observation-quality and repetition-independence criteria for validation repetitions.
- [x] Whether the system created a work does not affect the eligibility of its observations for validation repetitions.
- [x] No legacy/uncontrolled tier or source-specific validation-repetition exclusion is applied to imported observations.
- [x] Moving an entry to production requires an explicit user action.
- [x] No automatic action, including rollback, changes the stage of a production entry downward.
- [x] Maturity transitions are recorded in a history log, and rollback is available; rolling back a production entry to a lower stage requires an explicit user action.
- [x] When a production color fails the configured stability or deviation check, it receives a questioned flag, retains its production stage, and exposes the supporting observations and measured deviations to the user.
- [x] Discrete Color Engraving and Color-path Photo Engraving exclude questioned production parameter sets from new plans unless the user explicitly includes them for that specific plan.
- [x] Tonal plans may use questioned production parameter sets without separate user confirmation.
- [x] When a Tonal plan uses questioned production parameter sets, the system displays a visible warning and provides access to their associated observations.
- [x] Plan generation does not change the questioned flag or knowledge stage of any parameter set used in a Discrete, Color-path or Tonal plan.
- [x] The user can confirm a questioned entry to clear its flag or demote it manually; both actions are recorded with the observations that triggered the flag.
- [ ] The system provides a universal ingestion workflow accepting a LightBurn file in .lbrn or .lbrn2 format together with a rig photograph of the finished engraving, including historical works.
- [x] LightBurn ingestion reconstructs an EngravingPlan from the file's layer power, frequency, speed and fill geometry, and supports manual photograph alignment by image corners.
- [x] Each ingested layer region yields observations stored in the experiment database.
- [x] Imported observations inform the color-space model and AI Experiment Designer and are eligible for validation repetitions when they satisfy the shared observation-quality and repetition-independence criteria.
- [x] A validation repetition is a separate physical engraving, on a new piece or a new area of the same sheet (DEC-021); a re-photograph of the same engraving is never counted as a repetition and only feeds rig repeatability.
