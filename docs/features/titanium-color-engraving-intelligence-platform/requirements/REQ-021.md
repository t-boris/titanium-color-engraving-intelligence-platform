## Statement

The system shall accept a source photograph or image and an intended engraving result, prepare an editable vector representation, and generate a normal LightBurn project for the selected laser and lens. The operator shall be able to choose among task strategies such as text, line art, filled/color artwork, tonal photo and color-path photo. The system shall preserve the original image, vector geometry, task assignments, selected settings, predictions and exported LightBurn file as one linked work record.

The job builder shall use the task-conditioned knowledge in REQ-020 to assign supported settings to vector regions, paths or layers. It shall show a preview and identify portions outside measured coverage or with weak evidence before export. It shall not fabricate a supported recipe where none exists; uncovered areas can instead be routed to a proposed experiment.

## Acceptance Criteria

- [x] An image can be imported with a selected task strategy and target physical size.
- [x] The prepared artwork contains editable vector geometry, with regions/paths retaining their source-image relationship and intended engraving task.
- [x] Each generated layer or operation has the full applicable LightBurn settings and hardware/material context.
- [x] A preview shows the generated geometry, task assignments, predicted outcomes and areas without adequate evidence.
- [x] The user can review and revise the vectorization and settings before export.
- [ ] The exported standard LightBurn file opens with the intended geometry and layer settings, and remains linked to its source image and plan.
- [ ] After engraving, the paired result photo can be measured against the source and plan and added to the task-specific knowledge base.
