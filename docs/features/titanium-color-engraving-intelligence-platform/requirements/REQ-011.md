## Statement

The system shall run as a locally launched web application on the user's PC (single user, no roles, data stored locally) with the interface in a browser, usable from a tablet near the rig on the same network. Engraving plans shall be exported in a form LightBurn can load; the system shall not control the laser directly.

## Acceptance Criteria

- [ ] All data (experiments, photos, models, plans) are stored on the local machine and work without internet access.
- [ ] The UI is reachable from a browser on another device on the local network to upload photos from the rig.
- [ ] An EngravingPlan can be exported to a LightBurn-loadable artifact with the parameter settings preserved per layer/region.
- [ ] No login or role system is required in the first version.
