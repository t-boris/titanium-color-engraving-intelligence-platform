## Statement

The system shall run as a single locally launched process on the user's PC, providing a single-user web application with no login or role system and locally stored data. Its browser UI shall be reachable from a tablet near the rig on the same local network. The specification shall describe browser UI screens without choosing a specific implementation technology. Engraving plans shall be exported in a form LightBurn can load; the system shall not control the laser directly.

## Acceptance Criteria

- [x] The application runs as a single locally launched process on the user's PC.
- [x] The application serves its UI in a browser.
- [ ] All data (experiments, photos, models, plans) are stored on the local machine and work without internet access.
- [ ] The UI is reachable from a browser on a tablet or another device on the same local network, allowing photo uploads from near the rig.
- [x] An EngravingPlan can be exported to a LightBurn-loadable artifact with the parameter settings preserved per layer/region.
- [x] The system does not control the laser directly.
- [x] The first version supports a single user without a login or role system.
- [x] The specification describes browser UI screens without choosing a specific implementation technology.
