## Statement

The system shall read every Path shape of a .lbrn/.lbrn2 file as exact outlines in file millimetres: Bezier edges flattened to polylines, each sub-path separated, nested sub-paths kept as holes, and closure decided per sub-path from its full edge list.

## Acceptance Criteria

- [ ] A path whose edges mix line and Bezier primitives and return to the first vertex is reported closed
- [ ] A path with two disjoint loops yields two regions; a loop inside another loop is a hole of that region
- [ ] Bezier edges are flattened so that no sample deviates more than 0.02 mm from the curve
- [ ] The XForm of the shape is applied; the bounding box of a region covers the flattened curve
- [ ] A fill mask of a region with a hole does not cover the hole
- [ ] Existing Rect and Bitmap regions and every layer setting are read exactly as before
