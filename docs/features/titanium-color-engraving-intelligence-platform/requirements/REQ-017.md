## Statement

The system shall store each physical laser as a device record (identity, passport limits, a table of selectable pulse widths with their power cut-off frequency, acceptance-test results, controller configuration and attached source documents), link a laser profile version to at most one device, and generate that device's charts and operating-point figures from the stored data.

## Acceptance Criteria

- [ ] A device stores manufacturer, model, optional serial number, rated average power, repetition-rate range and a table of selectable pulse widths, each with its cut-off frequency (CW has none).
- [ ] A laser profile can be linked to a device; creating, updating or linking a profile whose pulse width is not a selectable step of that device is refused with a message that lists the steps.
- [ ] Changing a profile's device link does not create a profile version and does not change stored constants, plates or measurements.
- [ ] Source documents (JPG, PNG, PDF, TXT) can be attached to a device with a kind and a title, viewed in the UI and removed; the original file is kept byte for byte.
- [ ] Charts are generated only from stored data: cut-off frequency by pulse width, maximum pulse energy by pulse width, output power by frequency and pulse energy by frequency; no value is typed twice.
- [ ] For a set power, frequency, speed, pulse width, line interval and passes the system reports output power, pulse energy, pulse pitch, pulse density, areal dose and coverage rate, and states that these come from the passport model and are not measurements.
- [ ] When the profile has a device, the calibration plate preview and the stored plate cells show output power and pulse energy per cell; the parameter vector of observations is unchanged.
- [ ] A value that cannot be read reliably from a photograph is not stored as data; it is listed as an open item of the device.
- [ ] A catalogue template for the JPT YDFLP-E-60-M7-M-R creates a device with its pulse-width and cut-off table without typing it.
