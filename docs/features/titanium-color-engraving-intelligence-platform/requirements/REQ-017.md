## Statement

The system shall store physical lasers as device records containing equipment facts, acceptance-test results, controller settings and source documents, and derive charts from those records. Plates and plans shall select the device directly. Uncertain handwritten controller values shall remain visibly unverified; illegible or conflicting values shall not be resolved by guessing. Equipment confirmation shall not alter historical measurements.

## Acceptance Criteria

- [x] Device records retain identity, optional serial number, rated power, repetition-rate limits, selectable pulse widths and cut-off frequencies, test results, controller settings and unchanged source documents.
- [x] Plate and plan pulse widths are checked against the selected device's selectable steps; an unsupported value is refused with the available steps shown.
- [x] Source documents remain viewable and removable, and charts are generated from stored data without duplicate manual entry.
- [x] Controller settings distinguish printed, handwritten/unverified and confirmed values. Illegible values remain unknown with a source reference.
- [x] Conflicting handwritten and printed values, including Max PWM, are shown together as unresolved; neither is silently promoted to confirmed.
- [x] Galvo scales, red-pointer scales and the controller serial number are not invented or copied from unrelated equipment.
- [x] The existing JPT device template remains available; operating-point figures use the selected job settings rather than profile constants.
