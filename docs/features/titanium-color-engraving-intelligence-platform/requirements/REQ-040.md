## Statement

The system shall identify useful learning opportunities, propose targeted experiments and generate identifiable calibration plates whose measured results close the learning loop.

## Acceptance Criteria

- [x] Accepted observations can trigger analysis; the operator can also run or schedule analysis of accumulated work.
- [x] Findings identify their supporting records, comparison, task/material context, sample count, uncertainty and limitations. Measured improvements, hypotheses, anomalies and AI explanations are visibly distinct.
- [x] Follow-up proposals address stated coverage gaps, uncertainty, instability or target colors and explain each selected setting. Colors marked unreachable during artwork conversion automatically become visible experiment targets.
- [x] Proposals addressing a target color retain that link through engraving, measurement and comparison.
- [x] Proposal generation works offline and is reproducible for the same data, configuration and seed. Optional LLM explanations cannot alter selected settings, observations or measured conclusions; their absence does not change the proposal.
- [x] The operator decides which proposal to engrave. An accepted proposal generates a calibration experiment with its configured cleaning pass first, registration markers and a machine-readable identifier engraved with the test geometry.
- [x] Parameter matrices can vary any two supported settings among power, speed, frequency, pulse width, line interval and passes while holding the remainder fixed. Power-by-frequency grids with speed series are supported; line-interval tests use filled patches and vector-line response can be tested separately.
- [x] Generated matrices contain no more than 28 test-setting cells, fit within 100 × 100 mm including registration, and satisfy known equipment field limits. A compact default 5 × 5 layout minimizes stock use, with cleaning restricted to the plate footprint.
- [x] Results link back to the proposal and experiment definition. Findings can be recalculated as evidence accumulates while preserving prior versions and provenance.
