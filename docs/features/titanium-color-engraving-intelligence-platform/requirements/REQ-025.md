## Statement

The system shall keep every setting a LightBurn layer carries, including nested sub-layer passes and the image settings of bitmap objects, apply group transforms to the shapes inside them, and report each shape that it does not read instead of ignoring it.

## Acceptance Criteria

- [ ] Every nested setting of a SubLayer is kept in the layer's settings, several sub-layers in file order, and they take part in the recipe key
- [ ] Numbers written differently ('20' and '20.0') in nested settings give the same key; keys of existing flat settings do not change
- [ ] A shape inside a group is positioned by its own transform followed by the transforms of the groups above it
- [ ] Text, ellipse and any other shape type that has no outline geometry is counted per layer, shown as a note of that layer and never dropped silently
- [ ] The image settings of a bitmap object (without its pixels, file name and size) are part of its layer's settings
- [ ] The run order (priority) of a layer is not part of the recipe stored with new observations (DEC-051)
- [ ] A layer is not sampled where a later layer engraves over it (DEC-050)
