## Statement

The system shall estimate the engraving time of every recipe from its settings, show it on the colour map and in vector work, filter colours by a maximum time per area, and prefer the faster of colours that are equally close.

## Acceptance Criteria

- [ ] A filled recipe's time per square centimetre is 100 / (speed x line interval) seconds x passes x global repeats x 2 with cross-hatch, plus a turnaround allowance per line; Line-mode recipes have a time per centimetre; pulse width and frequency do not change it
- [ ] The time is labelled an estimate and shown for every colour on the colour map and in vector work
- [ ] The colour map and vector work filter colours by a maximum time per square centimetre
- [ ] The nearest-colour search orders colours within the delta E tolerance by time, fastest first, and says so
- [ ] The estimated time of a whole vector work is shown before export
