## Statement

The system shall provide an offline local application that previews evidence-supported grayscale results and exports reviewable engraving plans within LightBurn and equipment constraints.

## Acceptance Criteria

- [x] The application runs as one locally launched process, stores experiments, files, models and plans locally, and performs its core workflows without internet access.
- [ ] A single-user browser UI requires no login or role system and is reachable from a tablet on the same local network, including photograph upload near the rig. Screen behavior is specified without prescribing an implementation framework.
- [ ] Plans export as standard LightBurn-loadable projects with intended geometry, full applicable settings and execution order preserved. The system does not directly control the laser.
- [x] Continuous parameter plans are quantized into fixed-setting output layers. All exports use only output indices 00–29; tool layers T1/T2 never carry laser output.
- [x] Cleaning, registration and engraving all count toward the 30-output-layer limit. Oversized jobs are refused with an explanation before download; cleaning executes first.
- [x] Vector export uses closed regions with shared boundaries and one output layer per used recipe. Reimport preserves regions, holes, layer settings and gapless coverage.
- [x] For a grayscale image layer, a predicted titanium preview maps processed grey levels linearly from minimum to maximum power and interpolates Lab between neighboring measured powers under matching operating, hardware and material conditions.
- [x] Prediction previews identify the evidence behind every curve point and label camera-relative evidence. Powers outside the measured span are not extrapolated: affected pixels are hatched and their share is reported.
- [x] Brightness, contrast and gamma adjustments use disclosed assumptions; unmodeled enhancement and denoising are named. Unsupported dithered modes and files without an embedded picture are refused with a reason.
- [x] Changing minimum or maximum power updates the preview without another upload. Exported files and subsequent observations remain linked to the reviewed plan.
