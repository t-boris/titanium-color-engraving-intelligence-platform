## Statement

The system shall accept a photograph of a parameter matrix (LightBurn Material Test) without a LightBurn file, find the grid, read the engraved settings, let the operator confirm or correct them, and measure the colour of every cell as an observation carrying that cell's full setting.

## Acceptance Criteria

- [x] A photograph with one or more complete matrices yields one proposed experiment per matrix; a matrix cut by the edge of the photograph is not offered; a photograph without a matrix is refused with a reason
- [x] Every cell's settings are the header's fixed settings plus its row's and its column's value; axis values are evenly spaced between the first and last value
- [ ] Labels are read when tesseract is installed; a value that agrees with no evenly spaced sequence is not used; what was read is shown to the operator
- [x] Missing or unusual settings are listed on the review screen; acceptance is refused until the settings are complete and confirmed
- [x] Correcting the settings regenerates the LightBurn file and re-checks the photograph
- [x] Each accepted cell is an observation with its settings and its cell in the evidence; chart-corrected cells are eligible for the colour model
- [ ] The review and experiment screens show the measured colour of every cell in a table with the axis values
