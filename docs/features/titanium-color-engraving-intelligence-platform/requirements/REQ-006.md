## Statement

The system shall analyze gaps and uncertainty in the existing color space and propose new calibration plates designed to maximize useful information from the next physical experiment. Colors marked 'unreachable' during Discrete Color Engraving are automatically recorded as target colors, and the Experiment Designer shall take them into account alongside gap and uncertainty analysis when proposing the next plate.

## Acceptance Criteria

- [ ] Each proposed plate lists the parameter sets to engrave and the reason for each (gap, high uncertainty, instability, or target color)
- [ ] Marking a color 'unreachable' in artwork conversion creates a target color visible to the Experiment Designer without extra user action
- [ ] A proposed plate that addresses a target color references that color so the result can be checked against it after measurement
