## Statement

The system shall analyze gaps and uncertainty in the existing color space and propose new calibration plates designed to maximize useful information from the next physical experiment. Plate proposals are computed by an offline algorithmic core (color-space model with uncertainty plus an acquisition function over candidate parameter sets) that takes into account gaps, high uncertainty, instability and target colors; colors marked 'unreachable' during Discrete Color Engraving are automatically recorded as target colors. An external LLM may optionally produce an explanation and hypotheses for the operator but shall never choose parameters or modify data; the module shall work fully without an LLM key. The system shall support a universal ingestion workflow using a LightBurn file (.lbrn/.lbrn2) together with a rig photograph of the finished engraving, including historical works. Layer parameters (power, frequency, speed) and fill geometry shall be parsed from the file to reconstruct an EngravingPlan; the photograph shall be aligned manually by image corners as specified in DEC-010. Each layer region shall yield observations stored in the experiment database. These observations shall inform the color-space model and Experiment Designer. In accordance with DEC-016 applying DEC-015, observations from system-generated calibration plates, finished engravings and imported works shall be assessed under the same observation-quality and repetition-independence criteria for eligibility as validation repetitions. Whether the system created the work shall not determine eligibility. The 'legacy/uncontrolled' tier and its validation-repetition exclusions shall be removed; no source-specific restriction shall replace them. Shared observation-quality and repetition-independence criteria shall be defined separately before implementing automatic validation; DEC-016 does not establish specific thresholds. DEC-012 shall be explicitly marked as superseded by DEC-015, and the previous proposed weighting rule shall no longer be pending user confirmation. Independence of a validation repetition is defined by DEC-021: each separate physical engraving counts as one independent repetition, whether on a new piece or a new area of the same sheet, with the sheet link kept as context; a re-photograph of the same engraving never counts and only measures rig repeatability.

## Acceptance Criteria

- [ ] Each proposed plate lists the parameter sets to engrave and the reason for each (gap, high uncertainty, instability, or target color).
- [ ] Marking a color 'unreachable' in artwork conversion creates a target color visible to the Experiment Designer without extra user action.
- [ ] A proposed plate that addresses a target color references that color so the result can be checked against it after measurement.
- [ ] With the same database state, the algorithmic core proposes the same plate (deterministic given a fixed seed).
- [ ] With no LLM configured, proposals are generated identically and the explanation section is simply absent.
- [ ] LLM output is stored as text attached to the proposal and cannot change proposed parameter sets or observations.
- [ ] The system accepts a LightBurn file (.lbrn or .lbrn2) together with a rig photograph of the finished engraving through a universal ingestion workflow covering system-generated calibration plates, finished engravings and imported works.
- [ ] The system reconstructs an EngravingPlan from the imported file's layer parameters (power, frequency, and speed) and fill geometry.
- [ ] The imported photograph supports manual alignment by image corners as specified in DEC-010.
- [ ] Each imported layer region yields observations stored in the experiment database without assigning a 'legacy/uncontrolled' tier.
- [ ] Imported observations inform both the color-space model and the Experiment Designer.
- [ ] Observations from system-generated calibration plates, finished engravings and imported works are assessed under the same observation-quality and repetition-independence criteria for eligibility as validation repetitions.
- [ ] Whether the system created the work does not affect eligibility for validation repetitions.
- [ ] No source-specific restriction or exclusion prevents imported observations from counting toward validation repetition thresholds.
- [ ] Shared observation-quality and repetition-independence criteria are defined separately before automatic validation is implemented; DEC-016 does not establish specific thresholds.
- [ ] The specification explicitly marks DEC-012 as superseded by DEC-015 and removes the proposed 'legacy/uncontrolled' weighting rule and its pending-confirmation status.
- [ ] A validation repetition is a separate physical engraving, on a new piece or a new area of the same sheet (DEC-021); a re-photograph of the same engraving is never counted as a repetition and only feeds rig repeatability.
