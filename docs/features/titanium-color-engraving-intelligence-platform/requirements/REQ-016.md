## Statement

Every observation shall preserve the paired source files, selected laser device, physical engraving identity, historical lens context and engraving parameters with their provenance. File-recorded parameters shall be authoritative; absent required job settings shall be recorded as unknown or explicitly supplied, never inferred from a laser profile. Material profile, batch/sheet ID, focus, date and notes shall remain optional explanatory context. Unknown context shall be visible, and stability analysis shall attribute deviations only to supplied evidence. Shared quality and independent-engraving rules shall apply regardless of artefact source.

## Acceptance Criteria

- [x] Each observation identifies the physical laser device, physical engraving and complete available parameter vector; a laser profile is not required.
- [x] Values read from LightBurn are distinguished from settings explicitly supplied by the operator; unknown values are never replaced silently by 200 ns or another default.
- [x] Linked jobs retain their historical lens context. For imported works, the currently installed lens is not automatically asserted to be the lens used for the engraving.
- [x] Material profile, batch/sheet ID, focus, date and notes remain optional, default to unknown and offer explicit 'same as previous' entry.
- [x] Missing optional batch or focus metadata does not by itself reduce repetition eligibility.
- [x] Stability reports group by known context and explain when unknown batch or focus prevents attribution of deviations.
- [x] Parameter discrepancies and operator confirmations remain attached to the accepted observation.
