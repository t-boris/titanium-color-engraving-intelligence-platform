## Statement

Every observation shall originate from a LightBurn project file paired with a photograph taken on the fixed rig with the reference chart. It shall record the selected laser profile and laser parameters (power, frequency and speed) sourced authoritatively from that file's layers in all cases, including calibration plates. For calibration plates, the experiment identifier shall link the system-generated file and its layers to the plate definition, which shall be retained for experiment identity and geometry linkage. The system shall compare power, frequency and speed from the paired LightBurn file layers with the corresponding parameters in the linked plate definition. If those parameters differ, observation acceptance shall be blocked until the operator corrects the pair so that the mismatch is resolved or explicitly confirms that the attached LightBurn file was used for the physical engraving. After such confirmation, the LightBurn file shall remain authoritative for the observation's power, frequency and speed. Each detected discrepancy and any such operator confirmation shall be recorded with the observation. For artwork and photo engravings, parameters shall be extracted from the imported file. Laser profile is the only mandatory context. Material profile/sheet ID, focus, date and notes are optional and default to 'unknown', with one-tap 'same as previous' defaults offered. LightBurn .lbrn/.lbrn2 files do not record focus, material batch or laser profile constants. Stability and reproducibility analysis shall use available context as explanatory variables, group repeats by material/sheet and focus when known, explicitly label unknown context and state when a deviation cannot be attributed because context is unknown. All artefact sources shall use the same observation path without a separate 'legacy/uncontrolled' tier. Photographs with no detectable reference chart shall be flagged and excluded from model updates. Observations from system-generated calibration plates, finished engravings and imported works shall be assessed against the same observation-quality criteria for model-update eligibility and the same observation-quality and repetition-independence criteria for validation-repetition eligibility. Observations that satisfy the shared observation-quality criteria shall enter the color-space model and feed the AI Experiment Designer. Observations that also satisfy the shared repetition-independence criteria shall count toward repetition thresholds for automatic promotion to 'validated' on equal footing. Whether the system created the work shall not determine eligibility for validation repetitions. Reference-chart detection is necessary for model updates but does not by itself establish eligibility for validation repetitions. Shared observation-quality criteria, repetition-independence criteria and repetition thresholds shall be defined separately before implementing automatic validation; this requirement establishes no specific thresholds. Independence of a validation repetition is defined by DEC-021: each separate physical engraving counts as one independent repetition, whether on a new piece or a new area of the same sheet, with the sheet link kept as context; a re-photograph of the same engraving never counts and only measures rig repeatability.

## Acceptance Criteria

- [ ] Every observation originates from a LightBurn project file (.lbrn or .lbrn2) paired with a photograph taken on the fixed rig with the reference chart, whether the artefact is a system-generated calibration plate, finished artwork or photo engraving, or imported work.
- [ ] An observation can be saved with only the laser profile selected as mandatory context; material profile/sheet ID, focus, date and notes are optional and default to 'unknown'.
- [ ] Every observation, including calibration-plate observations, records power, frequency and speed sourced authoritatively from the paired LightBurn file layers; manually typed parameters are not stored when a LightBurn file is available.
- [ ] For calibration plates, the experiment identifier links the system-generated LightBurn file and its layers to the plate definition, which is retained for experiment identity and geometry linkage.
- [ ] For calibration plates, the system compares power, frequency and speed from the paired LightBurn file layers with the corresponding parameters in the linked plate definition.
- [ ] If any compared calibration-plate parameter differs, observation acceptance is blocked until the operator corrects the pair so that the mismatch is resolved or explicitly confirms that the attached LightBurn file was used for the physical engraving.
- [ ] When the operator confirms use of a mismatching LightBurn file, the accepted observation records power, frequency and speed from that file rather than from the plate definition.
- [ ] Each detected calibration-plate parameter discrepancy and any operator confirmation that the attached LightBurn file was used for the physical engraving are recorded with the observation.
- [ ] For artwork and photo engravings, parameters are extracted from the imported LightBurn file layers.
- [ ] Optional context fields offer 'same as previous' values that can be applied with one tap.
- [ ] Focus, material batch and laser profile constants are not treated as metadata recorded in .lbrn or .lbrn2 files.
- [ ] Stability and reproducibility reports use available context fields as explanatory variables.
- [ ] Stability and reproducibility reports group repeats by material/sheet and focus when known and explicitly label groups with unknown context.
- [ ] When unknown context prevents attribution of a deviation, the stability or reproducibility report explicitly states that limitation.
- [ ] Photographs with no detectable reference chart are flagged and their observations are excluded from model updates, regardless of artefact source.
- [ ] Observations from system-generated calibration plates, finished engravings and imported works are assessed against the same observation-quality criteria for model-update eligibility.
- [ ] Observations that satisfy the shared observation-quality criteria enter the color-space model and feed the AI Experiment Designer, regardless of artefact source.
- [ ] Observations from system-generated calibration plates, finished engravings and imported works are assessed against the same observation-quality and repetition-independence criteria for validation-repetition eligibility.
- [ ] Observations that satisfy the shared observation-quality and repetition-independence criteria count toward repetition thresholds for automatic promotion to 'validated' on equal footing, regardless of whether the system created the work.
- [ ] Observations are not assigned a separate 'legacy/uncontrolled' provenance tier or excluded from validation repetitions because of their artefact source.
- [ ] Reference-chart detection is a necessary condition for model updates but does not by itself establish eligibility for validation repetitions.
- [ ] Shared observation-quality criteria, repetition-independence criteria and repetition thresholds are specified separately before automatic validation is implemented; this requirement establishes no specific thresholds.
- [ ] A validation repetition is a separate physical engraving, on a new piece or a new area of the same sheet (DEC-021); a re-photograph of the same engraving is never counted as a repetition and only feeds rig repeatability.
