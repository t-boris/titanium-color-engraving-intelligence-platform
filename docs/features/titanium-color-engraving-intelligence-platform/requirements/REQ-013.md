## Statement

An EngravingPlan may optionally include registration markers and a machine-readable plan identifier placed outside the image area. When a photograph of a completed engraving is submitted, the system shall align it automatically via the registration markers if the plan includes them, or let the user align it manually by placing the image corners in the UI otherwise; in both cases the system measures deviations from the plan, estimates reproducibility and feeds the observation into the knowledge pipeline.

## Acceptance Criteria

- [ ] The plan editor offers a 'registration markers' option; when enabled, markers and plan ID are part of the exported plan outside the image area
- [ ] A photo of a marked engraving is aligned automatically with no manual input
- [ ] A photo of an unmarked engraving can be aligned by manually placing four image corners in the UI
- [ ] Observations from both paths are stored with the alignment method and enter the maturation pipeline like plate measurements
