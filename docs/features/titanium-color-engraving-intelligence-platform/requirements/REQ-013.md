## Statement

An EngravingPlan may optionally include registration markers and a machine-readable plan identifier placed outside the image area. Every observation of a completed engraving, including an imported work, shall originate from a LightBurn project file (.lbrn or .lbrn2) paired with a photograph taken on the fixed rig with the reference chart; engraving parameters shall be obtained from the LightBurn file. The system shall align the photograph automatically via registration markers if the plan includes them, or let the user align it manually by placing the four image corners in the UI otherwise. Observations from both paths shall be stored with the alignment method. Photographs with no detectable reference chart shall be flagged and excluded from model updates, regardless of their source. For observations that pass this gate, the system shall measure deviations from the plan, estimate reproducibility and feed the observation into the knowledge maturation pipeline. Continuous Photo Engraving analysis shall support both sub-modes of the single transfer-function pipeline, with their respective calibration and evaluation strategies: Tonal maps luminance to a monotonic parameter curve and is evaluated by brightness and contrast; Color-path maps luminance to a user-chosen trajectory in titanium color space and is evaluated by ΔE along that path. Artwork and photo-engraving observations, including observations of imported works, that pass the reference-chart detection gate shall enter the experiment database and inform the color-space model and AI Experiment Designer. Observations from system-generated calibration plates, finished engravings and imported works shall be assessed under the same observation-quality and repetition-independence criteria to determine eligibility for validation repetitions. Whether the system created the work shall not determine eligibility. Passing the reference-chart detection gate alone shall not establish eligibility for validation repetitions. Eligible artwork and photo-engraving observations, including observations of imported works, shall count toward repetition thresholds for automatic promotion to 'validated' on equal footing with calibration-plate cells. Shared observation-quality criteria, repetition-independence criteria and applicable thresholds shall be defined separately before automatic validation is implemented; this requirement does not establish specific thresholds. No separate 'legacy/uncontrolled' provenance tier or source-specific validation-repetition exclusion shall apply to imported production engravings. Independence of a validation repetition is defined by DEC-021: each separate physical engraving counts as one independent repetition, whether on a new piece or a new area of the same sheet, with the sheet link kept as context; a re-photograph of the same engraving never counts and only measures rig repeatability.

## Acceptance Criteria

- [ ] The plan editor offers a 'registration markers' option; when enabled, registration markers and a machine-readable plan identifier are included in the exported LightBurn project outside the image area.
- [ ] Every submitted production-engraving observation, including an observation of an imported work, includes a LightBurn project file (.lbrn or .lbrn2) and a photograph taken on the fixed rig with the reference chart.
- [ ] The system obtains engraving parameters from the submitted LightBurn file for every observation.
- [ ] A photograph of a marked engraving is aligned automatically via its registration markers with no manual input.
- [ ] A photograph of an unmarked engraving can be aligned by manually placing four image corners in the UI.
- [ ] Observations from both alignment paths are stored with their alignment method.
- [ ] A photograph with no detectable reference chart is flagged and excluded from model updates, regardless of its source or alignment method.
- [ ] For observations that pass the reference-chart detection gate, the system measures deviations from the plan and estimates reproducibility.
- [ ] Post-engraving analysis of Continuous Photo Engraving supports the Tonal sub-mode, evaluating brightness and contrast against the calibrated luminance-to-monotonic-parameter curve.
- [ ] Post-engraving analysis of Continuous Photo Engraving supports the Color-path sub-mode, evaluating ΔE against the calibrated luminance-to-user-chosen-color-space trajectory.
- [ ] Artwork and photo-engraving observations, including observations of imported works, that pass the reference-chart detection gate enter the experiment database and knowledge maturation pipeline and inform the color-space model and AI Experiment Designer.
- [ ] The system assesses observations from system-generated calibration plates, finished engravings and imported works under the same observation-quality and repetition-independence criteria when determining eligibility for validation repetitions.
- [ ] Whether the system created the work does not determine its observation's eligibility for validation repetitions.
- [ ] Passing the reference-chart detection gate alone does not establish eligibility for validation repetitions.
- [ ] Artwork and photo-engraving observations, including observations of imported works, that satisfy the shared observation-quality and repetition-independence criteria count toward repetition thresholds for automatic promotion to 'validated' on equal footing with calibration-plate cells.
- [ ] Shared observation-quality criteria, repetition-independence criteria and applicable thresholds are defined separately before automatic validation is implemented; this requirement establishes no specific thresholds.
- [ ] The system does not assign a separate 'legacy/uncontrolled' provenance tier to imported production engravings or exclude their observations from validation repetitions solely because they were imported.
- [ ] A validation repetition is a separate physical engraving, on a new piece or a new area of the same sheet (DEC-021); a re-photograph of the same engraving is never counted as a repetition and only feeds rig repeatability.
