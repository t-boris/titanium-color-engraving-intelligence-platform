## Statement

Every generated calibration plate shall include registration markers and a machine-readable experiment identifier engraved together with the parameter grid, so that computer vision can recover the plate geometry from a photograph and map each photographed cell to its exact parameter set (e.g. Power X / Frequency Y). Calibration plates shall be a special case of the universal observation input: a system-generated LightBurn project file paired with a photograph taken on the fixed rig with the reference chart. Parameters shall be sourced from the paired LightBurn project file, which shall be authoritative for power, frequency and speed. The linked plate definition shall be retained for experiment identity and geometry linkage. The system shall compare power, frequency and speed from the paired LightBurn file with those in the linked plate definition. If any of these parameters differ, observation acceptance shall be blocked until the operator corrects the pair or explicitly confirms that the attached LightBurn file was used for the physical engraving. The discrepancy and any such operator confirmation shall be recorded with the observation. Photographs without a detectable reference chart shall be flagged and excluded from model updates. Calibration-plate observations shall use the universal observation ingestion and knowledge-maturation rules, without a separate legacy or uncontrolled provenance tier. Observations from system-generated calibration plates, finished engravings and imported works shall be assessed under the same observation-quality and repetition-independence criteria. Whether the system created the work shall not determine eligibility for validation repetitions. Shared observation-quality and repetition-independence criteria shall be defined separately before implementing automatic validation; this requirement does not establish specific thresholds. Independence of a validation repetition is defined by DEC-021: each separate physical engraving counts as one independent repetition, whether on a new piece or a new area of the same sheet, with the sheet link kept as context; a re-photograph of the same engraving never counts and only measures rig repeatability.

## Acceptance Criteria

- [x] A calibration plate cannot be generated without registration markers and a machine-readable experiment identifier engraved together with the parameter grid.
- [x] Every calibration-plate observation originates from a pair consisting of the system-generated LightBurn project file and a photograph taken on the fixed rig with the reference chart.
- [x] From a photograph of a plate, the system detects the markers, rectifies the geometry and reads the identifier without manual input in the nominal case.
- [x] Each detected cell is linked to its exact parameter set sourced from the paired LightBurn project file and stored for that plate in the experiment database.
- [x] For every calibration-plate observation, power, frequency and speed are sourced from the paired LightBurn file as the authoritative source.
- [x] The linked plate definition is retained for experiment identity and geometry linkage.
- [x] The system compares power, frequency and speed from the paired LightBurn file with those in the linked plate definition.
- [x] If any compared parameter differs, observation acceptance is blocked until the operator corrects the pair or explicitly confirms that the attached LightBurn file was used for the physical engraving.
- [x] Each detected parameter discrepancy and any operator confirmation that the attached LightBurn file was used for engraving are recorded with the observation.
- [x] If markers or the experiment identifier cannot be detected, the system reports the failure and does not guess the mapping.
- [x] If the reference chart cannot be detected, the photograph is flagged as failing the rig check and excluded from model updates.
- [x] Calibration-plate observations use the universal LightBurn-file-and-rig-photograph ingestion workflow without a separate legacy or uncontrolled provenance tier.
- [x] Observations from system-generated calibration plates, finished engravings and imported works are assessed under the same observation-quality and repetition-independence criteria; whether the system created the work does not determine eligibility for validation repetitions.
- [x] Eligible calibration-plate observations enter the color-space model, feed the Experiment Designer and count toward repetition thresholds for automatic promotion to validated on equal footing with eligible observations from finished engravings and imported works.
- [x] Shared observation-quality and repetition-independence criteria shall be defined before automatic validation is implemented; this requirement establishes no specific thresholds.
- [x] A validation repetition is a separate physical engraving, on a new piece or a new area of the same sheet (DEC-021); a re-photograph of the same engraving is never counted as a repetition and only feeds rig repeatability.
