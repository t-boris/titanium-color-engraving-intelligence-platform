## Statement

Every generated calibration plate shall include registration markers and a machine-readable experiment identifier engraved together with the parameter grid, so that computer vision can recover the plate geometry from a photograph and map each photographed cell to its exact parameter set (e.g. Power X / Frequency Y).

## Acceptance Criteria

- [ ] A plate cannot be generated without registration markers and an experiment identifier.
- [ ] From a photograph of a plate, the system detects the markers, rectifies the geometry and reads the identifier without manual input in the nominal case.
- [ ] Each detected cell is linked to the parameter set stored for that plate in the experiment database.
- [ ] If markers or identifier cannot be detected, the system reports the failure and does not guess the mapping.
