## Statement

The system shall describe every image layer of a LightBurn file (engraving mode, kind, resolution, dot width and correction, cleanup pass, passes, picture processing) and, for a photographed work, report how the grey levels of the embedded picture came out as lightness on the metal.

## Acceptance Criteria

- [x] The mode, dpi, dot width, dot correction, cleanup pass, number of passes and sub-layer count of an image layer are read from the file; 3dslice is a depth engraving, every other mode is tonal
- [x] The picture of an image object is read from the file; objects that share a picture use the stored one
- [x] For an aligned photograph the lightness is reported per grey level of the picture with the rank correlation, the range and an evidence strength (clear or weak)
- [x] The edge of the picture that is up is chosen by the better positive agreement and reported
- [ ] A picture that is not stored or too few visible pixels give no profile, never an invented one
- [x] The single median colour of an image layer is still measured; the profile is stated to use the grey levels as stored, before brightness, contrast and gamma, without modelling dithering
