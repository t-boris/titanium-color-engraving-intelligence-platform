## Statement

The system shall derive from a laser device's passport, test report, pulse waveforms and laser settings a characterization of what that laser is (effective power, usable repetition-rate range, work field, selectable pulse widths, maximum pulse energy, measured wavelength and peak power), show for every item whether the calculations use it, and use the items that are marked as used when it computes operating points and checks plates.

## Acceptance Criteria

- [ ] The characterization is computed from the stored data on every read and is never stored, so changing a value changes it at once.
- [ ] The effective average power is the unit's measured power from its test report when that value lies within 0.5 to 1.5 times the rated power; otherwise the rated power, and the basis (measured or rated) is shown.
- [ ] The effective repetition-rate range is the laser's range narrowed by the controller's Min and Max PWM when those values are printed or confirmed; a handwritten, unconfirmed value is listed as waiting and is not used.
- [ ] The work field is taken from Field Size, or from Size Width and Size Height, only when the value is printed or confirmed; a plate whose size with its markers exceeds the field is refused with the sizes in the message.
- [ ] A frequency outside the controller range is reported as a warning with the operating point; a frequency outside the laser's own range is reported as a problem.
- [ ] The pulse energy of an operating point does not exceed the passport maximum pulse energy.
- [ ] Each item of the characterization states whether it is used in calculations, waits for confirmation, or is reference only.
- [ ] The display title of a device shows its model and its current serial number; the name holds no serial number.
