## Statement

The system shall show the version of the running application in the header of every screen, as the server reports it at GET /api/version.

## Acceptance Criteria

- [ ] The header shows v<version> next to the title, with a hint "Версия приложения"; the version is the one the server reports.
- [ ] The page asks the server for the version once and every later screen takes it from memory.
- [ ] When the server does not answer, no version and no error are shown and the header keeps its height.
- [ ] The label does not move the header on a narrow screen.
