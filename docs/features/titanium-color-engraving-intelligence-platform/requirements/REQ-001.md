## Statement

The system shall implement the loop experiment → engraving → photograph → measurement → comparison → model update → next experiment. Every observation, from a calibration plate, finished artwork, photo engraving or imported work, shall originate from a LightBurn project file paired with a photograph taken on the fixed rig with the reference chart; parameters, including power, frequency and speed, shall be sourced from the paired LightBurn file. Calibration plates shall be a special case of this universal ingestion path, using system-generated files with registration markers and an experiment identifier. For calibration plates, the paired LightBurn file shall be authoritative for power, frequency and speed; the linked plate definition shall be retained for experiment identity and geometry linkage. Before accepting a calibration-plate observation, the system shall compare those parameters with the linked plate definition. If they differ, observation acceptance shall be blocked until the operator corrects the pair to resolve the mismatch or explicitly confirms that the attached LightBurn file was used for the physical engraving. The discrepancy and any such confirmation shall be recorded with the observation. Photographs without a detectable reference chart shall be flagged and excluded from model updates regardless of their source; reference-chart detection, rather than provenance, shall gate model updates, with no separate legacy or uncontrolled tier. Accepted observations that pass the rig check shall enter the color-space model and feed the AI Experiment Designer. Observations from system-generated calibration plates, finished engravings and imported works shall be assessed under the same observation-quality and repetition-independence criteria for validation-repetition eligibility. Whether the system created the work shall not determine eligibility. Eligible artwork, photo engraving and imported-work observations shall count toward repetition thresholds for automatic promotion to validated on equal footing with eligible calibration plate cells. Shared observation-quality and repetition-independence criteria shall be defined separately before implementing automatic validation; no specific thresholds are established by this requirement. Physical measurements and experimental observations are the source of truth; AI predictions shall never silently overwrite measured data. Post-engraving analysis shall align the photograph with the original engraving plan, measure deviations, estimate reproducibility and detect unstable parameter regions. Continuous Photo Engraving shall support Tonal and Color-path as sub-modes of one pipeline through one transfer-function abstraction with two calibration and evaluation strategies: Tonal maps luminance to a monotonic parameter curve and is judged by brightness and contrast; Color-path maps luminance to a user-chosen trajectory in titanium color space and is judged by ΔE along the path. Post-engraving analysis shall support both comparison metrics. Independence of a validation repetition is defined by DEC-021: each separate physical engraving counts as one independent repetition, whether on a new piece or a new area of the same sheet, with the sheet link kept as context; a re-photograph of the same engraving never counts and only measures rig repeatability.

An operator may remove an uploaded pair from active use. Removal excludes its observations from model learning and reports, deletes the application's uploaded file copies, and keeps the immutable observation records as an audit archive.

## Acceptance Criteria

- [x] Every observation, whether from a system-generated calibration plate, finished artwork, photo engraving or imported work, originates from a LightBurn project file paired with a photograph taken on the fixed rig with the reference chart; engraving parameters, including power, frequency and speed, are sourced from that LightBurn file.
- [x] System-generated calibration plate LightBurn files include registration markers and an experiment identifier and are ingested through the same observation pipeline as finished artwork, photo engraving and imported work files.
- [x] For calibration plates, the linked plate definition is retained for experiment identity and geometry linkage; the paired LightBurn file is authoritative for power, frequency and speed.
- [x] Before accepting a calibration-plate observation, the system compares power, frequency and speed in the paired LightBurn file with those in the linked plate definition.
- [x] If any compared parameter differs, observation acceptance is blocked until the operator corrects the pair to resolve the mismatch or explicitly confirms that the attached LightBurn file was used for the physical engraving.
- [x] Every detected calibration-plate parameter discrepancy and any operator confirmation that the attached LightBurn file was used for engraving are recorded with the observation.
- [x] Photographs without a detectable reference chart are flagged as failing the rig check and excluded from model updates, regardless of their source.
- [x] Accepted observations that pass the rig check enter the color-space model and feed the AI Experiment Designer without a separate legacy or uncontrolled provenance tier.
- [x] Observations from system-generated calibration plates, finished engravings and imported works are assessed for validation-repetition eligibility using the same observation-quality and repetition-independence criteria.
- [x] Whether the system created a work does not determine its eligibility for validation repetitions.
- [x] Observations from artworks, photo engravings and imported works that meet the shared observation-quality and repetition-independence criteria count toward repetition thresholds for automatic promotion to validated on equal footing with eligible calibration plate cells.
- [x] Shared observation-quality and repetition-independence criteria, including the thresholds required for automatic validation, are explicitly defined before automatic validation is implemented.
- [x] Every measured color record is immutable once stored; model-derived values are stored separately and reference the measurements they were derived from.
- [x] Any attempt by a model update to change a measured value is rejected and logged.
- [x] An operator can remove an input pair from active experiments and learning. The pair is tombstoned, its uploaded file copies are deleted, and its immutable measurements remain in audit history but are excluded from maps, reports and recommendations.
- [x] An operator can remove a plan from active experiments after all linked input pairs are removed. The plan and plate remain archived when a deleted pair still references them, preserving the pair's historical measurement context.
- [x] For a photographed engraving, the system aligns the photograph with the original engraving plan and produces a deviation report per cell or region, comparing measured results with planned results, and a reproducibility estimate.
- [x] Continuous Photo Engraving supports Tonal and Color-path sub-modes through one pipeline and one transfer-function abstraction, with separate calibration and evaluation strategies.
- [x] In Tonal mode, luminance maps to a monotonic parameter curve; calibration, evaluation and post-engraving comparison assess brightness and contrast.
- [x] In Color-path mode, luminance maps to a user-chosen trajectory in titanium color space; calibration, evaluation and post-engraving comparison assess ΔE along that trajectory.
- [x] Parameter regions whose repeated measurements exceed a configurable variance threshold are flagged as unstable.
- [x] A validation repetition is a separate physical engraving, on a new piece or a new area of the same sheet (DEC-021); a re-photograph of the same engraving is never counted as a repetition and only feeds rig repeatability.
