## Statement

The system shall implement the loop experiment → engraving → photograph → measurement → comparison → model update → next experiment. Physical measurements and experimental observations are the source of truth; AI predictions shall never silently overwrite measured data. Post-engraving analysis shall align the photograph with the original engraving plan, measure deviations, estimate reproducibility and detect unstable parameter regions.

## Acceptance Criteria

- [ ] Every measured color record is immutable once stored; model-derived values are stored separately and reference the measurements they were derived from.
- [ ] Any attempt by a model update to change a measured value is rejected and logged.
- [ ] For a photographed engraving, the system produces a deviation report per cell/region (measured vs. planned color) and a reproducibility estimate.
- [ ] Parameter regions whose repeated measurements exceed a configurable variance threshold are flagged as unstable.
