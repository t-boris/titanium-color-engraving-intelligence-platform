## Summary

LightBurn's Material Test is the right model for controlled two-variable experiments: choose two axes and keep every other material setting fixed. Because the product needs a ready `.lbrn2` with the user's mandatory clean-first operation, registration and experiment provenance, the application generates an equivalent matrix itself and exports the whole job as a standard LightBurn project. Vector line tests remain separate from filled swatches so line continuity and trace width are measured from actual vector paths.
