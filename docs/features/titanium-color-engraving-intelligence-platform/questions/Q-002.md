## Question

Что первая версия должна уметь «от начала до конца», чтобы считаться готовой?

## Why it matters

16 доменов — это весь проект; без явного минимума нельзя написать критерии приёмки первой версии.

## Options

- **A**: Только калибровочный цикл: плата с маркерами → фото → CV-привязка → измерения → база → карта цветов с confidence. Без гравировки артов/фото.
- **B**: Калибровочный цикл + Discrete Color Engraving + экспорт в LightBurn.
- **C**: Калибровочный цикл + оба режима гравировки + Experiment Designer (всё заявленное).

## Recommended

B — Даёт замкнутый цикл и осязаемый результат, оставляя фото-режим и Designer на вторую итерацию.

## Answer

C. Калибровочный цикл + оба режима гравировки + Experiment Designer (всё заявленное).
