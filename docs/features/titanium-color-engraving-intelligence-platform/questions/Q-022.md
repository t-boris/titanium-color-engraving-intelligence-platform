## Question

Is the laser profile (pulse width, line interval, passes) needed as a separate record, or should these three values belong to each engraving and plate, with the laser device carrying only the equipment facts?

## Why it matters

DEC-005 and REQ-010 keep pulse width, line interval and passes as constants of a versioned laser profile, so that measurements are never merged across different conditions. The operator observes that these values belong to the artwork or engraving, not to the machine, and that the profile adds a record to maintain. Both views are partly right: the values do change the colour, so they must travel with every measurement, but they need not be a separate entity the operator creates first.

## Options

- **A**: Keep the profile as it is (a version-controlled set of constants chosen once per series of plates).
- **B**: Remove the profile as a screen: pulse width, line interval and passes become fields of each plate and of each engraving plan, with the laser device chosen there; measurements still store all three values, and 'same conditions' is decided by equality of the values.
- **C**: Keep the profile only as an optional saved preset (a name for a combination of the three values) that fills the plate form.

## Recommended

B
