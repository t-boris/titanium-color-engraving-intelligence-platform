## Question

Какие контекстные поля обязательны при записи наблюдения (ячейки платы или области гравировки), чтобы анализ стабильности мог объяснять расхождения?

## Why it matters

Влияет на модель данных и на UI ввода: без партии материала и фокуса анализ стабильности не отличит нестабильность цвета от смены условий; вопрос поднят в обсуждении, но ответа нет.

## Options

- **A**: Для стендовых плат обязательны: профиль лазера, профиль материала с идентификатором листа/партии, значение фокуса; опционально дата, температура, примечание. Для legacy-импорта обязателен только профиль лазера, остальное — «неизвестно».
- **B**: Везде обязателен только профиль лазера; материал, партия и фокус — опциональные метаданные.
- **C**: Все перечисленные поля обязательны всегда, включая legacy-импорт (с явным выбором «неизвестно» как значения).

## Recommended

A — Даёт анализу стабильности нужные объясняющие переменные там, где они реально известны, и не блокирует импорт исторических работ.

## Answer

Honestly if I provide import/export Lightbirn files - it has all parameters, For photos of matrixes all parameters are described on the plate
