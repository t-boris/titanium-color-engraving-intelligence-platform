## Question

Подтвердите правило веса для legacy-наблюдений (импорт LightBurn + фото без стенда): должны ли они засчитываться в повторы для автопродвижения до «validated»?

## Why it matters

DEC-012 записано с оговоркой «pending user confirmation»; от ответа зависит, может ли цвет стать validated только по архивным работам без единой стендовой платы.

## Options

- **A**: Не засчитываются: legacy-наблюдения видны в карте цветов и у Experiment Designer, но до «validated» цвет доводят только стендовые платы.
- **B**: Засчитываются с пониженным весом (например, 0.5 повтора), порог validated достигается быстрее при совпадении с хотя бы одной стендовой платой.
- **C**: Засчитываются наравне со стендовыми.

## Recommended

A — Соответствует DEC-012 и принципу источника истины; archive всё равно питает модель и Designer.
