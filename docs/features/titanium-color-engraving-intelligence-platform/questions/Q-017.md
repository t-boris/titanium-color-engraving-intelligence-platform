## Question

Real .lbrn2 layers record pulse width (`QPulseWidth`) and line interval (`interval`). How should the importer use them, given REQ-010 says profile constants come from the linked laser profile version and REQ-015 says a layer with a different pulse width is imported with a warning?

## Why it matters

It decides whether a layer engraved with different constants can contaminate the color data of the active laser profile version.

## Options

- **A**: Read them from the layer, compare with the profile constants, import mismatches with a warning as 'not comparable'.
- **B**: Ignore them and always trust the profile constants.
- **C**: Treat them as additional variable axes.

## Recommended

A — Keeps DEC-005 and REQ-010 intact and implements the REQ-015 'not comparable' rule without silently merging data.

## Answer

A. Read pulse width and line interval from each layer when the file has them. Compare them with the linked profile's constants. If they differ, import the layer with a warning and mark it 'not comparable'. It never enters the model or the repetition counts. The stored parameter vector still takes its constants from the profile version. Focus, material batch and passes stay unknown, because the file doesn't record them.
