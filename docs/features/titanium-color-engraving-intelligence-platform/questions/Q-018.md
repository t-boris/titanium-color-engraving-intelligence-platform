## Question

Which physical color reference chart is in the frame of every rig photograph? DEC-003 and REQ-009 require a color reference chart in every frame but do not say which one.

## Why it matters

Chart detection and chart-based color correction (REQ-009, plan I-4) need the chart's layout and published reference values. Without them the system cannot decide whether a photograph passes the rig check.

## Options

- **A**: A standard 24-patch ColorChecker Classic.
- **B**: A standard ColorChecker plus ArUco markers fixed to the rig.
- **C**: A custom chart generated by the system.
- **D**: A different chart.

## Recommended

B — Locating the chart by markers is more robust than detecting the patch grid alone.

## Answer

A. A standard 24-patch ColorChecker Classic (X-Rite or Calibrite). Use its published patch values and detect it with OpenCV's detector, verified on real photos.
