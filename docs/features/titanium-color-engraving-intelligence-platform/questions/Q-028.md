## Question

Should the four corners the operator places be fitted to the whole file (all layers, including those whose output is off) instead of only the layers that are measured?

## Why it matters

In pair 105 only the seal layer is on, and the manual corners the operator put around the whole diploma were fitted to the 25 x 23 mm seal, so the frame did not fit (the bug that led to REQ-055). The automatic route now finds this work, but the manual route would repeat it for any file whose output-off layers are on the plate. Fitting to all layers reverses part of REQ-050 for the manual route only: a layer that was never engraved would then make the work larger than the photograph shows.

## Options

- **A**: Keep fitting to the measured layers (today); the automatic ruler route covers pictures.
- **B**: Fit to all layers of the file; say in the warning when output-off layers were included.
- **C**: Ask the operator which layers the corners enclose, with all layers as the default.

## Recommended

C
