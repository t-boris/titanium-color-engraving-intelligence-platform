## Question

Какого рода приложение вы видите: где оно живёт и как с ним работают?

## Why it matters

Определяет общую архитектуру (локальное хранилище vs сервер, UI vs скрипты) — технологию не выбираем, только тип продукта.

## Options

- **A**: Локальное настольное приложение рядом с LightBurn: всё хранится на машине у лазера.
- **B**: Локально запускаемое веб-приложение (один процесс на ПК, интерфейс в браузере).
- **C**: Набор инструментов/ноутбуков без полноценного UI — только пайплайн и база.

## Recommended

B — Удобно снимать и загружать фото с планшета у стенда, при этом сохраняется локальность данных.

## Answer

B. Локально запускаемое веб-приложение (один процесс на ПК, интерфейс в браузере).
