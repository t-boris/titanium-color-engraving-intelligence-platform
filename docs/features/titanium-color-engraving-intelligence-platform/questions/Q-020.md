## Question

Which handwritten values on the controller parameter table are correct: the number written next to Max PWM (4000 against the printed 200 kHz), the galvo scale factors, the red-pointer size scales and the controller serial number?

## Why it matters

The photograph is slanted and the handwriting is ambiguous, so none of these values is stored as data. The galvo scales and the Max PWM value decide how a LightBurn job maps to the marking field and the pulse train.
