## Context

Continuous Photo Engraving could target either luminance fidelity or a controlled iridescent color trajectory; the two need different transfer-function calibration and different success metrics.

## Alternatives

1. Tonal mode only
2. Color-path mode only

## Decision

Both are supported as sub-modes of a single pipeline: Tonal (luminance → monotonic parameter curve, judged by brightness/contrast) and Color-path (luminance → user-chosen trajectory in titanium color space, judged by ΔE along the path).

## Reason

The user chose full scope; Tonal mode is the minimal path, Color-path is the unique value of titanium, and they share image processing, banding, export and post-analysis.

## Consequences

The specification must define one transfer-function abstraction with two calibration/evaluation strategies, and post-engraving analysis must support two comparison metrics. Larger first-version scope.
