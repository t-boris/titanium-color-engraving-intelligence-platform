## Context

Implementing task-conditioned knowledge (REQ-020) on 2026-10-18 required rules the specification does not state: when a plan's or layer's task counts as stated by the operator, how tasks of vector regions and service layers are set, and how a task enters the recipe key without changing the meaning of existing records (REQ-020 AC8).

## Alternatives

1. Add the task to every recipe key (re-keys every existing record)
2. Keep tasks only as a filter and never separate knowledge by task

## Decision

The task vocabulary lives in one table (text, line, fill, tonal image, colour image, plus mark, cleaning, deep, relief, cutting) with the metrics a photograph can and cannot support. A task is derived from the LightBurn layer (Line -> line, Fill and Offset Fill -> fill, Image -> tonal image with a non-grayscale mode noted, 3D slice included) unless stated: a layer's choice on the review screen, then the work's task at upload, then the plan's or plate cell's task. A plan's task counts as stated only when the operator chose it; the UI choosers always send their selection, so a discrete plan kept at 'colour image' is stated and its layers stay apart from calibration-plate fill knowledge (choosing 'fill' joins them). A recipe key gains the task only when it is stated and differs from the task the LightBurn mode implies, so every existing key stays exactly as it was. In vector jobs colour, fill and tonal regions count as fill while text and line keep their task; an output layer mixing tasks falls back to its mode and the mix is shown. Area conversions and the photo-engraving curve never use recipes kept apart as text or line. Cleaning, registration and label layers always keep the task of their role. The application-guide goal colour maps to fill and image to tonal image. Missing context travels as codes that the screen names in Russian.

## Reason

Unlike tasks are never summarised together (REQ-020 AC5) while 108 accepted observations of the live database keep their keys unchanged (tested).

## Consequences

Proposed for the operator's review.
