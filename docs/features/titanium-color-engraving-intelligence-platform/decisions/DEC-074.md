## Context

The operator asked that, after the regions are coloured with known titanium colours, every colour can be changed by hand and the whole work recoloured automatically, and that on a face the eyes and lips get the most attention. The installed OpenCV ships no face detector. The operator chose all four recolouring modes and automatic face detection plus manual marking.

## Alternatives

1. Manual marking of important areas only, no face model
2. Fewer recolouring modes

## Decision

The operator can change the titanium colour of any colour group or of any single region by hand. Automatic recolouring offers four modes, each giving a previewed variant that can be kept or undone: closest to the original (nearest measured colour by delta E); keep tonality (the lightness order of the original colours is kept, hues may change); random (seeded; another variant on request; earlier variants restorable); fewer layers (near colours merged so fewer recipes are used). Faces are found with OpenCV's YuNet face detector, a model file of about 0.3 MB under the Apache-2.0 licence shipped with the application (no new Python library), which gives the face box, the eyes and the mouth corners; eyes and lips get finer segmentation. The operator can also mark or remove important areas by hand.

## Reason

The operator chose these options on 2026-10-19.

## Consequences

The model file and its licence notice ship as package data; detection runs on the uploaded image only and stores nothing beyond the work record.
