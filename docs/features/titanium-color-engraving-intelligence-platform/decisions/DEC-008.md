## Context

LightBurn assigns power/frequency/speed per layer and varies only power per pixel via grayscale images (external fact to verify). Continuous plans need a representation LightBurn can consume.

## Alternatives

1. Power-only grayscale with fixed frequency/speed per layer
2. Hybrid: layers by frequency/speed with grayscale power inside each layer

## Decision

EngravingPlans are quantized into N bands; each band is exported as a separate LightBurn layer with its own power, frequency and speed. N is a plan parameter.

## Reason

Gives access to all three calibrated axes and uses the same export mechanism for discrete and continuous plans; banding granularity remains tunable.

## Consequences

Visible band boundaries at low N and large multi-layer files at high N; the EngravingPlan format must be band-oriented, and the model must predict a color per band rather than per pixel.
