## Context

DEC-003 and REQ-009 require a color reference chart in every rig frame but do not name it. Detection quality on the real rig is unverified.

## Alternatives

1. A ColorChecker plus ArUco markers fixed to the rig.
2. A custom chart generated by the system.
3. A different chart.

## Decision

The reference chart is a standard 24-patch ColorChecker Classic (X-Rite or Calibrite). The system uses its published patch values for chart-based color correction and detects it with OpenCV's ColorChecker detector. A photograph in which the detector finds no chart fails the rig check (REQ-009).

## Reason

The user chose this option. A standard chart with published values makes the correction a real calibration and needs no extra printed hardware.

## Consequences

OpenCV's detector (called with the number of charts, `process(image, 1)`) found the chart in OpenCV's two published test images and in 8 synthetic renders (plain, noisy, blurred, perspective-warped, two scales). It is not verified on a real rig photograph, which the agent does not have. Until the user supplies a real RAW sample, chart detection stays behind an interface and is marked unverified in the capture-setup record. The patch reference values, white point and observation conditions are an explicit configurable setting of the capture setup, because the requirements do not define them.
