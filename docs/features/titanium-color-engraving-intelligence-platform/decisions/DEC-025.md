## Context

DEC-003 and REQ-009 require a color reference chart in every rig frame but do not name it. A first OpenCV detection probe on synthetic images found no chart, so detection quality is unverified.

## Alternatives

1. A ColorChecker plus ArUco markers fixed to the rig.
2. A custom chart generated by the system.
3. A different chart.

## Decision

The reference chart is a standard 24-patch ColorChecker Classic (X-Rite or Calibrite). The system uses its published patch values for chart-based color correction and detects it with OpenCV's ColorChecker detector. A photograph in which the detector finds no chart fails the rig check (REQ-009).

## Reason

The user chose this option. A standard chart with published values makes the correction a real calibration and needs no extra printed hardware.

## Consequences

Detection quality is not yet verified on a real rig photograph: the agent has none, and a probe on synthetic images returned no detection. Until the user supplies a real RAW sample, chart detection stays behind an interface, is tested only with synthetic images, and is marked unverified. The patch reference values, white point and observation conditions are an explicit configurable setting of the capture setup, because the requirements do not define them.
