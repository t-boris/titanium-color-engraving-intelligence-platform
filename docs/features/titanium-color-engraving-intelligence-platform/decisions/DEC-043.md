## Context

The existing parameter-vector function defaults to 200 ns, and the device's stored pulse-width table includes that step. No supplied evidence establishes an optimal color-marking pulse width.

## Alternatives

1. Require manual pulse-width selection for every new plate.
2. Prefill 200 ns as an editable starting value.
3. Treat 200 ns as a fixed or experimentally optimal color-marking setting.

## Decision

Use 200 ns as an editable initial value for a new calibration plate when supported by the selected device. Do not treat it as a device fact, a profile constant or a validated optimum.

## Reason

This provides a concrete starting point without converting an untested choice into experimental knowledge.

## Consequences

New plate forms may start at 200 ns when the selected device supports it. Imported layers and saved jobs retain their own values. Color suitability remains an experimental result.
