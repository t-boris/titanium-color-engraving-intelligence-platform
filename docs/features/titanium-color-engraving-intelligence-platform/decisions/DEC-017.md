## Context

F-002 identifies a contradiction: REQ-010 sources calibration-plate parameters from the plate definition, while DEC-015 and REQ-015 require the paired LightBurn file as the universal parameter source. Editing the file after plate generation can produce conflicting parameter-to-color observations.

## Alternatives

1. Use the paired LightBurn file as the parameter source and only warn when it differs from the plate definition.
2. Use the plate definition for calibration-plate parameters and the LightBurn file for other engravings.

## Decision

For every observation, including calibration plates, source power, frequency and speed from the paired LightBurn file. If those parameters differ from the linked plate definition, block observation acceptance until the operator corrects the pair or explicitly confirms that the attached LightBurn file was used for the physical engraving.

## Reason

The team selected the LightBurn file as the authoritative parameter source, with mandatory discrepancy resolution to prevent silently associating measured colors with conflicting settings.

## Consequences

Update REQ-010 to source calibration-plate power, frequency and speed from the paired LightBurn file; retain the plate definition for experiment identity and geometry linkage. Add a mismatch check to REQ-015 that blocks observation acceptance until the pair is corrected or the operator explicitly confirms that the attached file was used for engraving. Record the discrepancy and confirmation with the observation. Align DEC-014 and REQ-016 with this rule.
