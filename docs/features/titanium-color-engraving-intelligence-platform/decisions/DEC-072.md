## Context

Closing the remaining gaps of the 2026-10-18 audit required choices the specification does not state: how a setting missing from a LightBurn layer is supplied and kept, where a measured spot lives, how a computed setting gets the three values of REQ-002, and a fix found while testing DEC-059.

## Alternatives

1. Infer a missing pulse width from the device default
2. Keep the measured spot on the laser passport

## Decision

A setting missing from a test-feature layer may be supplied by the operator on the review screen, validated against the laser (pulse width steps listed when refused, frequency range, positive values, whole passes), stored with the pair as supplied by the operator with its time (the application has no user identities), and carried into the observation with a per-setting provenance (file, operator or none); file values are never replaced and nothing is inferred. Replacing a pair's LightBurn file drops supplied values; a re-photograph keeps them; a matrix pair is corrected in its matrix instead. The measured spot diameter belongs to the lens record; an old passport value moves once to the lens installed on that laser (audited) and a passport carrying a spot value is refused. Capability plates are checked against the whole work field (lens and confirmed controller settings); an unknown field is labelled 'not checked'. A setting computed from a thickness law carries confidence = law r2 x n/(n+2) (n independent engravings behind the law), expected error = RMS delta E of the four nearest measured cells against the model, stability = total variance of those misses; without all three it is not offered, and no dose outside the measured span is computed. The chart orientation is decided by the most neutral row (the grey ramp), which also turns an outline found from the opposite corner.

## Reason

Every value the model uses keeps its source; nothing unmeasured is presented as a prediction (REQ-002, REQ-016).

## Consequences

Proposed for the operator's review. The chart orientation change alters the measurement path for charted photographs whose chart was found from the opposite corner.
