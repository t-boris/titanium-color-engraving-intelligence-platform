## Context

Need to know whether roles, multi-user data and sharing are required.

## Alternatives

1. Small workshop with operator/approver roles
2. Community platform sharing calibrations across lasers

## Decision

The first version serves one researcher/operator with one laser; no roles, no shared or community data.

## Reason

The closed loop must first be proven on one laser; roles and sharing can be added once the model shows value.

## Consequences

No authentication or permission model; data lives locally; the 'manual approval' for production is simply the user's own action.
