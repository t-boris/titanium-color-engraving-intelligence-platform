## Context

F-003 identified a contradiction: DEC-011 excludes questioned production knowledge from new plans by default, while REQ-005 applies that exclusion only to Discrete and Color-path plans. The team selected an explicit exception for Tonal.

## Alternatives

1. Exclude questioned production parameter sets by default in all engraving modes, allowing explicit inclusion only for a specific plan.
2. Allow Tonal plans to use questioned production parameter sets with a warning, while retaining default exclusion and explicit per-plan inclusion for Discrete and Color-path plans.

## Decision

Tonal plans may use questioned production parameter sets with a visible warning and access to the associated observations, without separate confirmation. Discrete and Color-path plans shall exclude those parameter sets by default and require explicit inclusion for a specific plan. The questioned flag and knowledge stage shall remain unchanged by plan generation.

## Reason

The team chose to preserve the available tonal range while accepting the risk of using unstable parameters. Warnings make that risk visible to the operator.

## Consequences

Amend DEC-011 and REQ-005 to state the Tonal exception explicitly. Tonal planning shall display a warning and the associated observations when questioned parameter sets are used, without requiring separate confirmation. Discrete and Color-path plans shall retain default exclusion and explicit per-plan inclusion. Add acceptance criteria covering these mode-specific behaviors. Resolve F-003 through this explicit exception.
