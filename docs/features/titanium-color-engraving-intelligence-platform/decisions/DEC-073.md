## Context

The operator asked (2026-10-19) that vector work turns a photograph into up to 30 colour regions, coloured with "the colours known to me". No knowledge entry is validated yet (all 343 are measured), so the validated/production rule of REQ-004 would leave nothing to colour with. LightBurn has 30 output layers (DEC-044). The operator chose: all measured colours; cleaning always first, so up to 29 colours.

## Alternatives

1. Only chart-corrected colours
2. Only validated or production colours as in REQ-004
3. Always 30 colours without cleaning; cleaning in a separate file

## Decision

The palette of a vector work is every measured colour of the colour map (REQ-029) of the work's laser, lens and titanium stock, each with its recipe; each colour shows how it was measured (chart, against clean titanium, as photographed), how many independent engravings gave it and its engraving time. This is an exception to the validated/production rule of REQ-004 for vector work only; discrete conversion keeps REQ-004. A vector work holds at most 29 colours, because the cleaning layer is always its first operation; with registration markers it holds 28. The operator chooses the number of colours within that limit.

## Reason

The operator chose it on 2026-10-19: the work must be colourable with the colours actually obtained so far, and every plate and work starts with cleaning.

## Consequences

A vector work may use recipes that are measured but not repeated; the screen says so per colour. Supersedes the 'one recipe per settings group, nearest validated entry' palette of DEC-067 for vector work.
