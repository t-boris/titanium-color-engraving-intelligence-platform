## Context

REQ-011 requires a single locally launched process on the user's PC. The repository has no deploy mechanism, and the only configured MarkView environments belong to another project.

## Alternatives

1. Docker image.
2. A packaged macOS application.

## Decision

A release is built with `python -m build` into a wheel. "Deploy" means installing that wheel into a dedicated virtual environment on this Mac, starting the single local process, and confirming that `GET /api/version` returns the new version. Data lives in a local data directory outside the repository.

## Reason

It is the smallest mechanism that satisfies REQ-011 without a container runtime and can be checked mechanically.

## Consequences

Proposed only. Needs the user's confirmation or a different mechanism.
