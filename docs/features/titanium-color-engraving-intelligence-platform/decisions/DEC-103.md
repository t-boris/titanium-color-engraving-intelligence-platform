## Context

The operator engraved the grey-ramp plate TCE-A93B49E6 (8 tiles: line interval 0.0127-0.0254 by pulse 250 / 350 ns) from the file as LightBurn 2.2 saved it. The photograph aligned by its markers, but three of the four 250 ns tiles were read as "0 pixels" and the four 350 ns tiles had no picture. Two causes. (1) LightBurn 2.2 stores a picture placed twice once: the second Bitmap of a row has Data="" and the first one's SourceHash, under its own file name (GREY-...-PW350.png); the reader filled a missing picture only from a Bitmap with the same file name. (2) LightBurn rewrote MirrorY and reflected every XForm; normalize_saved_orientation reflected the outlines back to the plan's axes but not the picture's own matrix nor the holes, so what a picture strikes was laid mirrored about the plate's centre (tile 8 at photo rows 1171-1283, its struck mask at 541-654) and missed its own tile. Earlier plates had no pictures, so this did not show before.

## Alternatives

1. Fill a missing picture from the shared lists when the file is parsed (a second mechanism beside the existing one by file name)
2. Ignore the picture of a reflected file and measure the whole rectangle of the tile (the plate's ramp is opaque everywhere, but a picture with transparent parts would be measured where nothing was engraved)

## Decision

The existing pass that gives a Bitmap without Data the picture stored with an earlier object looks it up by the same file name first (as before) and otherwise by the same SourceHash. normalize_saved_orientation reflects each shape's holes and each picture's matrix with its outline, so a picture stays on its shape in the plan's axes.

## Reason

Both are how LightBurn writes the file; the picture belongs to its shape, and whatever maps the shape must map the picture. Looking up by file name first keeps every earlier result unchanged: none of the 27 stored files has one name or hash with two different pictures, and only the plate's file has pictures stored once.

## Consequences

The plate's photo measures all 8 tiles, 16 of 16 steps each. Checks made before 0.18.1 keep their measurements; Перемерить заново measures the plate again with the alignment it was accepted with. Overlays do not change (they draw outlines, already reflected), so the render version stays.
