## Context

The user forbade auto-correcting production after one photo; a positive rule was needed.

## Alternatives

1. Fully manual promotion with system suggestions
2. Fully automatic promotion with log and rollback

## Decision

The system promotes knowledge automatically through measured → candidate → repeated → validated using a repetition threshold; 'production' requires explicit user approval.

## Reason

Statistics are the system's job; responsibility for production stays with the human, matching the user's maturity scheme.

## Consequences

Two transition logics; a history log and rollback are required; threshold value is configurable (default proposal ≥3 independent plates).
