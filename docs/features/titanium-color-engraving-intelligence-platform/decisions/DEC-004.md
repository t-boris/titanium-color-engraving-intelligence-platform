## Context

Type of product: desktop app, local web app or script toolkit.

## Alternatives

1. Native desktop app next to LightBurn
2. Toolkit/notebooks without UI

## Decision

A single local process on the PC with the UI in a browser, reachable from a tablet near the rig.

## Reason

Convenient photo upload from the rig, local data, easy to move to a server later; matches the wish for screen-by-screen UI.

## Consequences

Spec describes browser UI screens; no specific technology is chosen.
