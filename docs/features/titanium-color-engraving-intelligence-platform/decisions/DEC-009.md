## Context

Q-009 asked how the system behaves when a requested artwork color has no acceptable titanium match.

## Alternatives

1. Always take the nearest validated color and only display ΔE/confidence
2. Threshold + manual substitution without passing gaps to the Experiment Designer

## Decision

In Discrete Color Engraving a desired image color is matched to the nearest validated/production titanium color only when the expected color error is within a configurable ΔE threshold. Above the threshold the color is marked 'unreachable'; the user manually chooses a substitute from the titanium palette or excludes the color. Every unreachable color is automatically registered as a target for the AI Experiment Designer for the next calibration plate.

## Reason

Protects against silent compromises in the plan while turning unreachable colors into the strongest signal for the next experiment, closing the loop artwork → gap → experiment.

## Consequences

Artwork conversion UI needs an explicit 'unreachable' state per color with substitute/exclude actions; the Experiment Designer must accept target colors in addition to gap/uncertainty analysis; the threshold is a user-adjustable setting.
