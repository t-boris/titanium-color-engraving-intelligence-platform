## Context

Experiments are derived from plans (REQ-028, DEC-055): every kept plan is an experiment waiting for a photograph. That fits a plate series, but a vector work is not a plate waiting for a photograph. The same plan row is the work, so the delete of an experiment, the delete of a test on the plan page and the delete in 'Векторная работа' all reach it. The vector-work section has a confirmation that names the consequences; the other two did not.

## Alternatives

1. Keep the work in the list but hide 'Удалить эксперимент' for it (not chosen)
2. Keep the button with a stronger confirmation that asks for the name of the work (not chosen)
3. Block DELETE /plans/{id} for vector works on the server and add a separate delete route for them (not chosen: more change for the same effect)

## Decision

A plan of the mode 'Vector job' that has no active check (photograph) is left out of the experiments: it is not in the list of experiments, and opening its experiment key gives 'not found'. It becomes an experiment when a photograph of it is added and stops being one when its photographs are deleted. The plan page of a vector work ('План гравировки') has no 'Удалить тест' button and, before a photograph, no link 'К эксперименту'; the work is deleted only in the section 'Векторная работа', whose confirmation lists what goes with it. The change is in one place of the code (the grouping of experiments); DELETE /plans/{id} itself is unchanged.

## Reason

Operator, 2026-10-19: 'Я удалил эксперимент и удалилась моя работа... Почему?'. The experiments list showed every plan, a vector work included (kind 'Векторная работа'); 'Удалить эксперимент' deletes the plan, and a never-photographed vector work is hard-deleted with it (audit plan_deleted, picture and variants gone) under a confirmation that spoke only of 'плата и все проверки (0)'. The operator chose, from three options, to leave such works out of the experiments, and to remove the delete button from the plan page of a vector work.

## Consequences

The experiments list is one entry shorter for every unphotographed vector work. A vector work that has photographs is still an experiment, and deleting that experiment deletes its checks and then archives the plan (status 'Deleted'): the work disappears from the vector list but its rows and files are kept; this is not changed here and is reported to the operator.
