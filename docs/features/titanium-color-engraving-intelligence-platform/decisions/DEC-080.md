## Context

Operator, 2026-10-19, after the vector work became one screen: "Поменяй UI на 1 screen without scroll for карта цветов и для экспериментов". Measured before at 1421 x 951: the experiments list 3725 px, the page of one experiment 4403 px (1295 px without a photo), the colour map 1473 px, the colour model of one laser and lens about 30 000 px. The operator chose the scope "menu items and the pages inside them", the experiments layout "list on the left, working task and findings on the right" and the colour map layout "filters on the left, the map in the centre, the colour search on the right".

## Alternatives

1. Only compact the existing pages (rejected: the model page cannot be brought to one screen that way)
2. Hide the side menu on every page (rejected: the experiments list fits beside it and the menu is how the operator moves between sections)
3. A separate stylesheet per page (rejected: one shared frame in styles.css, page rules under their own prefixes)

## Decision

Every page of these two sections is a frame `.os` (a header, columns `.os-col`, one list or table per panel that may scroll inside `.os-scroll`) as high as the window; below 1100 px the columns stack and the page scrolls as before. The side menu folds away ('Меню' opens it) only on pages that need the width: the colour map, the experiment page, the colour model and the knowledge page; the experiments list keeps it. The router leaves the footer note out of such pages. Experiments: the filtered list in the left column, 'Рабочая задача' compact over 'Выводы для материала' on the right. Colour map: filters and the folded explanation on the left, projection switch, lightness range and the large chart in the centre, 'Какой цвет нужен' with its results on the right. Experiment page: the photo with its overlay on the left, tabs Результат, Матрица, Проверки, Плата, Работа, Выводы on the right (a tab is shown only when it has content). Colour model: a list of sets on the left, the map of the selected set in the centre, the model table and tabs 'Что видно', 'Варианты', 'Все слои' on the right; knowledge: details on the left, history and evidence on the right. The open tab or set is remembered by the browser. Nothing was removed: what no longer fits sits in a tab, a panel or a fold-out.

## Reason

One screen without scrolling was asked for twice for the same kind of work (looking at a picture beside its controls); one frame and one rule keep the pages alike and the code small, and tabs plus inner lists keep every number reachable without a page that is thirty screens tall.

## Consequences

New shared CSS section `.os*` and a router condition for the footer; the chart of the colour map scales to its box; the old long layouts of the experiment page (.exp-head, .exp-photo-card, .exp-stage, .exp-photo, .exp-tools, .exp-checks) are gone. The measured layers of an experiment are cards instead of a five-column table. Below 1100 px the pages scroll as before; this was checked by CSS and tests, not in a narrow browser.
