## Context

Real .lbrn2 files record, per layer, the pulse width (`QPulseWidth`) and the line interval (`interval`) next to power (`maxPower`), speed and frequency. REQ-010 sources profile constants from the linked laser profile version, and REQ-015 requires layers with an unsupported axis such as a different pulse width to be imported with a warning and marked as not comparable. They do not record focus, material batch or passes.

## Alternatives

1. Ignore pulse width and line interval in the file and always trust the profile constants.
2. Treat pulse width and line interval as additional variable axes (conflicts with DEC-005).

## Decision

The importer reads pulse width and line interval from each layer when the file has them and compares them with the constants of the linked laser profile version. If they differ, the layer is imported with a warning and marked 'not comparable'; it never enters the color-space model or the repetition counts. Comparable layers store the full parameter vector with constants taken from the profile version. Focus, material batch and passes are not read from the file and stay unknown unless the operator supplies them.

## Reason

The user chose this option. It keeps DEC-005 (three variable axes) and REQ-010 intact and applies the REQ-015 rule without silently merging data from different constants.

## Consequences

The parser must expose power, speed, frequency, pulse width and line interval per layer and flag layers whose values cannot be read. The mapping from the file's frequency unit (Hz in the file) to the profile's unit is explicit and tested.
