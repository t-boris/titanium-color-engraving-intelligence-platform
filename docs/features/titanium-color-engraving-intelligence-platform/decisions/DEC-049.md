## Context

A framed work shows only part of the plate; the dark frame covers the border. Region masks built from the file geometry reach into the frame, so a partly hidden element would be sampled together with black frame pixels. Plates already carry a visible-surface mask for the right edge; finished works have none.

## Alternatives

1. Measure the full file geometry and warn
2. Drop every element that touches the frame
3. Ask the operator to draw the window by hand

## Decision

When a frame window is detected during registration, its polygon is stored in the alignment record and used as a visible-surface mask for every layer. Elements entirely under the frame are reported as inferred and are not measured. Elements partly under the frame are measured on the visible part only, and the report lists them.

## Reason

A median over mask pixels that include frame pixels is biased dark; excluding the frame keeps the colour an observation of the engraving only, consistent with the reference-chart gate and with the rule that measured values beat computed ones.

## Consequences

Alignment record gains a window polygon and per-element status; measurement subtracts hidden pixels; the overlay draws the hidden part of an outline in a separate colour.
