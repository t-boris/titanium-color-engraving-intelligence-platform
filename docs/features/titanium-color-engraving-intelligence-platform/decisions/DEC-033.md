## Context

DEC-013 requires an offline algorithmic core: a color-space model with uncertainty plus an acquisition function over candidate parameter sets that accounts for gaps, high uncertainty, instability and target colors, deterministic for a fixed database state and seed. It gives no formulas or numeric values.

## Alternatives

1. Interpolation with distance-based error estimates instead of a Gaussian process.
2. Fit the kernel hyper-parameters from the data. With a handful of parameter sets this overfits and makes the result depend on the optimiser.

## Decision

- Candidates: 1500 points drawn with a seeded generator inside the laser profile's axis ranges, rounded to power 0.1, frequency 1 and speed 1, plus every existing unstable parameter set.
- Model: a Gaussian process with a fixed RBF kernel (length scale 0.3 on axes normalised to 0..1, noise 0.01), fitted on the mean Lab of each measured parameter set. It needs at least 3 measured sets; with fewer the designer proposes by gap only and says that target colors cannot be addressed yet.
- Four scores in 0 to 1 describe every candidate: target (exp(-d / 10) with d the model's predicted delta E to a registered target color), instability (variance divided by twice the saved variance threshold, only for existing sets above that threshold), uncertainty (posterior standard deviation) and gap (distance to the nearest measured set divided by 0.25, capped at 1). Each proposed set names the reason it was chosen for.
- Selection is phased and greedy. Phase 1 serves registered target colors, at most half of the proposal, one set per target, taking the candidate the model predicts closest to it. Phase 2 re-measures existing parameter sets above the saved variance threshold, at most half of the remaining slots. Phase 3 fills the rest with the larger of uncertainty and gap. After every pick the utility of nearby candidates is multiplied by min(1, distance / 0.15) so a proposal spreads out. Ties are broken by candidate index.
- Targets are served first because taking the largest of the four scores lets far-away gap candidates, whose gap score saturates at 1, outrank every target candidate: a first version did that and could never address a target.
- The proposal is stored once per laser profile, database signature and seed, so asking again returns the same plan. The default seed is 1729 and the default size is 6 sets.
- Registered target colors that a proposal addresses are linked to it; targets it cannot address are reported.
- An optional explanation is plain text attached to a proposal by a caller-supplied function. It cannot change parameters or observations; with no function the explanation is simply absent.

## Reason

A fixed kernel makes the result a pure function of the data and the seed, which DEC-013 requires and tests can check. Phasing keeps each reason honest and guarantees that a registered target is addressed whenever the model is fitted: a set is proposed for exactly one named cause.

## Consequences

Proposed only. Every constant is an unvalidated engineering default (length scale, noise, scales, radius) and the axis ranges that bound the candidates are whatever the operator set in the laser profile, not verified hardware limits. No real LLM adapter is wired in this version: there is no API key to test one with, so only the text-attachment interface exists.
