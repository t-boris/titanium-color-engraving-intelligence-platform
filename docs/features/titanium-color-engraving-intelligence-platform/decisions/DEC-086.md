## Context

Operator, 2026-10-20: "Q-Pulse нет в файле - это баг, быть такого не может"; "somewhere in the file there is a default for Q-Pulse, it looks like 200; it needs to be set in the parameters". Found: LightBurn 2.1.04 leaves a setting out of a layer when it is at its default (the file of work 22 has no QPulseWidth in the cleaning layer, whose own name says PW200, and in the label layer C16 P25-F60-V150, which the app's plan defaults give 200 ns; across 18 files the 21 layers without the tag are all at 48 or 60 kHz, the frequencies of those two layers). The earlier rule of REQ-015/016 was that nothing is filled in automatically; the pulse width of such a layer was unknown, the layer not comparable, the observation out of the model.

## Alternatives

1. Keep the layer unknown until the operator supplies the pulse width layer by layer (REQ-016)
2. A global application setting instead of a parameter of the laser
3. Read the pulse width from the layer name (PW200)

## Decision

The passport of a laser has an optional "default pulse width" (ns, one of its steps; 200 in the JPT M7 template and on the operator's laser). A required setting that the file omits is taken from, in this order: the operator's supplied value for that layer (REQ-016), then the laser's default pulse width, else it stays unknown. The report of a layer keeps the file's own value (None) and lists the defaulted settings with their source; the accepted observation stores the value used and the provenance "laser default"; the screens say "по умолчанию лазера", never "нет в файле". Only the pulse width has a default; nothing else is filled in.

## Reason

The omission is not missing information: it is how LightBurn writes the default, and the default is a property of the laser the operator knows. A layer without Q-Pulse can no longer fall out of the model, and the operator sets the value in one place.

## Consequences

Observations accepted before this change keep pulse_width None and model_eligible 0 (observations are immutable); measuring those experiments again gives them the default. A laser without a default behaves as before. The default is a statement of the operator; a layer that really had another width and was left out of the file cannot happen (LightBurn writes it then). Supersedes the part of REQ-015/REQ-016 that said no default is ever substituted, for the pulse width only.
