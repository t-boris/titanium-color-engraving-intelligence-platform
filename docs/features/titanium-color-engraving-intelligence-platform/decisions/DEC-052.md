## Context

170 LightBurn files of the operator (LightBurn 1.7) contain 86 image layers: dither modes grayscale, 3dslice, stucki, jarvis, sketch and threshold, dpi, dot width and dot correction, a cleanup pass with a sub-layer for 3D slices, and Bitmap objects whose picture is stored as PNG (a picture used on several layers is stored once). A single median colour per layer says little about a continuous-tone engraving, but removing it would make a work made only of image layers impossible to accept.

## Alternatives

1. Drop the single colour of image layers
2. Model LightBurn's dithering and compare predicted and photographed dots
3. Interpret nothing and keep the settings only as raw data

## Decision

An image layer is described structurally (mode, kind tonal or depth, dpi, dot width, dot correction, cleanup pass, passes, picture processing). The picture embedded in the file is laid over the photograph through the alignment and the lightness L* of the photograph is binned by the picture's grey level, giving a tonal profile with its rank correlation, range and evidence strength. The edge of the picture that is up is taken from the better positive agreement because the file does not state it. The single median colour of the layer is still measured and stays eligible as before. Grey levels are those of the stored picture, before LightBurn's brightness, contrast and gamma; dithering is not modelled.

## Reason

This is the tonal evaluation of REQ-004 for imported works, built only from what the file and the photograph contain, without predicting dither results. It was validated on synthetic photographs with a known answer and the file reading on all 170 files; no photograph of an image-mode work was available.

## Consequences

The tonal profile is a report field, not an observation: it feeds no knowledge stage yet. A turned picture with an inverted tone looks the same as a plain one; the positive reading is assumed and reported. The result must be checked on a real photograph of an image-mode work before it is trusted.
