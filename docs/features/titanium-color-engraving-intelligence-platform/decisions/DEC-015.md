## Context

DEC-012 assumed the user's archive of artworks would be imported with uncontrolled photos and therefore needed a separate weight rule (Q-014). The user clarified that these works are not legacy: he can photograph them on the rig like plates, and he will always operate with the pair «LightBurn file + image».

## Alternatives

1. Keep a 'legacy/uncontrolled' tier that does not count toward 'validated' (DEC-012 as recorded)
2. Count artwork observations with a reduced weight (e.g. 0.5 repeat)
3. Use artwork observations only as Experiment Designer targets

## Decision

Every observation — from a calibration plate or from a finished artwork/photo engraving — originates from the pair «LightBurn project file + photograph taken on the fixed rig with the reference chart». Observations from artworks are regular controlled observations: they enter the color-space model, feed the Experiment Designer and count toward repetition thresholds for automatic promotion to 'validated' on equal footing with plate cells. The 'legacy/uncontrolled' provenance tier introduced in DEC-012 is dropped. Photos that fail the rig check (no detectable reference chart) are flagged and excluded from model updates, whatever their source.

## Reason

The quality of an observation is determined by how the photo was taken (rig + reference chart), not by whether the artefact was a plate or an artwork. Since all photos go through the same rig and chart-based correction, a separate tier would only duplicate the rig check already required by REQ-009. This keeps the data model small and the maturation rule single.

## Consequences

REQ-015 is renamed from 'historical import' to the universal ingestion path; REQ-009 applies to all photographed artefacts; REQ-016 sources parameters from the LightBurn file in all cases. Calibration plates become a special case of the same pair (system-generated file with markers and experiment identifier). The gate for model updates is the reference-chart detection, not provenance.
