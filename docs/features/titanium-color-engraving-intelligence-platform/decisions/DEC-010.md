## Context

Q-010 asked whether real artwork/photo engravings should carry registration markers for automatic post-engraving alignment.

## Alternatives

1. Always engrave markers and ID on every piece
2. Markers only on plates; align pieces by feature matching or manually

## Decision

An EngravingPlan may optionally include registration markers and a plan identifier outside the image area. With markers, post-engraving analysis aligns the photograph automatically using the same CV pipeline as calibration plates; without markers, the user aligns the photograph manually by placing the image corners in the UI.

## Reason

Keeps fully automatic feedback where marks on the workpiece are acceptable, without forcing markers on finished pieces.

## Consequences

EngravingPlan carries a 'markers' flag and marker geometry; the specification must describe two alignment paths (automatic and manual corner placement); manually aligned observations may carry lower alignment confidence.
