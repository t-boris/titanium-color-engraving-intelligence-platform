## Context

DEC-016 requires the same observation-quality and repetition-independence criteria for every artefact source, and REQ-001, REQ-005 and REQ-006 say these criteria must be defined before automatic validation is implemented. The prototype counted distinct `pieceId` values, which would exclude real calibration experiments that engrave several plates on one sheet.

## Alternatives

1. Only an engraving on a new physical piece counts (prototype `pieceId` rule).
2. Each separate engraving counts, and the repetitions must also span at least two known sheets or batches.

## Decision

The repetition-independence criterion is: each separate physical engraving counts as one independent repetition, whether it is on a new piece or on a new area of the same sheet. The link to the sheet is kept as context. A re-photograph of the same engraving never counts as a repetition; it only measures rig repeatability (REQ-009).

## Reason

The user chose this option. It matches how calibration experiments are run and keeps the criterion independent of whether the system created the work.

## Consequences

This defines only the independence criterion. The shared observation-quality criteria and the numeric repetition threshold remain configurable and are not given a default here (DEC-006 only proposed a value). Automatic promotion beyond 'measured' stays disabled until the operator has saved a repetition threshold and the quality criteria. Observations record an engraving identity so that re-photographs of one engraving are not counted twice. Replaces the prototype's `pieceId` demonstration rule.
