## Context

The compact capability export assigned a separate output layer to every parameter combination. LightBurn showed only the 30 normal color layers; excess geometry appeared on T1/T2, which are non-output tool layers. The screenshot identified the practical failure before engraving.

## Decision

Treat LightBurn output colors 00–29 as the complete set of laser-output layers. T1 and T2 are non-output tool layers and must never carry engraving geometry. Count clean and registration operations toward the 30-layer limit; a clean-first, marker-bearing test plate can have at most 28 test-setting layers.

When several shapes use identical settings, place them in one LightBurn output layer and keep their named geometry groups in the experiment record for separate image measurements. Use separate small plate types for detailed sweeps that do not fit the compact overview. Reject any export that would exceed the real palette.

## Reason

The LightBurn guide documents 30 normal palette swatches (00 through 29) and identifies T1/T2 as tool layers that are never output to the laser. A file that exceeds the output palette leaves test shapes unengraved or misassigned.

## Consequences

The compact overview has 28 test-setting layers plus clean and registration. Power/speed, calibration and pulse-cutoff grids are sampled to fit the hardware limit; full frequency and wobble sweeps remain separate plate types. The result map preserves grouped line-gap and text samples from one shared-setting output layer.
