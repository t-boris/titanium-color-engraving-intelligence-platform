## Context

DEC-006 only described upward promotion; the downward path for degraded production colors (new titanium batch, focus drift) was undefined.

## Alternatives

1. A: flag only, no exclusion from plans — doubtful color stays usable until the user reacts
2. C: automatic demotion after N confirmed deviations — contradicts manual control of production and risks rollbacks caused by photography errors

## Decision

When new observations show a production color is unstable or deviates beyond tolerance, the system flags it as 'questioned' without changing its stage, shows the evidence, and excludes it from new engraving plans by default. The user may explicitly include it, confirm it, or demote it manually.

## Reason

Keeps the principle that only a human changes production knowledge (DEC-006) while preventing a doubtful color from silently entering new work.

## Consequences

A 'questioned' flag exists orthogonally to maturity stages; plan generation must check it; the UI needs an evidence view and confirm/demote actions; demotion thresholds are configurable.
