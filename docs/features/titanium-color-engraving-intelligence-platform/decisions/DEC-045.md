## Context

A RAW photograph without a usable reference-chart correction can still show relative differences among layers in that photograph. The ingestion check already stores those measurements, but the color map previously read only accepted observation rows. A checked pair therefore looked empty until a separate acceptance action created immutable observations.

## Decision

Show measured RAW camera-relative values from any successfully aligned, checked pair on the color map, including pairs awaiting mask review or acceptance. Mark these sets as provisional and link to the pair review. Keep their Lab values relative to that one photo, show cleaning and registration operations alongside test layers, and exclude all such evidence from standardized color predictions.

Acceptance remains the only operation that creates immutable observation records. A pair without valid alignment or measured layers stays off the color map.

## Consequences

An experiment is no longer invisible while its masks await review. The operator can inspect its dark, bright, warm, cleaning and label results from the color map, then return to the pair to review masks and accept the evidence. RAW-relative results remain useful for within-photo ranking but cannot be averaged across photographs or used as calibrated production recipes.
