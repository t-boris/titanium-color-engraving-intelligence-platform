## Context

The user asked why not all EZCAD settings of the laser are visible. The controller table mixes printed screenshot values, which text recognition read reliably, with handwritten numbers (galvo scale factors, red-pointer scales, the machine serial) that cannot be read with confidence from the slanted photograph. DEC-037 kept the unsure ones out of the data entirely, which hides the setting itself.

## Alternatives

1. Show only the printed values (the list looks incomplete, which is what the user noticed).
2. Transcribe the handwritten numbers as if certain (a wrong scale factor would later be trusted).

## Decision

Every controller setting that can be located on the photographs is listed with its name. A value carries a status: printed (read from the printed screenshot), handwritten (written by hand, shown for comparison and flagged unverified) or confirmed (the operator checked it against the original). A handwritten value that cannot be read is shown as 'see photo' and also listed as an open item. No controller value takes part in any calculation.

## Reason

The operator sees the complete list and knows which numbers to trust, and the photograph stays one click away on the same page.

## Consequences

Check boxes that could not be read reliably are not listed and are noted as an open item. Marking a value confirmed is an edit of the passport and never touches measurements.
