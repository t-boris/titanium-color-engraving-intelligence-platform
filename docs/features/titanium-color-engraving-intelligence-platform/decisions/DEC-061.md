## Context

The operator engraves LightBurn Material Tests: a grid of squares, two settings varying along the axes, the axis values engraved beside the rows and under the columns, the fixed settings engraved above, sometimes a single column (one setting). There is no LightBurn file to upload: the photograph carries the job. These plates are exactly the dose ramps the oxide kinetics needs (DEC-060).

## Alternatives

1. Ask the operator to type every setting of every cell: slow and error-prone for 100 cells
2. A separate experiment type with its own measurement code: duplicates the check, masks, acceptance, colour map and model
3. Recognise the grid and its labels, let the operator confirm, and generate a LightBurn file with one layer per cell so that the existing pair pipeline measures it (chosen)

## Decision

`matrix.py` finds the cells as near-square outlines on an exposure-normalised rendering of the RAW, fits a lattice to the cells of one size (other size groups are tried after it), takes the grid's extent from the connected block of cell-like lattice nodes, rectifies it and reads the labels with tesseract when that program is installed (an optional system tool, no Python dependency): each row and column label from its own crop with its own contrast threshold, three binarisations, decimal points kept; the fixed settings from the header lines above the grid; the axis titles. Axis values are fitted as an evenly spaced sequence (at least three agreeing labels, a reading with a moved decimal point counts half, zero and one-digit readings count nothing, the ends rounded to the printed precision); rows are trimmed by missing row labels and grow by agreeing labels; columns only grow. The varying settings are named by the titles, by what the header lacks, or by the usual range of the values. The result is a proposal: the pair carries it as `matrix`, its LightBurn file is generated from it (one Scan layer per cell, index = row x cols + col), it is aligned straight from the lattice (method "material test grid"), and it cannot be accepted until the operator confirms the settings (or corrects them, which regenerates the file and re-checks). Every complete matrix in a photograph is offered as its own experiment. The chart is now looked for on the exposure-normalised rendering first (all six under-exposed sample photographs: found, residual 2.8–3.6 dE; on the 8-bit decode: one of six).

## Reason

On the operator's six photographs (2026-10-18): four 10 x 10 matrices read completely and correctly (power x speed at 250 kHz 9 ns, 330 kHz 4 ns, 60 kHz 300 ns; power x interval at 1950 kHz 2 ns), one 1 x 5 interval column read correctly except passes (4 for 1), one 1 x 10 Q-pulse column read except the power label (cut by the plate edge) and the interval (overprinted by a neighbouring test), plus a second 1 x 5 passes column found in the same photograph. Cell centres within 1-3 px; 100 cells measured per matrix in 25-35 s; synthetic matrices within 2 px.

## Consequences

Observations of a matrix are ordinary observations with the cell in their evidence; they enter the colour map, the oxide model and the kinetics. Reading quality depends on the labels' contrast and on tesseract being installed; without it the operator types the first and last value per axis and the fixed settings. A setting outside the usual range of a marking laser is flagged on the review screen. A re-photograph of an accepted matrix finds the matrix again and keeps the confirmed settings.
