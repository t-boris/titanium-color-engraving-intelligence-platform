## Context

REQ-009 and DEC-015 require a reference chart in every frame of a measured work; photographs without one are to be flagged and excluded from model updates. In practice the operator photographs without a ColorChecker card: plates are measured relative to the camera (their own markers make them the target), and the first finished work, the pilot pair unbreakable, has a photograph without any card. The operator first asked to wait for a photograph with the card, then, once it was clear that the card is a physical ColorChecker and not a file, allowed measurement without it.

## Alternatives

1. Keep requiring the chart and wait for a new photograph
2. Accept chart-less photographs into the colour model as if calibrated

## Decision

A finished work whose photograph has no usable reference chart is measured from the decoded RAW without colour correction, exactly as a calibration plate is: the observations are kept as experiment evidence, flagged camera-relative (model_eligible = 0) and excluded from standard-colour predictions and from the colour model. The check says so in a warning. The setting allow_relative_finished_works (default on) can be switched off to restore the strict rule of REQ-009.

## Reason

REQ-009 asks that such photographs are flagged and excluded from model updates, which this satisfies; refusing to create any observation lost the geometry, parameters and layer relations that are exact without a chart. Camera-relative Lab values are comparable only within one camera and one lighting, and they are labelled so.

## Consequences

The pilot pair gives 19 observations (alignment element anchors) that do not feed the colour model. Repetitions of the same recipe on charted photographs stay the only route to validated knowledge. An exposure as dark as IMG_3281.DNG gives low absolute L* values; only comparisons within the same photograph are meaningful.
