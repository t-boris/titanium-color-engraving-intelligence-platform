## Context

REQ-036 asks that unsupported shapes or settings are reported per layer. A LightBurn layer carries many tags; some the reader interprets, some it keeps in the recipe without interpreting (galvo timings, tab counts), some it does not know. While testing REQ-038's refusal gates it was found that the gate on the median anchor residual can never trigger: it measures anchors already kept within the same 0.2 mm limit, and excessive residuals are refused earlier by the inlier (disagreement) gate.

## Alternatives

1. Report every tag the model does not interpret (a note on almost every layer)
2. Remove the redundant median-residual gate

## Decision

A setting is reported as unread only when its tag is unknown to the reader; tags kept in the recipe (they take part in its identity) are not reported. Every shape that yields no outline is counted on its layer, whatever its type. The median-residual gate stays as it is; REQ-038's refusal for excessive residual is carried by the inlier gate, which a plate bent by 0.4 mm triggers in the tests.

## Reason

Reporting kept tags would bury the one note that matters (on the operator's 16 files: no settings notes and one Path without an outline).

## Consequences

Proposed for the operator's review. The refusal message 'only N elements matched' understates N when fewer than four elements match; it is corrected with this change.
