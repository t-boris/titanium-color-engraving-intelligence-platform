## Context

The five photographs are printed forms photographed at an angle, some with handwriting. The test report and cut-off table are printed and legible. The controller table mixes printed screenshots with handwritten values (field size, scale factors, a number next to Max PWM, the controller serial number) that cannot be read with confidence. The pulse waveforms are printed graphs.

## Alternatives

1. Transcribe every handwritten number that looks plausible.
2. Digitise the waveform curves from the photograph with image processing.

## Decision

Each photograph is attached to the device unchanged as a source document. Printed values that were read twice (visually and by text recognition) are stored as data. Handwritten values that are not certain are not stored; they are listed on the device as open items and as a question. Waveforms are stored only as key figures (peak power, duration) read from the axes, marked approximate.

## Reason

A wrong scale factor or serial number copied into the data would be trusted later, and nothing in the application could tell it from a measured value. The photograph stays the source of truth (REQ-001 principle applied to documents).

## Consequences

The device page links to the photographs and shows the open items until the operator confirms them. Digitising the waveforms is possible later from the stored photographs.
