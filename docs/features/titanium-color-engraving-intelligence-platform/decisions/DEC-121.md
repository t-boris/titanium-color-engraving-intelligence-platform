## Context

REQ-043 and DEC-020 describe one local Python 3 process, packaged as a Python package with a console entry point and reachable from a tablet. The electron feature (DEC-022) adds an Electron desktop shell and requires this contract change to be agreed before implementation.

## Alternatives

1. Desktop only, the console mode kept as a developer tool

## Decision

DEC-020 stays valid for the console mode: the package and `titanium-platform` command keep working as before. In addition, the desktop application runs the same package as a hidden child process on loopback with a session secret. Tablet access (REQ-043) in the desktop application is an explicitly enabled LAN mode with pairing (electron DEC-033, DEC-047); in the console mode the existing `--host` behaviour remains. Both modes check Host and Origin of requests.

## Reason

The owner chose "both modes" on 2026-10-24 (electron DEC-046).

## Consequences

The operator's service on port 8765 and its deploy procedure are unchanged. Requests with a foreign Origin or an unexpected Host are refused in both modes.
