## Context

DEC-039 said that no controller value takes part in any calculation, and DEC-036 used the rated power. The operator wants the values they enter for the pulse shapes, the test report and the laser settings to be understood as one description of their laser and to be taken into account later. Treating a handwritten, unchecked number as a fact would put an unverified value into every later calculation.

## Alternatives

1. Keep the settings as documentation only (the operator's objection).
2. Use every value as soon as it is entered, whatever its reliability.

## Decision

A characterization is derived on every read. Values that are printed or confirmed feed the calculations; handwritten values that the operator has not confirmed are listed as waiting and are not used. The effective power is the measured power of the test report when it is plausible. The usable frequency range is the laser's range narrowed by Min PWM and Max PWM, and leaving it is a warning, because LightBurn has its own galvo limits. The work field decides whether a plate fits, and a plate that does not fit is refused. The pulse energy is capped at the passport maximum. The device title is the model with the current serial number.

## Reason

The operator sees one description of the laser and sees which numbers drive the results, and an unchecked number never does. A plate larger than the lens field cannot be engraved, so it is refused, while a frequency outside the controller range depends on how LightBurn is configured, so it is a warning.

## Consequences

Operating points and charts of a laser with a test report use 62.6 W instead of 60 W. Confirming Field Size, Min PWM or Max PWM changes what the plate form accepts. The old fixed question texts are removed because the questions are derived.
