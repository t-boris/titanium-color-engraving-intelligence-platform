## Context

REQ-015 requires one observation per layer region, sampled inside the layer mask with region edges excluded. A real LightBurn layer can own hundreds of separate shapes (one real file has 147 shapes on a single layer), and the requirements do not define a region, the size of the excluded edge, or how to treat a layer with several shapes.

## Alternatives

1. One observation per shape. A layer with hundreds of shapes would create hundreds of observations with the same parameters and tiny sample areas.
2. One observation per layer, from the median of the union of its shape masks.

## Decision

One observation is stored per readable, comparable layer. Its color is the median of the chart-corrected pixels inside the union of that layer's shape masks. Each shape mask excludes its edge by eroding a fraction of the shape's smaller side (20% by default, a named constant). A layer whose mask has fewer than 25 pixels after erosion is skipped and reported. The registration-marker layer of a system-generated file is never measured.

## Reason

All shapes of one layer share one parameter set, so one observation per layer matches how the model keys knowledge (by parameter vector) and avoids flooding the repetition counts with duplicates from a single engraving.

## Consequences

Proposed only. A layer with a color gradient across its shapes (for example a photo band) is reduced to its median, which discards that spread. The 20% edge fraction and 25-pixel minimum are not backed by any requirement.
