## Context

The parameter space dimensionality drives plate size, model and Designer complexity.

## Alternatives

1. All parameters variable from the start
2. Abstract multi-laser profile with configurable axes

## Decision

First version models one specific laser with power, frequency and speed as variable axes; pulse width, hatch, passes and focus are profile constants. Profiles must allow adding axes later.

## Reason

2–3 axes keep plates 2D and the model trainable on tens of plates; some colors may be unreachable until more axes are added.

## Consequences

Experiment records store the full parameter vector including constants; changing a constant creates a new profile version.
