## Context

An audit of every acceptance criterion against the code on 2026-10-18 found requirements whose wording was overtaken by later accepted decisions. The operator accepted the following resolutions as one decision.

## Alternatives

1. Resolve each contradiction in a separate question

## Decision

1) Reference chart: in REQ-001, REQ-003, REQ-009, REQ-013, REQ-015 and REQ-024 "no chart, no observations" reads "no chart, no model-eligible observations". The stated exceptions are camera-relative evidence of DEC-045/DEC-053 and the generated LightBurn file of a photographed matrix (DEC-061). Every photograph still gets a capture-setup (rig) record. 2) Unmarked small-patch plates (README) are an allowed exception to REQ-003; they are aligned by element anchors or four corners and never by guessed markers. 3) Deleting a pair (DEC-047) rebuilds the counts and statistics of the affected knowledge, but never lowers a stage automatically (DEC-006, DEC-029); an entry whose remaining evidence no longer supports its stage is flagged questioned with that reason, whatever its stage. 4) The titanium stock is required on every record (REQ-020); batch, sheet and focus stay optional (REQ-016). 5) DEC-050's narrow-stroke fallback replaces DEC-028's rule that a mask under 25 pixels is skipped; thin strokes only, with the overlap exclusion. 6) DEC-044 caps the number of bands at 29 output layers, 28 when a cleaning layer is present; this amends DEC-008's free N. 7) Wherever DEC-029, DEC-033, DEC-041 and DEC-056 say laser profile or profile version, read laser and lens with equal job settings (DEC-042, DEC-063). 8) The LightBurn file generated for a photographed matrix is a record of the job that was photographed, not an engraving export; it is not offered for engraving and the 30-layer limit does not apply to it. 9) DEC-058 supersedes the frame-window-first order of DEC-048; DEC-049 keeps its meaning with the window as an output of the registration.

## Reason

The operator accepted all resolutions at once; each follows the later accepted decision or the more specific requirement.

## Consequences

Implementation and tests follow these readings; the affected requirements keep their text and are read through this decision.
