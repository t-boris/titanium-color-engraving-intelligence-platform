## Finding

REQ-010 requires plate parameters to come from the plate definition, whereas DEC-015 and REQ-015 require the LightBurn file to be the parameter source even for calibration plates. If the file was edited after generation, these rules produce different parameter-to-color observations. Update REQ-010 so the plate definition supplies identity and geometry linkage while the paired file supplies parameters.

> For every rig-plate observation, power, frequency and speed are taken from the plate definition linked by the experiment identifier.

## Resolution

Брать параметры из файла LightBurn, но при расхождении с определением платы требовать исправить пару или явно подтвердить, что приложенный файл использовался при гравировке. — see DEC-017.
