## Finding

REQ-005 and REQ-006 still require a separate legacy/uncontrolled tier and exclude its observations from validation repetitions. This directly contradicts DEC-015 and REQ-001, REQ-009, REQ-013, REQ-015 and REQ-016, which require one controlled ingestion path and equal repetition eligibility. Remove the superseded legacy behavior from both requirements; retain the universal file-and-rig-photograph workflow.

> Each imported layer region yields observations stored in the experiment database with provenance = 'legacy/uncontrolled'.

## Resolution

Применить DEC-015 и дополнительно уточнить: допуск к повторам определяется качеством наблюдения, а не тем, создана ли работа системой. — see DEC-016.
