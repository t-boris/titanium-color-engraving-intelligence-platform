## Statement

The first level of photo engraving exposes engraving kind, size, the recommended scale and basic image adjustments. Group calibration controls by purpose while preserving all existing functionality and allow comparison against the state immediately before the latest parameter change.

## Acceptance Criteria

- [ ] Group Min/Max power, gamma, dot correction, measured points and scale details by purpose, with brief explanations of their effect.
- [ ] Retain exact numeric input alongside sliders.
- [ ] Allow comparison of the current result against the state immediately before the latest parameter change; after another change, advance the baseline accordingly. Treat one continuous slider adjustment as one change.
- [ ] Apply the same settings to prediction and LightBurn export, preserve the physical model and keep measured-range limitations visible.
- [ ] Verify the affected photo-work and vector photo-zone panels in the real browser and Electron interfaces, including keyboard and screen-reader access, enlarged text and narrow or low windows.
- [ ] Preserve validation, error feedback, the source image when changing scales, protection against stale responses, and undo restoration of size and settings.
