## Statement

Первый уровень фотогравировки содержит вид, размер, рекомендованную шкалу и основные регулировки.

## Acceptance Criteria

- [ ] Min/Max, гамма, поправка точки, измеренные точки и детали шкалы сгруппированы с объяснением назначения.
- [ ] Ползунки сохраняют точные числовые поля; эффект изменения можно сравнить с прежним состоянием.
- [ ] Одинаковые настройки применяются к прогнозу и LightBurn, ограничения измеренного диапазона видны.
