## Context

REQ-002 requires creation and editing of each card side on a dedicated canvas but does not specify the minimum operations for individual composition elements.

## Alternatives

1. Provide selection, movement, resizing and deletion on the card canvas; require graphics to be prepared externally for rotation and other advanced changes.
2. Prepare compositions in an external editor and provide only placement and deletion of finished elements on the card canvas.

## Decision

The operator can select, move, resize, rotate, reorder, duplicate and delete each composition element directly on the card canvas.

## Reason

The team selected full editing to support creating and revising the card composition on its dedicated canvas.

## Consequences

REQ-002 must require independent selection, movement, resizing, rotation, layer reordering, duplication and deletion of each composition element on each card side. Acceptance criteria must verify these operations for supported element types.
