## Context

The operator needs to assemble a card design.

## Alternatives

1. Start from an uploaded finished layout and add elements in the application.

## Decision

Create and edit the design on a dedicated card canvas, with the ability to add existing graphics.

## Reason

The user selected the in-application composition workflow.

## Consequences

The first version needs an editable card canvas and support for imported graphics.
