## Context

DEC-037 required icons and drawings to be generated on the device without an internet connection, and left model distribution, resources, quality and performance open. When asked which on-device runtime to use (a local Ollama text model writing SVG, a local diffusion model, or both), the operator answered "Let's use external OpenAI" and, asked to confirm that this reverses DEC-037, F-004's resolution and the approved REQ-002 criteria 4-5, confirmed "Yes, supersede DEC-037" (2026-11-06).

## Alternatives

1. Keep DEC-037: generate on the device through a local Ollama text model that writes SVG (no new library, limited drawing quality).
2. Keep DEC-037 with a local diffusion runtime (PyTorch/diffusers or MLX plus 2-7 GB of weights; needs approval of a library change).
3. OpenAI as the main generator plus a local offline fallback (the rejected alternative 2 of DEC-037; about double the generation work).

## Decision

Generate icons and drawings from a description with the OpenAI image service, through the application's existing OpenAI client, key and "AI" outbound switch. Generation needs an internet connection, a configured key and the AI switch on; the model name is kept as a setting. The generated picture is added to a card side as an image element and goes through the same tracing and drawing treatment as any imported graphic. The rest of the card workspace (composition, QR codes, saving, export) keeps working without a connection. This supersedes DEC-037.

## Reason

The operator chose the external service over an on-device runtime for generation quality and for not having to install and maintain a local model. The application already uses OpenAI for its AI features, with a key setting and an outbound switch, so no new library is added.

## Consequences

REQ-002 criteria 4-5 change from offline on-device generation to online generation with stated operating conditions (internet, API key, AI switch on). F-004's resolution now points to DEC-039. Generation is unavailable when offline or when the AI switch is off, and the screen says why; the rest of the workspace is unaffected. Generated pictures are traced into vectors on the device. The operator's description is sent to the OpenAI service, which the AI switch already governs.
