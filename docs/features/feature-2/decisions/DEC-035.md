## Context

The card workflow requires separate preparation of each side for non-colour engraving, with operator-defined settings for selected elements or groups. The preparation deliverable was not specified.

## Alternatives

1. Export each side as geometry for LightBurn and provide the assigned engraving settings separately for manual setup.
2. Create an internal plan for each side without exporting it to engraving software.

## Decision

Export each card side as a separate LightBurn project, ready for the operator to open and review.

## Reason

This provides a defined deliverable connecting preparation to the existing LightBurn workflow while carrying each side’s geometry and assigned settings together.

## Consequences

Each card side must be exported as a separate LightBurn project that preserves its physical geometry and assigned engraving settings. The operator must be able to open and review each project before engraving.
