## Context

Decorative elements may come from several sources.

## Alternatives

1. Provide a library and imported graphics without generation from descriptions.

## Decision

Provide a configurable library of shapes, frames and icons, graphic import, and generation of icons and drawings from descriptions.

## Reason

The user selected all three sources.

## Consequences

The first version includes generation from descriptions in addition to a library and imported graphics.
