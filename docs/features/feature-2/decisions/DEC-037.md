## Context

The first version requires generation of icons and drawings from descriptions, while the platform has an offline-operation requirement. The card specification did not establish whether generation must also be available offline.

## Alternatives

1. Use an external online service for generation while keeping the rest of the card workspace available offline.
2. Provide both offline local generation and an optional external online service.

## Decision

Generate icons and drawings on the device without requiring an internet connection.

## Reason

This choice makes the required generation capability available offline in line with the platform's offline-operation expectation.

## Consequences

REQ-002 must require offline, on-device generation and define the supported workshop hardware and operating conditions. Model distribution, resource needs, generation quality, and performance remain to be specified.
