## Context

The user wants QR codes for links, contact cards and other content.

## Alternatives

1. Provide structured input only for links, contacts and text.

## Decision

Support QR codes for links, vCards, text, Wi-Fi, email and telephone content.

## Reason

The user selected the broader set of content types.

## Consequences

The QR workflow needs inputs appropriate to each selected content type.
