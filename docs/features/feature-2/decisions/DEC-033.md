## Context

A card side can contain lettering, graphics and QR codes that may need different engraving settings.

## Alternatives

1. Use one set of engraving settings for each card side.
2. Use different engraving settings for selected elements or groups on the same side.

## Decision

Allow the operator to set different engraving parameters for selected elements or groups on each card side.

## Reason

The operator selected separate settings for elements or groups.

## Consequences

Each side must support assigning and reviewing engraving settings at element or group level.
