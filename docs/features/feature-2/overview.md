# Гравировка титановых визиток

## Idea

Создавать макеты титановых визиток небольшого размера и подготавливать их к обычной гравировке: размещать надписи, геометрические фигуры, рамки, иконки, небольшие изображения и QR-коды.

## Problem

Для работы с титановой визиткой нужен удобный макет в её физических размерах и набор средств для композиции и гравировки мелких элементов. Существующие средства работы с изображениями, надписями и служебными QR-кодами сами по себе не описывают полный процесс создания визитки.

## Scope

Входит: создание и редактирование макета титановой визитки на отдельном холсте, надписи, настраиваемая библиотека фигур, рамок и иконок, импорт графики, генерация иконок и рисунков по описанию, небольшая графика, эффект рисунка, QR-коды и подготовка к гравировке. Вне заявленного запроса: бумажная печать и выполнение заказов внешним сервисом. Остальной состав первой версии зависит от открытых решений.

## Existing behaviour

- Для новых работ уже сохраняется контекст мастерской: лазер, линза, титановая заготовка и другие выбранные данные. Поддерживаются результаты «фото», «цвет», «силуэт» и «линии». (`src/titanium_platform/creation_context.py`)
- Фоторабота имеет размер в миллиметрах, предпросмотр, надписи с добавлением, изменением, копированием и удалением, отмену и повтор изменений, а также экспорт в LightBurn. (`src/titanium_platform/photo_work.py`)
- Из исходного изображения создаются векторные области, текстовые силуэты и линии; ширина задаётся в миллиметрах. (`src/titanium_platform/vectorize.py`)
- В проекте есть обработка изображения для рисунка из линий с привязкой к физическим размерам. (`src/titanium_platform/drawing.py`)
- Для идентификации экспериментальных пластин уже создаётся QR-код со служебным идентификатором. Это не подтверждает наличие конструктора пользовательских QR-кодов для визиток. (`src/titanium_platform/plans.py`)
- Для служебных QR-кодов экспериментальных пластин параметры гравировки задаёт оператор; автоматические значения не предусмотрены. (`docs/features/titanium-color-engraving-intelligence-platform/decisions/DEC-027.md`)
