## Statement

Support separate preparation of each business-card side for non-colour engraving, with operator-defined engraving settings for selected elements or groups, and export each side as a separate LightBurn project for operator review before engraving.

Colour engraving of imported vector artwork (feature-3/DEC-003): each part of imported artwork has a design colour, which is how it looks in the editor, and an engraving colour, which is a measured engraving setting of the card's own laser, lens and material chosen for it. Preparation and export use the chosen engraving colours: a side is exported with a layer for each set of engraving settings its parts use. The design colour never decides what is engraved.

## Acceptance Criteria

- [x] The operator can prepare each side of a card separately for non-colour engraving.
- [x] The operator can assign engraving settings to selected elements or groups on a side.
- [x] The operator can review the settings assigned to elements or groups before preparing the side for engraving.
- [x] Elements or groups on the same side can have different engraving settings.
- [x] Each card side can be exported as a separate LightBurn project that preserves its physical geometry and assigned engraving settings.
- [ ] The operator can open and review each exported LightBurn project before engraving.
- [x] Each part of imported vector artwork engraves with the engraving colour chosen for it (a measured colour of the card's laser, lens and material), and a part without a choice engraves with the card's default settings.
- [x] The exported LightBurn project of a side has a layer for each set of engraving settings used by its parts, and every part is a shape of the layer of its engraving colour.
- [x] Changing the design colour of a part does not change the engraving colour chosen for it, and choosing an engraving colour does not change the design colour.
