## Statement

Generate QR codes for supported content types for inclusion in either side of a business-card design, allow each QR code to be independently edited directly on the card canvas, and check its module size and quiet zone at its placed physical size against separately defined thresholds. Warn the operator when either falls below its threshold while allowing work and engraving preparation to continue. Passing the check does not guarantee that the engraved code will scan.

## Acceptance Criteria

- [x] The operator can generate and insert a QR code on either side of the card for a link, vCard, text, Wi-Fi, email or telephone content.
- [x] The generated QR code represents the content entered for its selected type.
- [x] The operator can independently select, move, resize, rotate, reorder, duplicate and delete each QR code directly on the card canvas on either side.
- [x] Each QR code's module size and quiet zone are checked against their separately defined thresholds at its placed physical size.
- [x] The operator is warned when a QR code's module size or quiet zone falls below its threshold.
- [x] The operator can continue working and preparing the card for engraving after a physical suitability warning.
- [x] Passing the physical suitability check does not guarantee that the engraved QR code will scan.
