## Statement

Allow the operator to compose each card side on a dedicated card canvas using lettering and graphic elements from a configurable library, imported graphics, and icons and drawings generated from descriptions by the OpenAI image service (DEC-039). State the operating conditions of generation: an internet connection, a configured API key and the workshop's AI switch on; when they are not met, say so and keep the rest of the workspace usable. Allow the operator to independently select, move, resize, rotate, reorder, duplicate, and delete each composition element directly on the card canvas.

## Acceptance Criteria

- [x] The operator can create and edit the composition of each card side on a dedicated card canvas, including lettering and geometric shapes.
- [x] The operator can add and configure shapes, frames, and icons from a library.
- [x] The operator can import existing graphics and add them to a card side.
- [x] The operator can generate icons and drawings from a description with the OpenAI image service and add the results to a card side.
- [x] The operating conditions of generation (internet connection, API key, AI switch on) are defined, and the operator is told which one is missing when generation is unavailable, while the rest of the card workspace keeps working.
- [x] For each supported composition element type on each card side, the operator can independently select, move, resize, rotate, reorder, duplicate, and delete an element directly on the card canvas.
