## Statement

Provide a dedicated, physically sized, two-sided workspace for creating and editing a titanium business card design, with the ability to add existing graphics and save and reopen the complete editable card work, including both sides, their editable elements, dimensions, and engraving settings.

## Acceptance Criteria

- [x] The operator can create a card work using either an 85 × 53 mm or an 85 × 54 mm preset or enter custom dimensions.
- [x] The work contains front and back designs on physically sized canvases dedicated to card design.
- [x] The operator can create and edit the design on each side of the card.
- [x] The operator can switch between the two sides and continue editing each side.
- [x] The operator can add existing graphics to the card design.
- [x] The operator can save the complete editable card work, including both sides, their editable elements, dimensions, and engraving settings.
- [x] After closing or restarting the application, the operator can reopen the saved card work with both sides, their editable elements, dimensions, and engraving settings restored.
- [x] After reopening the saved card work, the operator can continue editing both sides and their elements, dimensions, and engraving settings.
