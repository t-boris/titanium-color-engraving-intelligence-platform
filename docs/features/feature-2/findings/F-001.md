## Finding

The specification does not define the minimum editing operations needed to arrange and revise a composition. The choice affects whether the operator can actually build a card without an external editor.

> The operator can create and edit the composition of each card side on a dedicated card canvas, including lettering and geometric shapes.

## Possible interpretations

- Elements can be selected, moved, resized, rotated, reordered, duplicated and deleted independently.
- The editor supports only a smaller subset of these operations, with other composition work performed externally.

## Resolution

Редактировать каждый элемент непосредственно на холсте: выбирать, перемещать, изменять размер, поворачивать, менять порядок слоёв, копировать и удалять. — see DEC-034.
