## Statement

Panels and forms adapt without losing information or actions at a width of 320 CSS px, in an 800×600 CSS px content viewport, and with text enlarged to 200%; the low-window and enlarged-text conditions must also work together.

## Acceptance Criteria

- [x] At a viewport width of 320 CSS px, forms and primary actions remain accessible; a necessary two-dimensional canvas may have its own scrolling.
- [x] Verify an 800×600 CSS px content viewport at normal text size, text enlargement to 200% independently of the low-window condition, and the combination of an 800×600 CSS px viewport with text enlarged to 200%. In every case, form controls and save/export actions remain reachable and usable; vertical form scrolling is permitted.
- [x] On narrow screens, selected-object properties open in a slide-out panel; the header does not displace the usable work area.
- [ ] Verify actual interface behavior in the browser and Electron, including the keyboard workflow from REQ-001; CSS declarations alone do not establish acceptance.
- [x] Layout and text-size changes preserve the domain guarantees in research section n58: image retention when changing scale, matching card and prediction palettes for the current width, rejection of stale responses, restoration of size and settings on cancellation, preview/export consistency, independent color and photoengraving assessments, and file and measurement history.
