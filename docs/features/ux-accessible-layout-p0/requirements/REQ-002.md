## Statement

Панели и формы перестраиваются без потери действий при изменении окна и масштаба текста.

## Acceptance Criteria

- [ ] На ширине 320 CSS px формы и основные действия доступны; необходимый двумерный холст допускает собственную прокрутку.
- [ ] На низком окне и увеличенном тексте кнопки сохранения/экспорта достижимы; вертикальная прокрутка форм разрешена.
- [ ] Свойства выбранного объекта открываются выдвижной панелью на узком экране; шапка не вытесняет рабочую область.
