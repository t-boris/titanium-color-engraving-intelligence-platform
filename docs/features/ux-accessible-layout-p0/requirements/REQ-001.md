## Statement

Клавиатура и эквивалентные элементы позволяют выполнить основные действия холста и форм.

## Acceptance Criteria

- [ ] Проверен путь меню → поиск → диалог → цвет → редактор → экспорт → возврат с видимым фокусом.
- [ ] Для выбора объекта, перемещения/поворота и масштаба есть список/числа/кнопки как альтернатива жестам и мелким точкам.
- [ ] Сохранены семантика вкладок, уменьшение анимаций и системные контрастные режимы; реальные области нажатия проверены с учётом расстояний.
