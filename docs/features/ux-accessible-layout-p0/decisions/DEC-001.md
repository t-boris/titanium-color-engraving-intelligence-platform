## Context

REQ-002 specified narrow layouts but left the low-window height and text enlargement undefined.

## Alternatives

1. A: 800×480 CSS px viewport with text enlarged to 200%.
2. C: 800×480 CSS px viewport with text enlarged to 400%.

## Decision

Use an 800×600 CSS px content viewport and text enlargement to 200% as the mandatory acceptance profile.

## Reason

The user selected option B.

## Consequences

Acceptance covers the viewport and text enlargement separately and together. Heights below 600 CSS px are outside the mandatory low-window profile; the existing 320 CSS px width criterion remains.
