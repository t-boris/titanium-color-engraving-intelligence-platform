## Question

Какой профиль низкого окна и увеличенного текста сделать обязательным для приёмки? В каждом варианте проверяем условия отдельно и совместно; существующая проверка ширины 320 CSS px сохраняется.

## Why it matters

REQ-002 уже задаёт ширину 320 CSS px, но не определяет минимальную высоту и степень увеличения текста. Без этих границ нельзя однозначно принять требование.

## Options

- **A**: Окно с областью содержимого 800×480 CSS px; увеличение текста до 200%.
- **B**: Окно с областью содержимого 800×600 CSS px; увеличение текста до 200%.
- **C**: Окно с областью содержимого 800×480 CSS px; увеличение текста до 400%.

## Recommended

A — Предлагаю конкретную проверяемую границу для P0; ширина 320 CSS px уже отдельно закреплена в REQ-002.

## Answer

B. Окно с областью содержимого 800×600 CSS px; увеличение текста до 200%.
