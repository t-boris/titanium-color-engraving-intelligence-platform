## Statement

Organize infrequently used equipment reference information so that operators can find it without presenting every technical section as an equally prominent entry.

## Acceptance Criteria

- [x] Frequent equipment actions remain visible, while charts, pulse waveforms, the test report and documents are reachable through clearly named technical information groups.
- [x] Existing technical information and actions remain accessible after grouping.
