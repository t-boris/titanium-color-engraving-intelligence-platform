## Statement

Normal and compact density modes preserve readability and access to full content; a light theme remains subject to evaluation before a release decision.

## Acceptance Criteria

- [ ] Both density modes keep important labels readable and provide access to complete names without requiring hover.
- [ ] Panels retain clear semantic groups while reducing repeated borders, gradients and explanations and using one primary accent.
- [ ] Compare readability and task performance in the current and light variants under actual workshop lighting and on a tablet; record the results for a subsequent release decision.
- [ ] Compactness does not hide errors or make touch targets inconvenient.
