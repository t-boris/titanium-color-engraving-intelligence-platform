## Statement

Обычный и компактный режимы сохраняют читаемость и доступ к полному содержимому.

## Acceptance Criteria

- [ ] Плотность не достигается уменьшением важных подписей до трудно читаемого размера; длинные имена доступны без обязательного hover.
- [ ] Один основной акцент на панели, меньше повторных рамок/градиентов/пояснений при сохранении смысловых групп.
- [ ] Светлый вариант оценивается на рабочем освещении и планшете; результаты определяют необходимость выпуска темы.
