## Decision

A variant records a key of the split's regions (ids, colours and pixel counts). It can be restored on any version whose key is the same, so a variant survives a size change; a merge or a re-split changes the key. Variants made before this rule, which have no key, keep the former rule of the same version number. The work's view says of each variant whether it is restorable now.

## Reason

A size change makes a new version with the same regions; locking variants to the version number would lose them for no reason, and rewriting their versions would need undo bookkeeping of its own.
