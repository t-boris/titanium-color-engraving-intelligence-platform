## Statement

Обновления применяются только на безопасной границе операций и сохраняют пользовательскую мастерскую вне каталога установки приложения.

## Acceptance Criteria

- [ ] При активной операции установка обновления откладывается до её безопасного завершения или отмены.
- [ ] После обновления распределяемого приложения сохранённые работы, измерения, файлы и подключённые лаборатории доступны из прежней мастерской.
