## Statement

Пользователь восстанавливает доступ через страницу входа облака к тому же аккаунту с сохранением владения лабораториями.

## Acceptance Criteria

- [ ] На странице входа доступен сценарий восстановления через управляемого провайдера.
- [ ] После восстановления пользователь входит в тот же аккаунт и сохраняет владение ранее созданными лабораториями.
