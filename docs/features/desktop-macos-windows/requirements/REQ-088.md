## Statement

Установщики и проверяемые обновления распространяются с ресурсов владельца проекта и подписываются средствами владельца для каждой платформы.

## Acceptance Criteria

- [ ] macOS-выпуск подписан Developer ID и проходит notarization; Windows-выпуск имеет проверяемую платформенную подпись владельца.
- [ ] Проверка подписи и целостности выполняется до установки обновления; ошибка проверки запрещает установку.
- [ ] Установщики и метаданные обновлений размещены на ресурсах владельца, ключи подписи отсутствуют в репозитории.
