## Statement

Вход через системный браузер с безопасным возвратом в установленное приложение проверяется на обеих поддерживаемых платформах.

## Acceptance Criteria

- [ ] На macOS и Windows реальный браузер проходит первый вход и согласие, включая Google, и возвращает пользователя в приложение к тому же аккаунту.
- [ ] Неверный state или повторно использованный код не открывает сеанс; отмена и сбой провайдера сохраняют локальную работу.
- [ ] Свидетельства проверки указывают версию установщика и платформу; scripted production smoke не заменяет проверку реального браузера.
