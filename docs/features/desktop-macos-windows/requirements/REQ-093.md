## Statement

Карточки доступных выпусков явно показывают условия использования, выбранные автором; отображение подтверждается в интерфейсе.

## Acceptance Criteria

- [ ] Условия на карточке публичного и доступного закрытого выпуска совпадают с условиями опубликованного выпуска.
- [ ] Видимость и содержание условий проверены на экране установленного приложения с записью версии и результата.
