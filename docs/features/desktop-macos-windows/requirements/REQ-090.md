## Statement

Защищённый доступ планшета, сопряжение и поведение межсетевого экрана проверяются в распределяемом приложении на macOS и Windows.

## Acceptance Criteria

- [ ] На каждой платформе планшет сопрягается по защищённому каналу и загружает фотографию; поведение запроса разрешений межсетевого экрана зафиксировано.
- [ ] Доверенное устройство сохраняет доступ после перезапуска, отзыв запрещает дальнейший доступ.
- [ ] Выключение LAN прекращает внешний доступ и сохраняет работу настольного интерфейса.
