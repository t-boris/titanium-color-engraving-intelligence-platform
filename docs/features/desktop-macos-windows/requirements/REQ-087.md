## Statement

Публичная desktop-бета устанавливается и запускается на macOS Apple Silicon и Windows x64 без ручной установки Python, pip, Node.js или терминальных команд; поддерживаемые минимальные версии ОС подтверждаются на чистых машинах.

## Acceptance Criteria

- [ ] На чистой macOS Apple Silicon и Windows x64 установка и запуск распределяемых установщиков проходят без инструментов разработчика.
- [ ] Для каждой платформы зафиксированы минимальная проверенная версия ОС, версия и хеш установщика, шаги и результаты приёмки.
