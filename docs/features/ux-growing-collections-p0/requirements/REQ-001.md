## Statement

Материалы показываются компактными строками; редактор открывается только для выбранной записи.

## Acceptance Criteria

- [ ] В строке видны имя, сплав, партия и толщина; добавление и изменение — отдельные формы.
- [ ] Поиск, сортировка и порции позволяют работать с 20, 200 и 2000 тестовыми записями без раскрытия всех форм.
- [ ] Выбор предлагает поиск и последние записи, сохраняя различие марки и конкретной партии/листа.
