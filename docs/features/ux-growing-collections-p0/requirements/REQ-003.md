## Statement

Текущий рецепт, шкала или документ остаётся узнаваемым при поиске и переходе между порциями.

## Acceptance Criteria

- [x] Выбор 21-й записи и далее показан закреплённой строкой или явным переходом к записи.
- [x] Фильтр, исключающий текущий выбор, не очищает его молча; причина и действие сброса видны.
- [x] Программное открытие выбранной строки не завершается незаметным null без способа найти объект.
