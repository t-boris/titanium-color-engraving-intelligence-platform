## Statement

Каждый общий список объясняет пустую выдачу и позволяет сбросить поиск и фильтры без потери контекста.

## Acceptance Criteria

- [ ] «Ничего не найдено» отличается от пустой коллекции и содержит действие сброса всех активных условий.
- [ ] Сброс возвращает первую порцию и согласованные счётчики, сортировка и текущий выбор не меняются молча.
- [ ] Ошибки загрузки остаются возле списка с повтором; восстановление сохраняет поле ввода, фокус и уже загруженные строки.
