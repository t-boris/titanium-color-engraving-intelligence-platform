## Statement

RAW-наборы, история знания, документы и номера источников не выводятся целиком по умолчанию.

## Acceptance Criteria

- [ ] Для RAW-наборов и документов есть поиск и порции; история знания ограничена первой порцией.
- [ ] Длинные номера фото/наблюдений заменены счётчиком и раскрываемым перечнем со ссылками.
- [ ] Фильтрация и раскрытие сохраняют происхождение и доступ ко всем исходным данным.
