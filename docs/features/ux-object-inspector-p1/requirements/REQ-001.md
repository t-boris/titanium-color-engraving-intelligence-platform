## Statement

Keep the canvas primary and show the current object's properties in one inspector. For photo zones, expose basic properties in the inspector and retain the existing separate screen for detailed editing.

## Acceptance Criteria

- [ ] Selecting a region, photo zone or inscription displays its corresponding properties in one inspector without resetting the canvas view.
- [ ] For a selected photo zone, expose basic properties in the inspector and provide an explicit action that opens that zone in the existing detailed editor. Apply the basic-versus-calibration grouping defined by ux-photo-lettering-panels-p1/REQ-001.
- [ ] Preserve all existing detailed photo-zone controls and the vector work's shared undo/redo history across inspector and detailed-editor changes.
- [ ] Clearly separate document-wide colouring from selection colour; do not retain two indistinguishable Colours tabs.
- [ ] Keep splitting, variants, results and export accessible as document modes while preserving history.
- [ ] Verify selection, inspector editing and the detailed-editor round trip in browser and Electron, including keyboard and screen-reader access, enlarged text and narrow or low windows; preserve applicable n58 domain guarantees.
