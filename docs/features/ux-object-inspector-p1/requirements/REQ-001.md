## Statement

Холст остаётся главным, а одна панель показывает свойства текущего объекта.

## Acceptance Criteria

- [ ] Выделение области, фотозоны и надписи открывает соответствующие свойства и не сбрасывает холст.

- [ ] Разбиение, варианты, результат и экспорт доступны как режимы документа с сохранением истории.
