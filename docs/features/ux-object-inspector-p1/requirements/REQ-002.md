## Statement

Оператор до действия видит инструмент и объём затрагиваемого изображения.

## Acceptance Criteria

- [ ] Для кисти показано: одна область, весь исходный цвет или похожие соседи; смена режима при входе в Фото заметна.
- [ ] Слияние доступно при связном выделении, повторное разбиение — при одной области, фотозона — при подходящем выборе; недоступность объясняется рядом.
- [ ] Действия сочетаний клавиш доступны обычными кнопками; undo сохраняет прежние гарантии.

## Priority

P0 для n30: видимый режим и область действия кисти исправляются на текущем редакторе до перестройки инспектора (n25, P1). Общий приоритет фичи P1 относится к новой структуре панелей и не откладывает это локальное улучшение.
