## Context

REQ-001 did not define whether the unified inspector replaces the detailed photo-zone editor.

## Alternatives

1. Expose all photo-zone settings in expandable inspector groups.

## Decision

Retain the separate detailed photo-zone editor; expose basic properties in the unified inspector.

## Reason

The user selected option A, preserving the existing editor separation and keeping P1 focused on selection and action clarity.

## Consequences

The inspector provides basic photo-zone properties and an explicit action to open detailed editing on the existing screen.
