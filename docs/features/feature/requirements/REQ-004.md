## Statement

Оператор задаёт ширину и высоту пластины и перемещает рамку соответствующих пропорций по изображению. Работа становится частью изображения внутри рамки в размере пластины; области обрезаются, надписи и фотозоны перемещаются вместе с рамкой, действие можно отменить.

## Acceptance Criteria

- [ ] Изображение 3:4 после кадрирования под пластину 150 × 150 мм даёт работу 150 × 150 мм с частью изображения внутри выбранной рамки.
- [ ] Области целиком за рамкой удалены, пересекающие её обрезаны; слои экспортированного файла покрывают только пластину.
- [ ] Надписи и фотозоны внутри рамки сохраняют положение относительно изображения; оставшиеся снаружи удаляются с уведомлением.
- [ ] Отмена возвращает всё изображение и прежнее состояние работы.
