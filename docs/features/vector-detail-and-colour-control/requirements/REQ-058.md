## Statement

The system shall give every colour of a photo work a titanium colour of its own, in the first colouring and in every automatic mode, so that the work has as many layers as the number of colours set in the split settings, up to 29 and up to the number of colours in the palette, and shall offer no separate mode for it.

## Acceptance Criteria

- [ ] On the operator's work of 29 colours the first colouring and each of the modes 'Ближе к оригиналу', 'Сохранить тональность' and 'Случайно' use 29 of 29 layers
- [ ] With more colours than entries in the palette every entry is used once and the other colours take the nearest
- [ ] A colour no other wants takes the fastest entry within the tolerance, else the nearest
- [ ] The entries the operator kept are not given to other colours while others remain; the operator's choices stay in every mode
- [ ] There are no buttons 'Меньше слоёв' and 'Как можно больше разных цветов'; the API refuses those modes naming closest, tonality or random; a variant saved with the old mode still shows its name and restores
