## Statement

The system shall let the operator give a saved vector work another name, from the list of works and from the work itself, without changing anything else about the work.

## Acceptance Criteria

- [x] POST /api/vector/{id}/rename with {name} stores the stripped name and answers {id, name}; the list of works, the work, the plans list and the plan screen show it at once
- [x] A blank, whitespace-only, non-text or missing name is refused with 'give the plan a name' (translated) and changes nothing; an unknown or deleted work is 404; a plan that is not a vector work is refused
- [x] A rename adds no history entry and no document version, leaves undo, redo, 'изменена', the thumbnail and the exports untouched; undo after a rename goes on with the colouring and keeps the new name
- [x] Naming a work as it already is named writes nothing; any other rename writes one audit row vector_work_renamed with the plan id, the old and the new name
- [x] A file exported before keeps its name, the next export is named after the new name, and a copy made afterwards is named '<new name> (копия)'; renaming a copy leaves the original
- [x] A pencil beside the name on each card of the list, in the header of a photo work and on the long page of the other strategies opens the dialog 'Переименовать работу' with the name selected; Enter or 'Сохранить' saves with one request (also when pressed twice), 'Отмена' or the same name sends none, a blank name is refused before any request and the dialog stays open, a refused request keeps the dialog open for another try
- [x] The name shown in the card, the header and the title of the long page, and the labels of the pencil, change in place after saving; a long name is cut with an ellipsis in the header without breaking the one-screen layout
- [x] Covered by tests/test_vector_rename.py and tests/test_vector_workspace_ui.py
