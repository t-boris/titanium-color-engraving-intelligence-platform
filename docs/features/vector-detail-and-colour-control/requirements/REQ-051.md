## Statement

The system shall let the operator choose, when a photograph vector work is made and whenever it is split again, among the splitting algorithms the system supports, each described by the pictures it is for, and shall record which algorithm made each version of the split.

## Acceptance Criteria

- [x] The split settings and the form that makes a work offer the algorithms SLIC (default) and SEEDS, each with a description of what it is for; detail levels are not among them (DEC-076).
- [x] The choice travels with "Разбить заново" and with the creation of a work; an unknown algorithm is refused with a translated message and nothing changes.
- [x] The document and the history of each split record the algorithm; a work made before the choice reads as SLIC and can be split again.
- [x] Every algorithm offered splits a picture into regions that leave less than 0.5 % of it uncovered and less than 0.5 % covered twice, and gives the same split every time.
- [x] An algorithm is offered only after it was run through the real pipeline on at least a portrait, a photograph with thin lines and text, and flat shapes (DEC-080).
