## Statement

The system shall offer an AI colouring mode that, for a style the operator chooses, selects a measured titanium colour for every source colour of the work from the measured palette of the work's laser, lens and titanium, and shows the result as a previewable whole-work variant.

## Acceptance Criteria

- [x] The operator chooses a style before colouring: realistic, artistic, impressionism, cubism, or a free-text prompt (DEC-084: the four styles and a field for the operator's own description).
- [x] The AI is given only numbers (source colours in Lab, their shares of the area, which regions touch, the measured palette) unless the operator has allowed a reduced copy of the photograph for this work (DEC-084), and and every colour it returns is a measured colour of the work's laser, lens and titanium; an answer with any other colour, or with more recipes than the LightBurn layers allow, is refused with a translated message and the colouring is left as it was.
- [x] The result is one variant like those of the other automatic modes: it is previewed on the picture, can be restored, is undone as one operation, and keeps the operator's manual choices (editor DEC-075).
- [x] The variant records its style or prompt and the colours the AI chose; restoring it never asks the AI again.
- [x] Without an AI key, or offline, the mode is disabled and says why; the other colouring modes are unaffected.
- [x] Whether the source image's lightness order is kept is kept by default and a style's "свободная светлота" switch allows the model to change it (DEC-084; Artistic mode keeps it, DEC-079).
