## Statement

The system shall offer an AI colouring mode that, for a style the operator chooses, selects a measured titanium colour for every source colour of the work from the measured palette of the work's laser, lens and titanium, and shows the result as a previewable whole-work variant.

## Acceptance Criteria

- [ ] The operator chooses a style before colouring: realistic, artistic, impressionism, cubism, or a free-text prompt (the list is pending Q-007).
- [ ] The AI is given only what Q-005 allows, and every colour it returns is a measured colour of the work's laser, lens and titanium; an answer with any other colour, or with more recipes than the LightBurn layers allow, is refused with a translated message and the colouring is left as it was.
- [ ] The result is one variant like those of the other automatic modes: it is previewed on the picture, can be restored, is undone as one operation, and keeps the operator's manual choices (editor DEC-075).
- [ ] The variant records its style or prompt and the colours the AI chose; restoring it never asks the AI again.
- [ ] Without an AI key, or offline, the mode is disabled and says why; the other colouring modes are unaffected.
- [ ] Whether the source image's lightness order is kept follows Q-006 (Artistic mode keeps it, DEC-079).
