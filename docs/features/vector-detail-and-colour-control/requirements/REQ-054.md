## Statement

The system shall show a photo work on one screen, with its settings in tabs on the left, the picture in the middle and the editor's tools in tabs on the right, so that the page does not need to be scrolled.

## Acceptance Criteria

- [x] The work screen has a header (back to the list, name and summary, plan, copy, the file), left tabs Разбиение, Цвета, AI, Варианты and Файл, the picture in the middle and the editor's panel on the right in tabs Кисть, Слои and Цвета
- [x] At 1421 x 951 the page does not scroll (document height equals the window) and the tabs Разбиение, Цвета, AI, Варианты, Файл, Кисть and Слои show their content without an inner scroll for the reference work (28 colours, 16 layers); only a list too long for its panel (the source colours) scrolls inside it
- [x] The side menu folds away on this screen and the header's Меню opens it; other screens are unchanged
- [x] The open tab is remembered by the browser and is the same after the screen is built again (Разбить заново); the arrow keys move between tabs
- [x] The per-colour table opens in a window; the layers and the saved files of the file tab are listed, the layer list is folded
- [x] On a screen narrower than 1100 px the columns stack and the page scrolls as before
- [x] Without a key or without the language model's library the AI tab names the reason and the button is off; a missing library is a message, not a server error
