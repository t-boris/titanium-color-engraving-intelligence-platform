## Context

The operator: "нет возможности гладких линий". In 0.7.0 the field "Сглаживание границ, мм" is the Douglas-Peucker tolerance, so a larger value makes the line more angular, and the real low-pass along an arc is a fixed 1.2 px (0.15 mm). The portrait has 75 000 vertices for 290 regions. A prototype on the same arcs with the ends pinned: sigma 0.4 mm and 0.8 mm give visibly smooth contours with uncovered 0.00 % and overlap 0.00 %. The LightBurn format already carries curves: lightburn.py reads B primitives and the operator's own files use them; vectorize.py writes L only.

## Alternatives

1. Only a strength in mm, still straight segments
2. Fit curves but keep the strength as the tolerance

## Decision

"Сглаживание, мм" is the sigma of a Gaussian low-pass along every shared arc, its junction ends pinned, so both neighbours use the same smoothed arc and the map stays gapless. The simplification tolerance stops being a knob of the operator. Each arc is then fitted by cubic Béziers whose tangents are continuous inside the arc; corners and multi-region junctions stay corners. The preview draws the curves (SVG C), the LightBurn file carries them (B primitives); the flattened curve stays within 0.01 mm of the previewed one. Works made before keep their polylines until they are rebuilt.

## Reason

The operator chose "strength in mm and Bézier curves". A strength in the label's own unit does what the label says, and a curve is smooth in the file too, with fewer nodes than 60 000 short segments.

## Consequences

The arc record gets an optional curve form next to its points, read by the view, the editor merges, the coverage test and the export. Acceptance: continuous tangents on fixtures with a curve, a corner and a junction; uncovered and doubly covered each below 0.5 % on the portrait at 0.8 mm; the exported file read back by lightburn.py matches the preview.
