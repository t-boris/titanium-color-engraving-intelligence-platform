## Context

Artistic already requires reproducible variants within an operator-selected measured palette subset; its lightness constraint was unresolved.

## Alternatives

1. Preserve source lightness order while varying hues within the selected palette.
2. Allow unrestricted colour arrangements, including lightness inversions.

## Decision

Artistic shall vary hues within the selected measured palette subset while preserving the source image's lightness order.

## Reason

The operator selected preservation of source light and dark ordering.

## Consequences

Artistic variants must preserve source lightness order for automatically assigned colours. Existing manual-choice preservation remains applicable.
