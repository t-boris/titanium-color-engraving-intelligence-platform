## Context

The operator asked for colouring by AI with different prompts (artistic, realistic, impressionism, cubism) from all available colours, and said "доделай всё". REQ-050 was a draft waiting for Q-005, Q-006 and Q-007. The application already calls the model (research.openai_client, OPENAI_API_KEY from the environment or .env.local; the real app runs from the repository directory and finds it); no library is added. README promises that photographs stay on the computer.

## Alternatives

1. Numbers only, the photograph never
2. Numbers and a reduced photograph always
3. Lightness always kept, closed list of styles
4. The style decides about lightness

## Decision

Q-005 = C: by default the model receives only numbers (the work's source colours in Lab, their shares of the area, which regions touch, the measured palette); a reduced copy (512 px) is sent only after the operator allows it for that work, and the work remembers the permission. Q-006 = B: the order of light and dark of the source is kept by default (DEC-079), each style has a "свободная светлота" switch that allows the model to change it. Q-007 = B: a fixed list (реалистично, артистично, импрессионизм, кубизм) with a short description each, plus a field "своё описание"; the variant stores the style or the text and the colours the model chose and is never recalculated when restored.

## Reason

The operator accepted the recommended option of all three questions. The default keeps the promise of the README; the permission is explicit and per work.

## Consequences

REQ-050 becomes ready. Every colour in the answer is checked against the measured palette and the layer limit before anything is applied; a bad answer leaves the colouring unchanged. Tests use a fake client; no test calls the real service. The README's statement about photographs is extended with the permission.
