## Context

Different source images may benefit from different segmentation methods. The operator explicitly requested a choice of algorithms.

## Alternatives

1. Keep a single segmentation algorithm with adjustable detail presets.
2. Automatically select an algorithm without exposing a manual choice.

## Decision

Provide an explicit choice among supported photo-to-region segmentation algorithms before rebuilding Vector Work. Identify each algorithm and explain which image characteristics it is intended for. Detail presets must not be presented as distinct algorithms.

## Reason

The operator needs to choose a segmentation method appropriate to each image.
