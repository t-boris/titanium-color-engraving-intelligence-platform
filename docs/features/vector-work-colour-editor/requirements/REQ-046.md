## Statement

The system shall replace two or more titanium colours in use by one chosen titanium colour everywhere in the work.

## Acceptance Criteria

- [x] Choosing two or more titanium colours in the layers list and a target sets every source colour and area that showed a merged-away colour to the target.
- [x] The file then has one layer fewer per merged-away colour, and the totals show it.
- [x] Any automatic mode run afterwards keeps the merge, since it is the operator's choice.
- [x] A merge with fewer than two selected colours, or with a selected colour the colouring does not use, or with a target outside the palette, is refused with a translated message; one colour merged into another target counts as fewer than two (DEC-078).
