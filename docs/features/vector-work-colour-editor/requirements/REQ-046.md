## Statement

The system shall replace two or more titanium colours in use by one chosen titanium colour everywhere in the work.

## Acceptance Criteria

- [ ] Choosing two or more titanium colours in the layers list and a target sets every source colour and area that showed a merged-away colour to the target.
- [ ] The file then has one layer fewer per merged-away colour, and the totals show it.
- [ ] Any automatic mode run afterwards keeps the merge, since it is the operator's choice.
- [ ] A merge with fewer than two colours or a target outside the palette is refused with a translated message.
