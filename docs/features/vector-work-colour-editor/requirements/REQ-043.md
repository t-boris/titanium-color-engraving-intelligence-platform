## Statement

The system shall give every source colour of a photograph vector work a measured titanium colour as soon as the work is split or recoloured, without an acceptance step, and shall not block the LightBurn file because a colour lies outside the ΔE tolerance.

## Acceptance Criteria

- [x] After a split, a resplit or any automatic mode every source colour that has areas has a titanium colour: the fastest within the tolerance, else the nearest.
- [x] A colour beyond the tolerance is marked with its ΔE in the editor, and a switch outlines its areas on the picture; no accept button exists.
- [x] The file is blocked only when a chosen titanium colour is no longer measured, when the palette is empty, when nothing is left to engrave, or when the recipes exceed the LightBurn layers; each block says which.
- [x] Work 22 of the live data (28 colours, tolerance 0.05), opened on a copy, shows all 28 colours coloured and allows the export.
- [x] Choices made earlier with "accept" stay as the operator's choices.
