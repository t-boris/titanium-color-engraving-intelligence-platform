## Statement

Работы открываются из общего каталога с поиском, фильтрами и порциями.

## Acceptance Criteria

- [ ] Первая порция — не более 20 работ; видны миниатюра, имя, тип, размер, состояние и дата.
- [ ] Поиск, тип, лазер/линза/материал и сортировка по изменению совместимы; показаны счётчики и сброс.
- [ ] Есть переключаемая галерея, а состояние вида, поиска и места сохраняется после возврата.
