## Statement

Каталог управляет исходной работой без создания второй копии объекта или смешения работы с экспериментом.

## Acceptance Criteria

- [ ] Открытие ведёт в соответствующий редактор; смешанная работа остаётся одним документом с зонами и надписями.
- [ ] Переименование, копирование и удаление доступны в меню строки; удаление требует подтверждения.
- [ ] Фотография работы может появляться в экспериментах, но удаление проверки не подменяется удалением работы; старые ссылки открываются.
