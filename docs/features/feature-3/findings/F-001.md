## Finding

The new requirement introduces engraving-colour suggestions for the business-card workflow, while the existing card specification requires preparation for non-colour engraving. It is unclear whether this feature extends card preparation to colour engraving or whether the suggestions are informational and the existing export remains non-colour. This affects the meaning and use of the selected engraving colours in the finished card workflow.

> For source colours, the editor separately offers matching available engraving colours and lets the operator change the selection. / Support separate preparation of each business-card side for non-colour engraving

## Possible interpretations

- Extend the business-card workflow to prepare and export colour engraving using the selected colours.
- Keep card preparation non-colour and treat engraving-colour suggestions as information that does not change the existing export.

## Resolution

Выбранные цвета используются при подготовке и экспорте карточки для цветной гравировки. — see DEC-003.
