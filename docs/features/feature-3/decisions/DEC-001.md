## Context

The operator needs to recolour and arrange imported vector artwork.

## Alternatives

1. Edit the artwork only as a whole.
2. Also edit path shapes and nodes.

## Decision

Allow individual parts of imported vector artwork to be selected, recoloured, duplicated, moved, resized and rotated without path-node editing.

## Reason

This supports recolouring and composing artwork without requiring a full vector editor.

## Consequences

Imported artwork must expose independently editable parts; path-node editing is outside the chosen scope.
