## Context

Source appearance and achievable engraving colours serve different purposes.

## Alternatives

1. Replace source colours with suggested engraving colours.
2. Keep source colours and leave engraving selection entirely separate.

## Decision

Preserve source colours as design colours and separately suggest matching available engraving colours, with operator control over the selection.

## Reason

This preserves the source appearance while helping the operator prepare the design for engraving.

## Consequences

The editor must distinguish source design colours from suggested engraving colours and allow the operator to change engraving selections.
