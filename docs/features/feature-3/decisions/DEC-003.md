## Context

Feature-3 requires the editor to suggest available engraving colours and allow the operator to change the selection. Feature-2/REQ-003 currently specifies preparation of each card side for non-colour engraving.

## Alternatives

1. Treat engraving-colour suggestions and selections as informational; retain non-colour card preparation and export.
2. Defer engraving-colour matching while retaining source colours and manual recolouring.

## Decision

Use the selected engraving colours when preparing and exporting each business-card side for colour engraving.

## Reason

The team selected colour engraving as the intended use of the operator’s colour selections.

## Consequences

Update feature-2/REQ-003 to cover colour preparation and export for each card side to LightBurn. Define how selected colours relate to engraving settings and add acceptance criteria. Review feature-3/REQ-004 and REQ-005 for consistency with this export behaviour.
