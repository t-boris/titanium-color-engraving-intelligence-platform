# Discussion — Импорт и редактирование векторов для бизнес-карточки

### Answer to Q-001 · 2026-11-08

Насколько подробно нужно редактировать импортированный рисунок?

A. Редактировать отдельные части рисунка как объекты: выбирать, раскрашивать, копировать, перемещать, менять размер и поворачивать.

### Answer to Q-002 · 2026-11-08

Как должен работать подбор цветов по исходному рисунку?

C. Сохранять исходные цвета и отдельно предлагать соответствующие доступные цвета гравировки с возможностью изменения.
