## Statement

Allow the operator to compose a card design using independently editable imported vector parts, including selecting, recolouring, moving, resizing, rotating, duplicating and arranging them, without path-node editing, and retain those edits in the saved card work.

## Acceptance Criteria

- [x] The operator can select, recolour, move, resize, rotate and duplicate individual imported vector parts on a card side.
- [x] The operator can arrange imported parts using the editor's existing element actions, including layer order, grouping, ungrouping and deletion.
- [x] Path-node editing is not available for imported vector artwork.
- [x] After saving and reopening the card work, imported parts, their edits, design colours and engraving selections remain available for further editing.
