## Statement

Allow the operator to recolour individual imported vector parts, retain their source colours as design colours, and separately suggest available engraving colours matching the source colours with an operator-adjustable selection.

## Acceptance Criteria

- [x] The operator can manually change the design colour of an individual imported vector part.
- [x] Source colours remain available as design colours after import.
- [x] For source colours, the editor separately offers matching available engraving colours and lets the operator change the selection.
- [x] The editor distinguishes design colours from engraving colour selections and indicates when no matching engraving colour is available.
