## Statement

Allow the operator to import SVG and Adobe Illustrator vector artwork from the device into a business-card design as individually editable parts, preserving the supported source appearance and reporting import limitations. Path-node editing is out of scope.

## Acceptance Criteria

- [x] The operator can select an SVG or Adobe Illustrator file from the device and import its vector artwork into a card side.
- [x] Supported source appearance is retained in the imported artwork.
- [x] The operator can individually select, recolour, duplicate, move, resize and rotate parts of the imported artwork.
- [x] Path-node editing of imported artwork is not available.
- [x] The operator is informed if a file cannot be imported or contains content that cannot be preserved, without silently presenting an incomplete result as complete.
