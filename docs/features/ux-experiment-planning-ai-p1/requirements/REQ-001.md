## Statement

Пользователь выбирает цель и видит один объяснённый следующий тест до ручного перебора параметров.

## Acceptance Criteria

- [ ] Доступны цели цвета, текста, линий и изображения; рекомендация использует текущий контекст.
- [ ] До создания показаны что выяснит тест, размер и оценка времени; при нехватке данных названа причина.
- [ ] Ручной тип платы и полный перебор осей остаются доступны в расширенном режиме без потери ограничений лазера.
