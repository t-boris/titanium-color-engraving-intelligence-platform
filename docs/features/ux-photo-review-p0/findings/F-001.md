## Finding

The specification makes warnings the entry point for manual correction but does not establish access when automated checks report success and the operator sees incorrect contours. The current interface offers manual correction even with valid alignment (src/titanium_platform/ui/screens/ingest-review.js, render). Hiding those controls exclusively behind detected problems could remove that capability despite the stated requirement to preserve all manual correction. Specify that correction tools remain reachable from the photo review when no warning exists.

> Ручные средства проверки открываются из соответствующего предупреждения.

## Possible interpretations

- Manual correction tools are available only through automatically generated warnings.
- Warnings provide contextual shortcuts, while manual correction tools remain available even when automated checks pass.

## Resolution

Все ручные инструменты видны на этапе проверки независимо от предупреждений. Доступ прямой, но интерфейс становится более насыщенным. — see DEC-001.
