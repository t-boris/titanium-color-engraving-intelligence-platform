## Statement

During photo review, all manual tool entry points remain permanently visible regardless of automated warnings. Warnings show problems requiring attention and also provide contextual access to the relevant correction tools. This requirement remains draft; runtime and accessibility verification are pending, and this decision does not authorize implementation.

## Acceptance Criteria

- [x] Entry points for manual corners, workpiece alignment, matrix, all layers, and engraving tasks remain visible throughout photo review, whether or not automated warnings exist.
- [x] When no automated warning exists, every manual tool can be opened, including workpiece alignment for correcting alignment that automation considers valid.
- [x] Warnings show problems requiring attention while all manual tool entry points remain visible.
- [x] Each warning provides contextual access to the relevant manual tool.
- [x] Each blocking condition includes an explanation and a link to the tool needed to resolve it.
- [x] Acceptance and rejection preserve provenance, measurement rules, and linkage to the specific engraved version.
