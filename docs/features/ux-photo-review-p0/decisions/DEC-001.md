## Context

F-001 identifies ambiguity in REQ-002: warnings are specified as entry points for manual correction, but access is undefined when automated checks pass and the operator detects an error. The feature requires preserving all manual correction capabilities.

## Alternatives

1. Provide an always-available “Manual review” action, with contextual shortcuts from warnings.
2. Keep all manual tool entry points visible throughout photo review, regardless of warnings.
3. Provide an always-available “I see a problem” action that opens correction tools through an operator-reported issue.

## Decision

Keep all manual tool entry points visible during photo review, regardless of whether automated warnings exist. Warnings also provide contextual access to the relevant tool.

## Reason

The team explicitly selected direct, continuously visible access to manual tools and accepted the resulting increase in interface density. This resolves access when automated checks miss a problem.

## Consequences

Update REQ-002 to require permanently visible entry points for manual corners, workpiece alignment, matrix, all layers, and engraving tasks. Revise the exceptions-first principle: warnings show problems requiring attention, while manual tool entry points remain visible. Add acceptance coverage for opening every manual tool when no automated warning exists, including correcting alignment that automation considers valid. Preserve provenance, measurement rules, and linkage to the specific engraved version for acceptance and rejection. Runtime and accessibility verification remain pending; no implementation is authorized by this decision.
