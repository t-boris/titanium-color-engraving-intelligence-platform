## Statement

The system shall propose, where the knowledge of a photo mode is missing or still moving, the next photo-variations plate centred on the best known copy with smaller changes than the last plate, and make it with one press.

## Acceptance Criteria

- [x] A mode used in a work but never measured on this laser, lens and titanium gets a proposal for a first plate
- [x] After a measured variations plate the proposal is centred on its best copy with the changes halved
- [x] When the best copy is the centre and every change scores lower, the mode is marked settled and no plate is proposed
- [x] The proposal says what it will find and how big the plate is
