## Question

Should the 8-copy plate of a photo zone spend one copy on the dot width correction (0.01 mm), which a zone cannot use?

## Why it matters

A zone's «Подобрать настройки: 8 копий» varies power down and up, speed, line interval, dot width and two other dither kinds. A zone writes no dot width, so if that copy wins the zone still cannot take it; the copy only teaches what photo works (which can write it) would gain.

## Options

- **Slower speed instead**: For a zone the dot-width copy becomes speed −30 % (darker): every copy is a setting the zone can take; still 8 copies
- **Keep the dot width copy**: As now: the plate also tells whether photo works on this titanium gain from a dot width correction
- **Seven copies**: Drop the copy for a zone: a smaller plate

## Recommended

Slower speed instead
