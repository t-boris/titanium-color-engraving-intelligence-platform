# Лазерная мастерская

Локальное приложение для исследования режимов лазера, создания компактных экспериментальных плат LightBurn, совмещения RAW-фотографий с векторами файла и сохранения измерений. Исследование привязано к физическому лазеру, установленной линзе и конкретному материалу. Цели включают надписи, линии, маркировку, цвет, очистку, изображения, глубокую и 3D-гравировку и резку.

## Запуск

Нужен Python 3.11+; Node.js нужен для проверок интерфейса.

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/titanium-platform
```

Откройте [приложение](http://127.0.0.1:8765/#/research). Данные по умолчанию находятся в `~/.titanium-platform`; можно указать `--data-dir /path/to/data` и `--port 8765`.

Рабочая установка для оператора — колесо, установленное в отдельное окружение `~/.titanium-platform-app` (DEC-024), а не редактируемая копия из репозитория:

```bash
python -m build --wheel
~/.titanium-platform-app/bin/pip install --force-reinstall --no-deps dist/titanium_color_engraving_platform-<версия>-py3-none-any.whl
~/.titanium-platform-app/bin/pip install dist/titanium_color_engraving_platform-<версия>-py3-none-any.whl   # доставит зависимости, которых в окружении ещё нет
~/.titanium-platform-app/bin/python -c "import fastapi, uvicorn, multipart, numpy, scipy, sklearn, cv2, rawpy, openai"   # каждая объявленная библиотека должна импортироваться
~/.titanium-platform-app/bin/titanium-platform --data-dir ~/.titanium-platform --port 8765
```

Вторая команда нужна, потому что первая не ставит зависимости: без неё в окружении не оказывается библиотек, которые появились в проекте позже (так `openai` не попала в окружение, и AI-раскраска в приложении давала ошибку сервера 500; теперь без библиотеки кнопка выключена и объясняет причину). Из `~/.titanium-platform-app` работают и вызовы AI, поэтому первую проверку релиза делайте оттуда, на копии данных.

### 0.24.0: прогноз и результат — что шкала обещала до гравировки и что вышло (DEC-117)

- **Почему.** На «Inna Portrait-P1-30 150» прогноз был намного темнее результата и не показал жёлтых. Оператор: после принятых
  результатов нужен анализ, чтобы следующий прогноз был точнее. Первая часть этого — показать, где прогноз ошибся и почему.
- **«Прогноз и результат»** во вкладке «Результат» эксперимента с принятой фотогравировкой. Шкала строится по гравировкам, принятым
  раньше, на её ширине строк, как её показывала работа. Тон за тоном рядом прогноз и результат, медиана и максимум ΔE, доля в пределах
  5 ΔE и куда сдвинулось: светлее или темнее, желтее или синее.
- **На чём стоял прогноз** — факты с числами:
  - ширина строк среди измеренных (была ли измерена, между, вне — тогда взята ближайшая без пересчёта);
  - пластины и их толщина;
  - чистка;
  - чистый титан на фото. Если пластина и чистка те же, разница в нём — это свет снимка, а не металл.
- **Общий итог** по всем принятым фотогравировкам — мера, по которой проверяется каждое следующее изменение модели. На данных
  23.10.2026 прогноз до гравировки ошибался в среднем на 13,8 ΔE, а там, где ширина была измерена заранее, — на 10,2 ΔE.
- **API.** `GET /api/pairs/{id}/prediction-review` и `GET /api/prediction-reviews`.

### 0.23.0: фотозона открывается как работа фотогравировки (DEC-116)

- **Почему.** У фотозоны были только вид, шкала и мощности; серые всегда подбирались «по рисунку», и выбрать, как подобрать серые, было
  нельзя. Оператор: в фотозоне нужно то же, что в фотогравировке, — сохранить рисунок, подобрать серые, подцветить.
- **«Открыть»** на карточке фотозоны (вкладка «Фото» редактора) открывает зону на своём экране, как работу фотогравировки: слева шкалы
  лазера, линзы и титана работы, посередине картинка зоны рядом с прогнозом (вне зоны прозрачно), справа вкладки «Картинка», «Шкала»,
  «Подтверждение» (шкалы), «Точки». Там же «Вид:» с картинкой зоны в каждом виде, Min и Max или мощность точек, «Цвета по картинке»,
  «Как подбирать серые» («Сохранить рисунок» или «Ближайший цвет») и «Контуры». Ширина зоны — по её областям, она не меняется.
- **Отмена.** Каждое изменение — шаг векторной работы: «Отменить», «Повторить», Ctrl+Z и Ctrl+Shift+Z на экране зоны — её. Если шаг убрал
  зону, экран возвращает к работе. «← К работе» — обратно в редактор.
- **Файл и план.** Слой изображения зоны в файле LightBurn гравирует те же серые, что показывает прогноз. «План гравировки» и карточка зоны
  называют, как подобраны серые: «серые подобраны под цвета: ближайший цвет · контуры».
- **Старые зоны** открываются как были: серые подобраны «по рисунку», без контуров. Новая зона берёт настройки предыдущей.
- **Общий код.** Работа фотогравировки и фотозона подбирают серые одним кодом и одними сообщениями (`photo_state.py`, `photo-panels.js`);
  экран работы фотогравировки не изменился.
- **Дальше (0.23.1).** Вкладки «Раскраска» (цвета объектов, темы) и «AI» (правила частей) для зоны; объекты и части найдены один раз на всей
  картинке работы и вырезаны по зонам. До тех пор «Раскраски по объектам» у зоны нет.

### 0.22.4: допуск ΔE в «Новой векторной работе» — сразу и один раз

- **Почему.** Допуск ΔE не придумывается: он берётся из правил лазера с линзой или вводится в форме. Для JPT + F-Theta 174 мм его не было
  никогда, и форма говорила об этом только после «Создать работу», не подсказывая, какое число ввести.
- **Правило.** По решению оператора в правила JPT + F-Theta 174 мм сохранён ΔE 5 — предел, при котором две гравировки одного рецепта
  ещё совпадают (DEC-083). Пустое поле «Допуск ΔE» теперь значит ΔE 5.
- **Форма** сразу показывает, что в правилах: «из правил: 5» — пусто значит 5, число в поле только для этой работы; если допуска нет, поле
  обведено красным, подсказка говорит, что значат числа (ΔE 1 едва заметно, 2–3 мало, 5 — две гравировки одного рецепта ещё совпадают),
  а галочка «Запомнить для этого лазера с линзой» (включена) сохраняет введённое число в правила — один раз. Пустое поле без правила
  не отправляется: форма просит допуск и ставит курсор в поле.
- **Подсказка у «Титан»** говорит правду для каждой стратегии: «Фото» берёт цвета титана этой марки с любой его пластины, заливка, текст и
  линии — только рецепты этой заготовки (раньше всегда было «цвета другой заготовки не используются»).
- **Не изменено.** Заливке, тексту и линиям нужны валидированные или производственные рецепты; у JPT + F-Theta 174 мм их пока нет ни на одной
  пластине, поэтому для них форма честно предупреждает «все области окажутся без данных». У «Фото» 553 измеренных цвета.

### 0.22.3: во вкладке «Фото» щелчок выделяет, Esc снимает выделение

- **Почему.** Во вкладке «Фото» щелчок по картинке перекрашивал область кистью («Авто»), а не выделял: инструменты лежат во вкладке «Кисть»,
  их не видно, а кисть была выбрана. Выделение и кнопка «Сделать фотозоной» тоже были только во вкладке «Кисть». Esc снимал выделение, только
  если курсор ввода не стоял в поле: после мощности зоны, галочки или ползунка он не делал ничего; белая обводка под курсором оставалась.
- **Теперь** открыть «Фото» — значит выделять: инструмент становится «Выделение» (щелчок, Shift+щелчок, обвести мышью — лассо), блок
  «Выделение» с «Сделать фотозоной» и «Добавить в фотозону N» стоит над списком зон. «Выделить» у зоны больше не уводит на «Кисть». Вернувшись
  на «Кисть», вы видите выделение там же; инструмент остаётся «Выделение», кисть выбирается кнопкой.
- **Esc** снимает выделение откуда угодно (кроме открытого окна — там Esc закрывает окно), отменяет лассо, которое ещё рисуется, и убирает белую
  обводку под курсором (области или карточки зоны) до следующего движения мыши. Рамки фотозон остаются: это не выделение, а отметка того,
  что выйдет фотогравировкой.

### 0.22.2: фотозоны в «Плане гравировки»

- **Почему.** «План гравировки» векторной работы (кнопка в шапке работы) показывал только слои цвета: слоя изображения фотозоны в нём не было, хотя
  файл LightBurn его содержит. Перед гравировкой по плану нельзя было увидеть, что лицо пойдёт фотогравировкой и с какими настройками.
- **Теперь** после слоёв цвета идёт слой каждой фотозоны, например «C28 Photo 1 jarvis P20 · Фотозона 1 · Джарвис»: мощности (Min–Max для градаций
  серого, мощность точек для видов точками), частота, скорость, импульс, шаг строк, проходы; «Изображение (Image), режим …: картинка работы в
  областях зоны, вне зоны прозрачна»; в колонке «Прогнозный цвет» — картинка зоны, как она выйдет; число областей. Зона, которую нельзя
  гравировать (её шкала не измерена при этой ширине), показывает причину. Экспорт со страницы плана, как и раньше, пишет слои зон в файл.
- **Первое открытие после перезапуска приложения.** Страница плана работы с фотозоной в первый раз после перезапуска открывается около 2.5 с (дальше
  0.1 с): приложение один раз читает измерения шкал, так же как при первом открытии работы в редакторе (5 с) — это было и раньше.

### 0.22.1: выделение и фотозона обведены одной линией

- **Почему.** Выделение обводило каждую область отдельно: у лица из 108 областей — 108 тонких жёлтых контуров, на светлых цветах титана их почти не
  видно, и непонятно, что выделено целиком.
- **Теперь** выделенные области обведены одной общей линией: границы между двумя выделенными областями не рисуются, соседние области сливаются в одну
  фигуру. Линия жёлтая, на тёмной подложке, поэтому видна и на светлых, и на тёмных цветах. Так же одной фигурой обводится то, на что наведена мышь
  (карточка фотозоны, строка слоя, область заливки).
- **Фотозоны** во вкладке «Фото» обведены пунктиром (голубым) — каждая зона одной фигурой; на других вкладках картинка без рамок. Линия внутри
  зоны — граница области, которая в зону не вошла, или кусок зоны, не связанный с остальной её частью общей границей.
- После обновления перезагрузите страницу работы (Cmd+R): открытая страница остаётся на старой версии.

### 0.22.0: фотозоны — часть векторной работы гравируется фотогравировкой (REQ-073, DEC-114)

- **Почему.** Векторная работа заливала каждую область одним цветом титана, и лицо выходило мозаикой. Теперь часть картины остаётся векторами,
  а выбранные области — например, всё лицо — гравируются фотогравировкой самой картинки работы, на шкале серого, которую вы выбираете.
- **Выделить быстро.** Инструмент «Выделение»: щелчок, Shift+щелчок или **обведите мышью (лассо)** — выбираются области, которые внутри хотя бы
  наполовину; лассо с Shift добавляет к выделению, с Alt убирает. Сдвиг картинки в «Выделении» — пробел+перетаскивание или средняя кнопка мыши.
- **«Сделать фотозоной»** (под выделением): области выйдут фотогравировкой, на картинке зона сразу показана такой, какой выйдет. «Добавить в
  фотозону N» добавляет к уже сделанной, «Вернуть в цвета» возвращает области к цветам титана.
- **Вкладка «Фото»** (справа, рядом с «Кисть», «Слои», «Цвета») — каждая фотозона:
  - **Вид** — плитки с этой зоной в каждом виде: Градации серого, Порог, Упорядоченный (Байер), Аткинсон, Флойд–Стейнберг, Стаки, Джарвис,
    Газетный растр, Полутона, Эскиз; щелчок выбирает. «≈» — вид точками на этих настройках ещё не фотографировался: показана оценка по
    шкале, как в работах фотогравировки (0.21.0).
  - **Шкала серого** — шкала зоны с полосой её цветов (мощности зоны яркие) и «Другие шкалы этого лазера и титана: N»: у каждой — полоса
    цветов, скорость, частота, импульс, шаг строк и измеренный диапазон; щелчок по шкале делает её шкалой зоны.
  - **Min и Max** (градации серого) или **мощность точек** (виды точками, в файле Min = Max); **«Цвета по картинке»** — серые подобраны так,
    чтобы цвета титана шли за цветами картинки, сохраняя рисунок (как в работах фотогравировки); выключено — гравируются серые самой картинки.
  - «Выделить» выделяет области зоны, «Вернуть в цвета» распускает зону.
- **Новая зона** берёт лучшую измеренную шкалу лазера, линзы и титана работы (сначала с картой ColorChecker, потом больше гравировок), её
  измеренный диапазон при ширине зоны (длина строк, 0.20.0), градации серого и «Цвета по картинке»; следующая зона — настройки предыдущей.
- **Всё отменяется** (Ctrl+Z) и повторяется; копия работы сохраняет зоны; «Вернуть» вариант раскраски оставляет зоны как есть. Кисть
  «Участок» или «Заливка похожих» по области зоны красит её цветом титана и выводит из зоны, «Весь исходный цвет» зоны не трогает; заливка
  похожих останавливается на границе зоны. «Не гравировать» убирает область и из зоны. Слитая область остаётся в зоне, если там была хотя
  бы половина её площади; новое разбиение переносит зоны по площади.
- **Файл LightBurn.** После слоёв цвета — по слою изображения на зону, например «C28 Photo 1 grayscale P2-29» или «C28 Photo 1 jarvis P20»:
  настройки шкалы, режим вида, Min/Max или Min = Max = мощность точек. Картинка — картинка работы, вырезанная по рамке зоны, **вне зоны
  прозрачная** (LightBurn её не гравирует), 20 точек на мм (не больше dpi слоя), вырезана по тем же сглаженным границам, что и
  контуры векторов. Чистка C00 — вся работа, как раньше. Время зоны — в оценке времени; слои цвета и зоны вместе — не больше 28 (29 без
  маркеров), иначе файл не создаётся и сказано, что слить.
- **Слои.** Во вкладке «Слои» подробности каждого слоя (площадь, областей, время) — на своей строке, больше не обрезаются «…»; фотозоны — в
  конце списка с картинкой. В шапке работы и во вкладке «Файл» слои считаются вместе с фотозонами.
- **Быстрее.** Измерения шкал читаются один раз, пока данные не меняются: на работе «Inna + Boris» плитки видов — 0.05 с (было 0.3 с каждая),
  список шкал — 0.75 с первый раз и 0.05 с потом (было 1.6 с), виды зоны после изменения — 0.15–0.25 с. Любое действие в редакторе этой
  работы (574 области, палитра 553) по-прежнему занимает около 1.3 с — как и до 0.22.0; фотозона добавляет к нему до 0.2 с.
- **Что увидит существующая работа.** «Inna + Boris» открывается как раньше, без фотозон. У неё 27 слоёв из 28 — места ровно на одну зону;
  в проверке на копии данных лицо (108 областей лассо) убрало из файла один слой цвета, и после первой зоны осталось место ещё на одну.
- **Чего пока нет.** Прозрачность слоя изображения проверена чтением файла, как его читает LightBurn, и после сохранения в LightBurn 2.2, но не
  гравировкой на лазере. «Результат» (работа над ошибками) сравнивает только слои цвета — фотозоны не проверяются, и на картинке «как
  выгравировано» их нет. Поправки ширины точки (dotWidth) файл не пишет, как и в 0.21.0.

### 0.21.1: «Новая работа» спрашивает «Какая гравировка?» вторым шагом

- **Почему.** В 0.21.0 окно «Новая работа» спрашивало только картинку, название и ширину; вопрос о виде открывался уже после «Создать»,
  и в окне об этом говорила одна серая строка мелким шрифтом. Нажав «Новая работа», вопроса о виде не видно.
- **Теперь** «Новая работа» — одно окно в два шага. «Шаг 1 из 2: картинка» — картинка, название, ширина; «Дальше →». «Шаг 2 из 2: какая
  гравировка?» — ваша картинка в каждом виде, выбраны градации серого; щелчок по виду выбирает его, «Создать в «…»» создаёт работу в этом
  виде и открывает её. Так же со страницы «Шкалы серого» («Новая работа на этой шкале»).
- **«← Назад»** возвращает к шагу 1 с той же картинкой, названием и шириной. Работа, которую сделал шаг 1, удаляется, если уйти со
  второго шага не через «Создать»: «Назад», ×, Escape или щелчок мимо окна. Картинки в каждом виде считаются по уже загруженной картинке,
  поэтому шаг 1 её загружает.
- **Уже созданные работы** не меняются и при открытии ничего не спрашивают; вид меняет кнопка «Вид: …» над картинкой, как в 0.21.0.
- **Не сделано**, как и в 0.21.0: поправка ширины точки в файле (dotWidth), отдельная проверка гравировок работы в виде точками,
  ступенчатые границы между кусками фона.

### 0.21.0: «Какая гравировка?» — картинка в каждом виде; раскраска по объектам, как в раскраске (REQ-071, REQ-072, DEC-112, DEC-113)

- **Почему.** Новая работа фотогравировки не спрашивала, какой гравировкой её делать, и ни один вид, кроме градаций серого, нельзя было
  увидеть на своей картинке. И подобрать цвета можно было только всей картинке сразу, а нужно — губам, очкам, волосам, фону по отдельности.
- **«Какая гравировка?».** Новая работа сразу открывается с вопросом: под каждым видом, который красит титан, — ваша картинка, какой она выйдет
  на шкале работы. Градации серого, Порог, Упорядоченный (Байер), Аткинсон, Флойд–Стейнберг, Стаки, Джарвис, Газетный растр, Полутон, Эскиз;
  3D-срез не предлагается — он даёт рельеф, а не цвет. В работе вид меняет кнопка «Вид: …» над картинкой; «Отменить» его возвращает.
  - **Вид точками — оценка по шкале.** Каждая точка бьёт на одной мощности: её цвет — цвет шкалы при этой мощности, между точками — очищенный
    титан; издалека глаз их смешивает. Пока этот вид на ваших настройках не гравировался, картинка подписана «оценка». Точка — самая короткая
    строка, а цвет зависит от длины строки (0.20.0), поэтому настоящие точки могут выйти другого оттенка. Узор — по опубликованным алгоритмам;
    у Упорядоченного, Газетного и Эскиза узор LightBurn не опубликован — показан похожий.
  - **Мощность точек** — одна, вместо Min и Max: сначала та, чей цвет сильнее всего отличается от титана; меняется щелчком по полосе шкалы.
    «Точки вблизи» — квадрат 4 мм точка в точку при dpi шкалы.
  - **Файл LightBurn**: C00 — чистка, C01 — картинка как загружена, в режиме этого вида, Min = Max = мощность точек; точки ставит LightBurn.
  - **«Проба этого вида»** — пластина с одной полоской в этом виде на мощности точек. Выгравируйте, сфотографируйте, загрузите — картинка
    покажется по измеренным тонам вместо оценки.
  - Подбор серых под цвета, контуры, правила частей и раскраска — для градаций серого; в виде точками они сохраняются и вернутся с градациями серого.
- **Раскраска по объектам** — вкладка «Раскраска» и третий способ подбора серых. Объекты картинки: куски фона (до четырёх — небо, город, столб…),
  волосы, кожа лица и тела, одежда, «другое» (очки и всё надетое), губы и глаза (если лицо найдено; глаза за очками остаются в «другом»).
  - Выберите объект и щёлкните цвет на полосе цветов шкалы — это его **основной цвет**. Светлые и тёмные места объекта ложатся вокруг него по
    соседним цветам шкалы (шаг не больше 5 ΔE): от золотого не прыгает в синий, губы остаются губами. «Темнее/светлее» сдвигает тона объекта
    по его семейству; «Авто» убирает цвет — объект как при «Сохранить рисунок».
  - **Темы** дают цвет всем объектам сразу: «Тёплая», «Холодная», «Контрастная», «Случайно» (каждый раз другие цвета), «Всё — авто».
  - **«Раскрасить по просьбе»**: напишите своими словами («очки золотом, фон синий, губы красные») — AI выберет каждому объекту цвет шкалы;
    видит только числа (объекты, их цвета на фото, цвета шкалы), картинку — только если это разрешено во вкладке «AI». Ответ с цветом не со
    шкалы отправляется AI обратно один раз; второй плохой ответ ничего не меняет.
  - Прогноз и файл LightBurn — одна картинка; каждый шаг отменяется «Отменить»; копия работы сохраняет цвета.
- **Что увидит существующая работа** (Boris - 3, Inna Portrait): то же, что в 0.20.3 — градации серого, «Сохранить рисунок» или «Ближайший цвет»,
  ни один объект не раскрашен. Вопрос «Какая гравировка?» задаётся только новой работе; у существующей вид меняет кнопка «Вид», раскраска —
  вкладка «Раскраска».
- **Чего пока нет.** Поправки ширины точки (dotWidth, «коррекция точки» LightBurn) файл не пишет. Гравировки работы в виде точками
  сравниваются с прогнозом, как гравировки других настроек; отдельно это не проверено. Границы кусков фона идут по сегментации на 400 пикселей
  и бывают ступенькой.

### 0.20.3: шкала с одной плиты работает на любой плите той же марки; файл картинки сначала чистит (REQ-069, REQ-070, DEC-110, DEC-111)

- **Почему.** Пластину «Шкалы серого» вы гравировали на «Big Plate 150», а файл работы для «Small Plate» предпросмотр отказывался показывать:
  «в этом режиме цвет ещё не измерялся». Измерения делились по записи о плите, а не по титану.
- **Один титан — одна марка.** Все плиты одного материала и марки (например, Grade 5) — один титан, какими бы ни были их названия, размер, толщина,
  партия и поверхность; запись без марки — сама по себе. Так считают шкалы серого и их кривые, предпросмотр файла, работы фотогравировки, палитра
  векторной работы (она уже так считала) и «Карта цветов».
  - Шкала, гравированная на двух плитах одной марки, одна, с гравировками обеих; на карточке: «Титан Grade 5 · измерена на Big Plate 150, Small Plate».
  - Работа остаётся на своей плите; гравировка работы на другой плите той же марки считается её шкалой и проверяет прогноз.
  - На «Карте цветов» одни настройки на двух плитах одной марки — один цвет с уверенностью по всем гравировкам; фильтр «Материал» предлагает марки,
    а точка по-прежнему называет плиту. Номера цветов палитры не меняются: сохранённые векторные работы открываются как были.
  - Не изменились (они хранят плиту в своих ключах): записи знаний модели, находки исследования, предложения конструктора, подсказки плит.
- **Предпросмотр** при отказе говорит, где этот режим измерен (лазер, линза, титан), и кнопкой «Показать на нём» переключается туда. В работе
  фотогравировки кнопка «Файл в предпросмотре» открывает её файл в «Предпросмотре фотогравировки» сразу с её лазером, линзой и титаном.
- **Файл LightBurn картинки сначала чистит.** C00 — чистка лазера (CLEAN-CROSSHATCH-…, как у пластин и векторных работ) прямоугольником ровно по
  картинке, первой; картинка — слой-изображение C01. Так и у работы, и у «Картинки на шкале»: шкалы измерены на очищенных пластинах. Время работы
  включает чистку и говорит, сколько из него чистка. Фото гравировки берёт C00 за свидетеля чистки и измеряет картинку на C01. Файлы, сделанные
  до 0.20.3, чистки не имеют и измеряются как раньше.

### 0.20.2: кожа светлая и ровная, черты лица видны; на картинке «как её видит LightBurn» никаких линий (REQ-068, DEC-109)

- **Почему.** На гравировках «Inna Portrait» кожа шла одним тоном без градиента, тени — почти чёрными пятнами, губы терялись: светлые серые картинки
  попадают на ровный светлый край шкалы, а тени — на её спуск к тёмному. «Сохранить рисунок» из 0.20.1 брал серый каждого пикселя из любого места шкалы,
  и соседние участки кожи получали далёкие мощности (серо-голубой рядом с загаром) — пятна. Контуры 0.20.1 были включены у всех работ: на тёмной шкале
  они рисовали белые штрихи прямо по вашей картинке.
- **«Сохранить рисунок»** теперь раскладывает тона картинки по одной плавной полосе шкалы: от её самого светлого цвета к самому тёмному, по порядку
  мощности, светлота только убывает, а оттенок меняется как можно меньше на каждом шаге (голубой «горб» шкалы при той же светлоте пропускается).
  Соседние тона получают соседние мощности — кожа остаётся ровной, с градиентом. Зерно и квадраты JPEG сглаживаются (0,25 мм, границы остаются),
  губы, глаза, тени лица (1,5 мм) подчёркиваются, средние тона светлеют. Оттенки картинки (голубое небо и т. п.) не повторяются — вся картинка
  в цветах этой полосы; повторяет их «Ближайший цвет». На «Inna Portrait» порядок светлого и тёмного — 99 % на каждой из ваших шкал.
- **В LightBurn** левая половина превью — это и есть файл: при подборе серый каждого пикселя — мощность, выбранная ради цвета, поэтому LightBurn
  показывает другую картинку, чем прогноз; теперь это ровный чёрно-белый портрет, а не пятна.
- **«Контуры»** выключены по умолчанию и работают только при «Подобрать серые под цвета»; без подбора галочка недоступна и картинка гравируется
  как загружена.

### 0.20.1: подбор серых сохраняет рисунок, потерянные границы обводятся (REQ-067, DEC-108)

- **Почему.** На «Inna Portrait» 100 мм «ближайший цвет» отдал светлой коже лба серый, который на этой шкале даёт тёмный загар: лоб стал почти чёрным, а губы,
  у которых цвет кожи и цвет губ шкала даёт почти одинаковым, пропали.
- **«Сохранить рисунок»** (новый выбор под «Подобрать серые под цвета», по умолчанию): светлота картинки раскладывается по порядку по светлоте, которую шкала даёт
  при ширине работы; мелкие детали (до 1,5 мм на титане) усиливаются; берётся серый с ближайшим цветом, где светлота важнее оттенка вчетверо. На большой ровной
  площади из почти таких же серых (до 3 ΔE дальше) берётся тот, чей цвет меньше меняется с мощностью. На «Inna Portrait» лоб стал светлым, порядок светлого и
  тёмного совпадает с картинкой на 98 % (у «ближайшего цвета» — 91 %). **«Ближайший цвет»** остаётся выбором.
- **«Контуры»** (галочка, включены): граница картинки (8 ΔE поперёк 0,5 % ширины, не меньше 0,3 мм), которая на титане потерялась бы (меньше 6 ΔE), обводится
  линией 0,3 мм — самым тёмным серым шкалы, у светлого блика или на тёмном — самым светлым. Короче 1 мм не обводится (текстура кожи, блики); внутри части с правилом
  «Один тон» — тоже. Вкладка «Картинка» говорит, какая доля картинки обведена.
- Прогноз и файл LightBurn — одна и та же картинка: подбор, правила частей и контуры делаются в файле с разрешением слоя, в прогнозе — с разрешением экрана,
  в миллиметрах одинаково. Выбор и контуры сохраняются в работе, отменяются и повторяются; старые работы открываются с «Сохранить рисунок» и контурами.

### 0.20.0: цвет зависит от размера гравировки — фотогравировка и векторные работы это учитывают (REQ-066, DEC-107)

- **Почему.** «Inna Portrait» шириной 150 мм вышла соломенной и золотой там, где шкала по полоскам 38,4 мм обещала фиолетовый и синий (медиана 14 ΔE), а те же серые,
  нарисованные цветами, измеренными при 150 мм, совпали с гравировкой (медиана 4,9 ΔE). Рабочая гипотеза: лазер возвращается к точке через строку, на короткой строке
  титан не успевает остыть и окисляется дальше. Поэтому каждое измерение помнит длину строки, при которой сделано: у полоски шкалы — её ширину, у картинки — её ширину,
  у заливки — сколько лазер проходит по строке через неё (слой заливается целиком, фигуры на одной строке складываются). Длина берётся из файла LightBurn пары; в базу
  ничего не пишется.
- **Работа фотогравировки** берёт цвета шкалы при своей ширине: измеренные (в пределах 10 %), между двумя измеренными ширинами (по логарифму длины) или, вне их,
  у ближайшей — без экстраполяции; плашка под картинкой и вкладка «Картинка» говорят, какие. Смена ширины пересчитывает прогноз, подбор серых, правила частей, время и файл.
- **«Проба на ширине работы»** во вкладке «Картинка»: пластина «Шкалы серого» с одной полоской шириной с работу на настройках её шкалы, Min и Max. Выгравируйте,
  сфотографируйте, загрузите — шкала станет измеренной при ширине работы. На лазере должна стоять линза, с которой измерена шкала.
- **Шкалы серого** показывают, при каких ширинах измерены, и шкалу при каждой из них. Подтверждение шкалы и проверка гравировки работы сравнивают гравировку только
  с гравировками своей ширины или ширин вокруг неё; гравировка другой ширины — «сравнить не с чем», а не «не подтверждает»; число гравировок прогноза — только этой ширины.
- **Пластины.** У «Шкал серого» новая ось «ширина полоски, мм» (ступень — 1/16 ширины, не уже 1 мм). Новая пластина «Размер заливки»: одни и те же рецепты полосками
  высотой 4 мм разной ширины (по умолчанию 5, 20, 50 и 100 мм, до 28 полосок). Пластина может быть до 300 мм (предел по умолчанию — 100 мм, у «Размера заливки» — 150 мм, иначе 100 мм не помещается);
  поле линзы проверяется, как раньше.
- **Векторная работа.** Каждый слой показан цветом, который его рецепт даёт при длине строк этого слоя: в редакторе, на картинке в списке, в ΔE и в цветах, которые
  обещает файл. Автоматический выбор сравнивает исходный цвет с цветом рецепта при длине строк областей этого цвета. В «Слоях» у каждого слоя — длина его строк (↔, подсказка
  говорит, при каких длинах измерен цвет рецепта); слой, чей цвет при такой длине не измерен, отмечен цветом предупреждения. Сейчас почти все цвета палитры измерены квадратами 3–8 мм, а слои работ длиннее: их цвета остаются измеренными, но
  помечены, пока пластина «Размер заливки» не измерит сдвиг.
- **Ограничения.** Длина строки считается вдоль угла сканирования слоя; cross-hatch и заливка «по группам» считаются как одна заливка. «Цветная гравировка» (по знаниям)
  размер пока не учитывает.

### 0.19.4: эксперимент можно переименовать (REQ-065)

- На странице эксперимента рядом с названием — карандаш: окно «Переименовать эксперимент», название в поле, «Сохранить» или Enter.
- Меняется только название. У платы или работы это название её плана; у готовой работы без платы — название гравировки, общее для всех её фото.
- Пустое название не принимается; то же самое название ничего не записывает; каждое переименование — одна запись в журнале.

### 0.19.3: гравировка работы фотогравировки проверяет прогноз (REQ-064, DEC-106)

- **Файл несёт имя работы.** «Файл LightBurn» работы записывает её идентификатор (TCE-P-…) в заметки файла. Фото гравировки, загруженное с этим файлом, привязывается к работе
  само, даже если работа при загрузке не выбрана; на экранах проверки, анализа и эксперимента — ссылка «Работа фотогравировки» на экран работы.
- **Гравировки работы.** Вкладка «Подтверждение» работы начинается с её гравировок: «Загрузить фото гравировки» (лазер, линза и титан взяты из работы) и каждое фото работы —
  его состояние, Min и Max в файле и, когда проверку примут, каждый серый картинки: какой цвет для него предсказывают остальные гравировки этих настроек и какой получился, ΔE,
  медиана и «подтверждает прогноз», если медиана не больше 5 ΔE, — так же, как подтверждение шкалы. Полосы «Прогноз» и «Получилось» — от белого (Min) к чёрному (Max),
  таблица «По серым» раскрывается. Фото с другими настройками, чем шкала работы, сравнивается с гравировками своих настроек и говорит об этом. Принятое фото входит в шкалу.
- **Фото, совмещённое по картинке, читается так, как совмещено.** Раньше для картинки из файла программа угадывала, какой её край верхний, по тому, темнеет ли фото вместе
  с серым, и принимала измерение, только если темнеет. У титана цвета шкалы не темнеют шаг за шагом (золото, фиолетовый, синий…): картинка могла быть прочитана вверх ногами,
  а фото отброшено как «слабое». Теперь, если фото совмещено по картинке самого файла, она читается так, как совмещена, и совмещение — доказательство. Для любой работы
  с картинкой; уже принятые фото не меняются, пока их не перемерить.
- **Ограничение.** Серые фото сравниваются полосами по 16 соседних серых, а фото слегка размыто. Там, где цвет титана быстро меняется с мощностью (синие и фиолетовые
  тона), полоса смешивает соседние цвета, и разница в ней больше, чем на самом деле; медиана по всем серым от этого почти не меняется. На копии ваших данных фото работы
  «Inna Portrait», нарисованное ровно по её шкале, дало медиану 2,8 ΔE, а в двух полосах около 13–15 % — 15–19 ΔE.

### 0.19.2: «Отменить» и «Повторить» в работе фотогравировки; AI заново с картинки (REQ-063)

- **Отменить и повторить.** В шапке работы — «Отменить» и «Повторить» (Ctrl+Z и Ctrl+Shift+Z, когда курсор не в поле ввода), как в редакторе векторной работы. Отменяется любое
  изменение того, что гравируется: шкала, Min и Max, ширина, подбор серых, правило части, ответ AI — по шагу, до 50 шагов; после отмены ползунки, ширина, правила и пояснение AI
  на экране — такие, какой стала работа. Разрешение отправлять AI картинку отменой не включается. Копия работы начинается без истории.
- **AI заново с картинки.** «Попросить AI» показывает AI нынешние правила частей, и он меняет то, о чём вы просите (можно уточнять по шагам). «Заново с картинки» — AI начинает
  с картинки без правил, и его ответ заменяет их все. «Все части как есть» рядом с таблицей частей убирает все правила сразу. «Вернуть как было» больше нет: это делает «Отменить».

### 0.19.1: «Попросить AI» поменять части картинки работы фотогравировки (REQ-062, DEC-105)

- **Вкладка «AI».** В работе фотогравировки напишите своими словами, что изменить («всё как есть, черно-белое, а кожу сделать равномерно светлой», «платье фиолетовым, ярким»),
  и нажмите «Попросить AI». AI предлагает правило для каждой части картинки, работа сразу показывает прогноз на титане, а «Вернуть как было» возвращает правила, какие были до ответа.
- **Части картинки.** Модель сегментации людей (MediaPipe, работает на этом компьютере) находит фон, волосы, кожу тела, кожу лица, одежду и прочее; в таблице — доля каждой части и её
  цвет на фото, а «Части на картинке» показывают их цветами поверх снимка. На картинке без людей всё — фон.
- **Правила.** «Как есть» — серые картинки; «Цвета фото» — каждому пикселю серый с ближайшим цветом на шкале; «Чёрно-белое» — только серые, которые на этом титане выходят почти
  серыми; «Цвет» — цель, светлое и тёмное части сохраняются; «Один тон» — один серый на всю часть (он стирает всё внутри неё, поэтому ровную кожу лучше задавать цветом). Серые всегда
  подбираются на шкале работы по вашим измерениям, не моделью, поэтому видно, что достижимо; «ΔE к цели» — насколько близко шкала подходит к желаемому. Каждое правило можно
  поменять вручную, без AI. Правила хранятся в работе, переходят в копию и в файл LightBurn; время гравировки от них не меняется (в градациях серого проходится каждый пиксель).
- **Что уходит в AI.** Только числа: пожелание, части с долей и цветом, 16 серых шкалы с их цветами на титане и текущие правила. Уменьшенная картинка — только если для этой
  работы включено «Отправить AI уменьшенную картинку». Ответ проверяется до применения; плохой ответ один раз возвращается модели с причиной, второй отклоняется, и работа не меняется.
  Нужен `OPENAI_API_KEY`; без него кнопка выключена и объясняет почему, а правила можно задавать вручную.

### 0.19.0: работы фотогравировки — как векторные работы (REQ-061, DEC-104)

- **Мои работы.** «Фотогравировка» открывается списком работ, как «Векторная работа»: у каждой — прогноз картинки на титане, название с карандашом, размер, шкала, титан, Min и Max,

- **Новая работа.** Картинка, название (по умолчанию — имя файла) и ширина на титане. Работа сразу встаёт на лучшую измеренную шкалу с её измеренными Min и Max и открывается.
- **Работа на один экран.** Слева шкалы (выбрана шкала работы), посередине ширина, «подобрать серые под цвета», Min и Max, полоса «серый → цвет» и картинка рядом с прогнозом, справа
  вкладки «Картинка», «Шкала», «Подтверждение», «Точки». Всё, что меняете, сохраняется в работе сразу: другая шкала (картинка остаётся, Min и Max становятся её измеренным диапазоном),
  Min и Max, ширина, подбор серых. В шапке — «← Мои работы», «Шкалы серого», «Сделать копию» и «Файл LightBurn» (слой-изображение в режиме градаций серого с настройками работы).
  Работу можно закрыть и открыть позже — картинка и настройки хранятся на этом компьютере. Если измерения шкалы удалены, работа открывается и говорит, что шкалу нужно выбрать заново.
- **Шкалы серого.** Обзор шкал — отдельной страницей по кнопке «Шкалы серого»: шкалы слева, Min и Max, полоса и таблица серых посередине, подтверждение, точки и виды справа; кнопка
  «Новая работа на этой шкале».
- **Пока не сделано.** Файл работы ещё не несёт её идентификатор: фото выгравированной работы измеряется как обычная фотогравировка и входит в шкалу, но к работе не привязывается
  (сделано в 0.19.3). «Попросить AI» поменять части картинки — следующий выпуск (сделано в 0.19.1).

### 0.18.1: пластина «Шкалы серого», сохранённая в LightBurn, читается целиком (DEC-103)

### 0.18.0: фотогравировка — четвёртый раздел; шкалы «серый → цвет» по вашим гравировкам; время каждой работы (REQ-059, REQ-060, DEC-100…DEC-102)

- **Меню.** Фотогравировка стоит четвёртой. «Цветная гравировка» убрана из меню (это и есть векторная работа), её адрес работает. Полосная форма и прогноз по файлу LightBurn открываются из раздела.
- **Шкалы серого.** Шкала — это один режим градаций серого: лазер, линза, титан, скорость, частота, импульс, шаг линий и проходы постоянны, меняются только Min/Max. Точки «мощность → цвет» берутся
  только из ваших гравировок в режиме серого (фото и ступени шкал). Заливки с теми же настройками показаны рядом как справка: на пластине 95 они расходятся с картинкой до 36 ΔE (DEC-100). Для выбранных
  Min/Max видны полоса «серый → цвет», таблица серых 255…0 с мощностью и цветом и проверка: каждая гравировка сравнивается с кривой остальных. Режим A (150 мм/с, 60 кГц, 300 нс, 0,0169 мм; Motorcycle и
  Girl on a bike) в тёмной половине подтверждается (1–3 ΔE), в светлой нет (10–16 ΔE): светлую часть решит пластина.
- **Картинка на шкале.** Загрузите PNG или JPG, задайте ширину и Min/Max: рядом с картинкой — прогноз гравировки, её время и файл LightBurn со слоем Image (dpi = 25,4 / шаг линий). Кнопка «подобрать
  серые под её цвета» для цветной картинки ставит каждому пикселю серый, который на этой шкале даёт ближайший цвет.
- **Пластина «Шкалы серого».** Кнопка в разделе открывает её в диалоге платы: каждая плитка — слой Image с 16 ступенями от белого к чёрному. По умолчанию строки — шаг линий 0,0127 / 0,0169 / 0,0212 /
  0,0254 мм (2000 / 1500 / 1200 / 1000 dpi), столбцы — скорость; Min/Max общие. После фото и проверки каждая плитка становится шкалой, а строки покажут, какой шаг удобнее 0,0169. Импульс 300 нс у
  этого лазера не является шагом (есть 250 и 350), поэтому плата берёт настоящие шаги.
- **Время каждой работы.** На странице эксперимента (плата — по своему файлу, готовая работа — по файлу, который гравировался), на странице плана и у картинки на шкале: «Время гравировки ≈ …» и время
  каждого слоя. Время считается по линиям сканирования настоящих фигур файла, около 1 мс на каждый отрезок линии (DEC-101). Сверено с вашими замерами: Inna + Boris 150 мм — 3,1 ч (у вас около 3 ч),
  100 мм — 1,65 ч (у вас 1,5–2 ч). Переходы между отдельными фигурами не учитываются.
- **Чтение файлов LightBurn.** LightBurn записывает контур один раз, а одинаковые по устройству фигуры дальше ссылаются на него по номеру. Платформа этих ссылок не понимала и читала такие фигуры как
  незамкнутые линии без площади: в Inna + Boris 9_backup — 222 фигуры из 574, всего в 8 ваших файлах (DEC-102). Теперь они читаются целиком, снимки с контурами перерисуются (версия рисунка 3).
  Сделанные раньше измерения не менялись; повторная проверка работы учтёт эти фигуры.

### 0.17.0: виды фотогравировки и работы, где часть векторная, а часть фото (REQ-053, REQ-054, DEC-095)

- **Какие бывают фотогравировки.** Для 11 режимов слоя-изображения LightBurn (градации серого, порог, упорядоченный, Аткинсон, дизеринг, Стаки, Джарвис, газета, полутон, эскиз, 3D-слайс) платформа

- **Состав работы.** Проверка пары разбирает файл по слоям в порядке прожига: очищающий прямоугольник, цветные заливки (Scan), слой-изображение (Image), линии (Cut). Показано, сколько площади занимает
  только заливка, только фото и оба вместе, и сколько каждого слоя остаётся видно. Если картинка лежит поверх заливок (≥ 5 % площади), так и написано.
- **Заливка и фото в одной работе.** Слой-изображение бьёт только там, где его картинка непрозрачна, а не по всему прямоугольнику. Раньше вырез в картинке не учитывался, и все заливки под ним
  назывались «на 100 % гравируются повторно». На вашем Джокере раньше не измерялась ни одна из 7 заливок, теперь измеряются все 7; цвет слоя-изображения перестал загрязняться фигурой (L* 48 → 84).
  Где картинка действительно лежит поверх заливок (девушка в стиле ар-деко, Лана), заливки остаются неизмеренными, и проверка объясняет почему: слой, режим, доля площади.
- **Тональный профиль без прозрачных пикселей.** Дыры в картинке больше не попадают в белый уровень профиля. На «Девушке на мотоцикле» профиль не изменился (тот же rho 0,898).
- **Насколько гравировки повторяются.** У измеренного цвета слоя показан разброс по пикселям, а у кривой «мощность → цвет» — расхождение независимых гравировок в ΔE. В предпросмотре сказано, какая доля
  картинки лежит там, где гравировки расходятся больше 5 ΔE, и какая — там, где измерила только одна. На «Девушке на мотоцикле» это 52,5 % картинки и 26,2 % (до 39,3 ΔE).
- **Прогноз для режимов точек.** Режимы Аткинсон, Джарвис, Стаки, дизеринг, газета, полутон и упорядоченный больше не отклоняются: их тон предсказывается по тональным профилям, снятым в том же режиме
  при тех же настройках и той же мощности точек. Кривая идёт по темноте серого, ползунков Min и Max нет. Растрирование не моделируется. Порог, эскиз и 3D-слайс по-прежнему отклоняются с причиной:
  у них нет тонов, которые можно измерить. Профили, снятые поверх векторных заливок, не используются: их цвет — заливка, смешанная с точками.
- **Что остаётся допущением.** Простая фигура на слое-изображении (рамка) ничего не гравирует; порог режима «порог» — середина серого; в градациях серого белое бьётся на Min (так сказано в
  документации и на форумах, но не измерено). Реальной пары в режиме точек в базе нет, поэтому этот прогноз проверен только на синтетических работах.

### 0.16.0: замена цвета в редакторе, откуда известен цвет, файл для LightBurn без переворота и лишних линий (REQ-051, REQ-052, DEC-093, DEC-094)

### 0.15.1: проверка фото не измеряет слои, которых на фото нет там, где их рисует файл (REQ-050, DEC-092)

- **Слой остался на старом месте.** Если в LightBurn картинку уменьшили и сдвинули, а слой скрыт («Показать» выключено), инструменты LightBurn его пропускают, и он стоит там, где его оставил
  файл работы, а все остальные слои уехали. Проверка сравнивает ваш файл с последним экспортом работы, находит сдвиг и масштаб, которые разделяют остальные слои (по каждой оси, с учётом
  отражения), и называет слои, оставшиеся на месте. Они не измеряются, не двигают окно привязки и не рисуются на наложении; в замечаниях сказано, какие это слои и до скольких процентов
  уменьшен остальной файл. Слой, который вы поменяли руками (его фигуры не совпали ни со старым местом, ни с новым), и файл, в котором ничего не сдвигали, не трогаются.
- **Вывод слоя выключен.** Слой с выключенным «Вывод» не гравировали, поэтому его не измеряют и не записывают в знания (раньше он записывался как голый титан с настройками этого рецепта).

  Чтобы увидеть это на уже загруженной фотографии, нажмите «Проверить заново».

### 0.15.0: карта цветов — уверенность, источники и фильтр сомнительных цветов (REQ-049, DEC-091)

- **Уверенность при выборе цвета.** Нажмите на цвет на карте или найдите рецепт: рядом показан кружок того же размера, что на карте, число уверенности, сколько гравировок совпало
  («2 из 3 совпали») и предупреждение, если цвет менялся при тех же настройках. Для гравировки, которую не повторяли, сказано, что уверенность не оценена.

- **Фильтр «Скрыть цвета, в которых не уверены».** «Диаметр меньше 1» — это кружок меньше, чем у одной гравировки, которую не повторяли: расходящихся гравировок не меньше, чем совпавших
  повторов. Такие цвета помечены «сомнительный»; фильтр запоминается вместе с остальными и действует и на карту, и на поиск. На ваших данных сомнительных цветов сегодня 20 из 610.
- Серверу: `GET /api/colors` и `GET /api/colors/search` принимают `hide_doubtful`; каждый цвет несёт `doubtful`, ответ карты — `recipes` (источники рецептов, которые гравировали больше раза),

### 0.14.0: работа над ошибками — результат гравировки против того, что обещал файл (DEC-090, REQ-047)

- **Зачем:** чтобы то, что вы видите в работе, совпадало с тем, что выгравировано. После каждого файла LightBurn, сделанного из работы, вы снимаете результат и принимаете фото как обычно;
  вывод записывается в саму работу.
- **Что запоминает работа:** при каждой выгрузке файла по каждому слою — настройки, цвет, который показывал предпросмотр, его основа, площадь и области. Раньше хранилось только число слоёв.
- **Сравнение:** слои гравированного файла и файла работы сопоставляются **по настройкам** (допуск на округление LightBurn), а не по номеру: гравировали не обязательно тот файл, который выгрузила
  работа (у проверки 77 «Inna + Boris 2» ни один из 16 слоёв не совпал с файлом «Inna + Boris», и экран так и пишет). По каждому слою: обещанный и измеренный цвет, ΔE, сдвиг светлоты,
  насыщенности и оттенка; слой «заметно отличается» от 5 ΔE (или от ошибки карты на этом фото, если она больше). Причины — только то, что видно по самим измерениям: блик выше белого
  квадрата, другая основа измерения, фото без карты, плохая карта, общий сдвиг почти всех слоёв (это про экспозицию или партию титана, а не про рецепты). Нет причины — не выдумывается.
- **Где смотреть:** вкладка «Результат» в работе (две картинки одной работы: «как обещал файл» и «как получилось»; слои строками, подробности по нажатию), строка в карточке работы в списке,
  блок «Вывод по работе» в отчёте по фото. При приёмке фото сообщение называет работу, в которую записан вывод.
- **Остальные работы:** после приёмки, перемера или удаления фото пересчитываются все работы этого лазера и линзы: сколько слоёв ушло от обещанного последним файлом больше чем на 5 ΔE.

  и «Применить все замены». Замена — обычная правка работы с отменой; выгравированный файл и ваши ручные выборы система сама не трогает. Слой, рецепт которого работа больше не использует,
  не считается; работа, из которой файл не делали, ничего не обещала и не помечается.
- **Работы, выгруженные до 0.14.0:** обещание восстанавливается по слоям работы, пока раскраска не менялась после выгрузки, и помечено «приблизительно».

  изменение параметров лазера (мощность, скорость) здесь не предлагаются: заменяется цвет другим измеренным, а не настройки.

### 0.12.0: уверенность в цвете настроек (REQ-045, DEC-083)

У каждых настроек (тот же лазер, линза, титан и рецепт) теперь есть **уверенность в цвете**, и программа предпочитает более уверенные цвета.

- **Повторилось и совпало — уверенность растёт.** Гравировки с отличием цвета не больше ΔE 5 считаются совпавшими. Две совпавшие дают 0,50, три 0,60, четыре 0,67 и так далее. Одна гравировка не повторялась: уверенность «не оценена», а в выборе она стоит между цветом, который менялся, и цветом, который повторялся.
- **Менялось — уверенность падает.** Каждая гравировка, не совпавшая с остальными, снижает уверенность. Если совпала не больше половины гравировок (например, одна гравировка жёлтая, другая тёмно-коричневая), настройки помечены «цвет менялся при тех же настройках»: автоматические режимы их не берут, пока повторная гравировка не прояснит цвет, а вручную выбрать можно.
- **Старый цвет заменяется новым.** Цветом настроек считается тот, на котором совпало больше всего гравировок; при равенстве побеждает группа с самой новой гравировкой. Была жёлтая, переделали тёмно-коричневой — цвет теперь тёмно-коричневый (уверенность низкая); ещё одна коричневая — цвет подтверждён. Одна выбивающаяся гравировка среди совпавших цвет не двигает: раньше цвет был средним арифметическим всех, то есть оттенком, которого никто не снимал.
- **Лучшее измерение заменяет худшее.** Если те же настройки измерены и по эталонной карте, и по чистому титану снимка, и «как снято», в палитре работы остаётся (для автоматики) измерение по эталонной карте; остальные помечены «заменён», но остаются в списке, и сохранённые работы продолжают на них ссылаться.
- **Внутри допуска ΔE более уверенный цвет берётся раньше более быстрого** (прежде внутри допуска побеждал самый быстрый).
- **Где это видно.** Палитра работы (колонка «Уверенность»: число, «2 из 3 совпали», пометки «цвет менялся» и «заменён»; в окне выбора цвета то же), поиск на «Карте цветов» (расстояние считается до согласованного цвета настроек, а не до ближайшего единичного измерения), страница знания («Совпали по цвету»). **На карте цветов диаметр кружка зависит от уверенности**: одиночная гравировка — средний кружок, повторы с тем же цветом крупнее, цвет, который менялся, мельче; подсказка кружка называет уверенность.
- Измерения не меняются (REQ-001): уверенность и согласованный цвет считаются при каждом чтении.
- На ваших данных (копия базы): из 539 рецептов на карте 23 повторялись, у 11 из них гравировки расходятся на ΔE от 7 до 23; в палитре работы «Inna + Boris» из 505 цветов 3 помечены «цвет менялся» и 16 «заменён»; ΔE 5 — предположение модели (в данных повторы согласуются на 0,8–4,1, расхождения лежат от 7), его можно поменять в одном месте (`agreement.AGREEMENT_DE`).

### 0.6.0: редактор цветов векторной работы

Каждый исходный цвет раскрашен сразу: самый быстрый цвет титана в пределах допуска ΔE, иначе ближайший; цвет дальше допуска помечается и по галочке «Показать далёкие от оригинала» обводится на картинке, но файл не блокирует. Редактор — большая картинка (колесо — масштаб, перетаскивание — сдвиг, вид «Титан», «Исходные цвета», «Оригинал») и панель: кисть (щелчок меняет участок, весь исходный цвет или заливку похожих соседей с порогом ΔE; наведение обводит, что изменится), пипетка (Alt+щелчок), выделение (Shift+щелчок), палитра всех измеренных цветов, слои титана («Слить в один»), исходные цвета («Объединить исходные цвета»), «Слить в один контур» для соседних участков. Ctrl+Z / Ctrl+Shift+Z отменяют и повторяют любые действия, включая слияния.

### 0.5.2: быстрые экраны

Нарисованные фотографии и наложения хранятся в `cache/renders/` папки данных (производные данные: папку можно удалить в любой момент, картинки нарисуются заново). Первый показ картинки занимает столько же, сколько раньше; чтобы и он был быстрым, после обновления один раз выполните:

```bash
~/.titanium-platform-app/bin/titanium-platform warm-cache --data-dir ~/.titanium-platform
```

### 0.5.0: векторная работа по фотографии

«Векторная работа» → «Фото: цветные области»: фото делится на 2–29 цветов (28 с метками; очистка всегда первая) без зазоров между областями; лица, глаза и губы находятся автоматически (модель OpenCV YuNet, лицензия MIT, в пакете) и делятся детальнее, важные области можно добавить или убрать вручную. Затем каждому цвету назначается измеренный цвет титана этого лазера, линзы и заготовки (самый быстрый в пределах допуска ΔE), цвет можно сменить у всей группы или одной области, есть автоматическая перекраска («Ближе к оригиналу», «Сохранить тональность», «Случайно», «Меньше слоёв») и оценка времени гравировки. Файл LightBurn делается только после того, как у каждого цвета есть рецепт. На карте цветов у каждого рецепта показано время на см² и есть фильтр «не дольше».

### Обновление до 0.4.0

Профили лазера убраны (DEC-042, DEC-063): каждая запись хранит лазер и линзу, с которой работа гравировалась (или «линза неизвестна»). При первом запуске 0.4.0 база переводится на новую схему: сначала делается копия `backups/titanium-before-0.4.0-<время>.sqlite`, затем все таблицы перестраиваются в одной транзакции; измерения не меняются. Версии до 0.4.0 открыть переведённую базу не могут — для отката остановите приложение и верните копию из `backups/`. Если базу перевести нельзя, приложение не запускается и пишет, что исправить.

Новые экраны: «Настройки» (титан, стенды съёмки с эталонными значениями карты, правила оценки для лазера и линзы, слой маркеров), «Векторная работа» (изображение → редактируемые контуры → файл LightBurn), «Предпросмотр фотогравировки» (как будет выглядеть фото при заданных Min/Max и режиме), «Выводы» (анализ накопленных результатов и предложения следующих опытов).

На экране «Эксперименты» кнопка «Создать плату» предлагает тип «Малые квадраты · 1–4 пробы». Размер каждого заполненного квадрата — 3 или 5 мм; один квадрат 3 мм без меток занимает 6 × 6 мм с технологическими полями. Для автоматического совмещения фото можно добавить QR и четыре метки — тогда та же плата занимает 19 × 19 мм. Начальный предел всей платы — 25 × 25 мм, его можно изменить до создания. «Показать размер» сообщает фактический габарит и площадь очистки. Если квадраты не помещаются в заданный прямоугольник, приложение создаёт отдельные LightBurn-файлы, каждый с первым слоем локальной очистки; ссылки на все части появляются сразу после создания. Предел 100 × 100 мм остаётся только верхней границей.

На экране **AI-исследователь** выберите лазер с линзой, заготовку и измеримую цель. AI (`gpt-6.1-sol`) читает паспорт и накопленные результаты, предлагает следующий тест, по прямой просьбе создаёт один проверенный `.lbrn2` и даёт ссылку на скачивание. После гравировки загрузите фактически использованный файл и RAW-фото, проверьте наложение и примите измерения. Только после этого выводы о режимах получают ссылку на фото-доказательство. Проверка глубины, 3D-рельефа и сквозного реза требует дополнительных физических измерений; фото сверху их не доказывает.

Для AI нужен `OPENAI_API_KEY` в окружении или в локальном `.env.local` в корне репозитория. `.env.local` исключён из Git. Паспорт, контекст исследования, история вопросов и результаты инструментов отправляются в OpenAI API при запросе AI; сами фотографии остаются локальными в текущем рабочем процессе. Исключений два, и оба — только после вашего разрешения для этой работы: раскраска векторной работы с помощью AI и «Попросить AI» в работе фотогравировки отправляют уменьшенную копию картинки (до 512 px); без разрешения уходят одни числа (цвета, доли, соседство или части картинки, измеренные цвета титана).

## MCP

Те же операции доступны локальному MCP-клиенту через stdio:

```bash
.venv/bin/titanium-research-mcp --data-dir ~/.titanium-platform
```

Сервер предоставляет инструменты чтения лазеров/материалов и результатов, создания исследовательской сессии, предпросмотра и экспорта теста, совмещения загруженного фото и сохранения гипотезы. Он не управляет лазером и использует ту же SQLite-базу, что и браузерное приложение. При настройке внешнего MCP-клиента укажите приведённую команду как исполняемый stdio-сервер.

## Проверка

```bash
.venv/bin/python -m pytest -q
```

Экспорт проверяется обратным чтением `.lbrn2` собственным парсером. Перед физической гравировкой проверьте файл в установленной версии LightBurn. В приложении AI-предложения и результаты без эталонной цветовой карты остаются предварительными; стандартные цветовые рекомендации требуют принятых и скорректированных измерений.

Технические решения и требования: [документация проекта](docs/features/titanium-color-engraving-intelligence-platform/overview.md).
