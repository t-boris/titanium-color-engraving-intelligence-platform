# Лазерная мастерская

Локальное приложение для исследования режимов лазера, создания компактных экспериментальных плат LightBurn, совмещения RAW-фотографий с векторами файла и сохранения измерений. Исследование привязано к физическому лазеру, установленной линзе и конкретному материалу. Цели включают надписи, линии, маркировку, цвет, очистку, изображения, глубокую и 3D-гравировку и резку.

## Запуск

Нужен Python 3.11+; Node.js нужен для проверок интерфейса.

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/titanium-platform
```

Откройте [приложение](http://127.0.0.1:8765/#/research). Данные по умолчанию находятся в `~/.titanium-platform`; можно указать `--data-dir /path/to/data` и `--port 8765`.

Рабочая установка для оператора — колесо, установленное в отдельное окружение `~/.titanium-platform-app` (DEC-024), а не редактируемая копия из репозитория:

```bash
python -m build --wheel
~/.titanium-platform-app/bin/pip install --force-reinstall --no-deps dist/titanium_color_engraving_platform-<версия>-py3-none-any.whl
~/.titanium-platform-app/bin/pip install dist/titanium_color_engraving_platform-<версия>-py3-none-any.whl   # доставит зависимости, которых в окружении ещё нет
~/.titanium-platform-app/bin/python -c "import fastapi, uvicorn, multipart, numpy, scipy, sklearn, cv2, rawpy, openai"   # каждая объявленная библиотека должна импортироваться
~/.titanium-platform-app/bin/titanium-platform --data-dir ~/.titanium-platform --port 8765
```

Вторая команда нужна, потому что первая не ставит зависимости: без неё в окружении не оказывается библиотек, которые появились в проекте позже (так `openai` не попала в окружение, и AI-раскраска в приложении давала ошибку сервера 500; теперь без библиотеки кнопка выключена и объясняет причину). Из `~/.titanium-platform-app` работают и вызовы AI, поэтому первую проверку релиза делайте оттуда, на копии данных.

### 0.18.2: картинка на шкале остаётся при выборе другой шкалы, прогноз пересчитывается сам (BUG-002)

- **Что было не так.** В «Фотогравировке» при выборе другой шкалы блок «Картинка на этой шкале» строился заново: выбранная картинка, ширина и прогноз пропадали, картинку приходилось
  выбирать снова для каждой шкалы.
- **Что сделано.** Блок картинки один на весь экран. При выборе другой шкалы картинка остаётся и сама показывается на новой шкале (с её Min и Max). Прогноз пересчитывается и без кнопки:
  при выборе файла, смене ширины, Min и Max и галочки «подобрать серые». Если ответ для прежней шкалы приходит позже, он не заменяет прогноз на выбранной. Кнопка «Показать на титане»
  отправляет картинку заново (нужна, если приложение перезапускали: загруженные картинки хранятся только в памяти).

### 0.18.1: пластина «Шкалы серого», сохранённая в LightBurn, читается целиком (DEC-103)

- **Что было не так.** Фото пластины TCE-A93B49E6 выровнялось по меткам, но три плитки из четырёх с импульсом 250 нс дали «0 пикселей», а у плиток с 350 нс не было картинки. Причин две. LightBurn 2.2
  хранит одинаковую картинку один раз: у второй плитки строки нет данных, только тот же `SourceHash`, а имя файла своё (…-PW350.png); платформа искала пропущенную картинку только по имени файла.

  измеряются, у каждой 16 ступеней из 16. Тест воспроизводит ваш случай: пластина, сохранённая так, как её сохранил LightBurn 2.2.

- **Что показала пластина.** На шаге 0,0169 ни 250, ни 350 нс не повторяют Motorcycle и Girl on a bike: на пластине уже при мощности 7–11 % идут фиолетовый и синий, а на этих работах до 13 % держится
  соломенный (светлая половина расходится на 24–29 ΔE, тёмная на 10–13). Импульсы между собой близки, значит дело не в импульсе. Настройки слоя совпадают; отличаются длина строки (150 мм у работ и
  38 мм у плитки) и шаг очистки (0,04 и 0,05 мм). Шкала с пластины поэтому пока не подтверждает режим A и не подтверждается им.

### 0.18.0: фотогравировка — четвёртый раздел; шкалы «серый → цвет» по вашим гравировкам; время каждой работы (REQ-059, REQ-060, DEC-100…DEC-102)

- **Меню.** Фотогравировка стоит четвёртой. «Цветная гравировка» убрана из меню (это и есть векторная работа), её адрес работает. Полосная форма и прогноз по файлу LightBurn открываются из раздела.
- **Шкалы серого.** Шкала — это один режим градаций серого: лазер, линза, титан, скорость, частота, импульс, шаг линий и проходы постоянны, меняются только Min/Max. Точки «мощность → цвет» берутся
  только из ваших гравировок в режиме серого (фото и ступени шкал). Заливки с теми же настройками показаны рядом как справка: на пластине 95 они расходятся с картинкой до 36 ΔE (DEC-100). Для выбранных
  Min/Max видны полоса «серый → цвет», таблица серых 255…0 с мощностью и цветом и проверка: каждая гравировка сравнивается с кривой остальных. Режим A (150 мм/с, 60 кГц, 300 нс, 0,0169 мм; Motorcycle и
  Girl on a bike) в тёмной половине подтверждается (1–3 ΔE), в светлой нет (10–16 ΔE): светлую часть решит пластина.
- **Картинка на шкале.** Загрузите PNG или JPG, задайте ширину и Min/Max: рядом с картинкой — прогноз гравировки, её время и файл LightBurn со слоем Image (dpi = 25,4 / шаг линий). Кнопка «подобрать
  серые под её цвета» для цветной картинки ставит каждому пикселю серый, который на этой шкале даёт ближайший цвет.
- **Пластина «Шкалы серого».** Кнопка в разделе открывает её в диалоге платы: каждая плитка — слой Image с 16 ступенями от белого к чёрному. По умолчанию строки — шаг линий 0,0127 / 0,0169 / 0,0212 /
  0,0254 мм (2000 / 1500 / 1200 / 1000 dpi), столбцы — скорость; Min/Max общие. После фото и проверки каждая плитка становится шкалой, а строки покажут, какой шаг удобнее 0,0169. Импульс 300 нс у
  этого лазера не является шагом (есть 250 и 350), поэтому плата берёт настоящие шаги.
- **Время каждой работы.** На странице эксперимента (плата — по своему файлу, готовая работа — по файлу, который гравировался), на странице плана и у картинки на шкале: «Время гравировки ≈ …» и время
  каждого слоя. Время считается по линиям сканирования настоящих фигур файла, около 1 мс на каждый отрезок линии (DEC-101). Сверено с вашими замерами: Inna + Boris 150 мм — 3,1 ч (у вас около 3 ч),
  100 мм — 1,65 ч (у вас 1,5–2 ч). Переходы между отдельными фигурами не учитываются.
- **Чтение файлов LightBurn.** LightBurn записывает контур один раз, а одинаковые по устройству фигуры дальше ссылаются на него по номеру. Платформа этих ссылок не понимала и читала такие фигуры как
  незамкнутые линии без площади: в Inna + Boris 9_backup — 222 фигуры из 574, всего в 8 ваших файлах (DEC-102). Теперь они читаются целиком, снимки с контурами перерисуются (версия рисунка 3).
  Сделанные раньше измерения не менялись; повторная проверка работы учтёт эти фигуры.

### 0.17.2: на снимке видны все слои, найденные по картинкам, а в шапке — версия (REQ-056, REQ-057, DEC-098, DEC-099)

- **Что было не так.** После 0.17.1 диплом (пара 105) выравнивался правильно, но рамка стояла только у печати: слои, у которых в файле выключен вывод (орёл, подписи, весь текст, очищающий прямоугольник),
  не рисовались, хотя проверка нашла три картинки. В замечаниях при этом было написано, что эти слои «не гравировались», а на фотографии они видны.
- **Что сделано.** Если работа найдена по картинкам файла, на снимке обводятся и слои с выключенным выводом, там, куда их помещает найденная работа, своим цветом (светло-голубым); они по-прежнему не измеряются.
  Слои, «оставленные позади» (REQ-050), по-прежнему не рисуются. Замечания теперь говорят то, что видно на фото: «картинка слоя есть на пластине, хотя вывод выключен (выгравирована раньше)» и «слой не измеряется, его контур нарисован там, где его помещает найденная работа».
- **Что проверено на паре 105.** Контуры двух текстовых слоёв (97 649 и 25 975 пикселей контура) лежат на буквах: яркость границы под контурами наибольшая при нулевом сдвиге, отклонение 1–2 пикселя (0,05–0,1 мм при 19,7 пикс/мм).
  Новая проверка не нужна: снимок перерисовывается из сохранённой проверки; тексты замечаний обновятся при следующей проверке.
- **Версия в шапке.** Рядом с названием стоит `v0.17.2`; приложение один раз спрашивает её у сервера (`/api/version`), а если сервер не ответил, метка не показывается. Она показывает версию запущенного сервера; чтобы
  страница загрузила новые скрипты, по-прежнему нужен Cmd+R.

- **Что было не так.** Фото законченного диплома (пара 105) не выравнивалось: в файле включён только слой с печатью, а остальные слои (картинки орла и подписей, текст, очищающий прямоугольник) были выключены

- **Что сделано.** Все слои файла лежат в одной системе координат, поэтому достаточно найти любой один. Если контуры рисунка и самая большая картинка работу не нашли, платформа читает масштаб с линейки

  масштабе во всех восьми поворотах и отражениях, **в том числе картинки слоёв с выключенным выводом**: на пластине, выгравированной раньше, они видны. Берётся тот поворот, в котором картинки сходятся в одном положении;
  дальше каждая уточняется, и по их углам строится одно преобразование. Такие слои по-прежнему не измеряются (REQ-050), а оператору сказано, какие слои нашли работу.
- **Что проверено.** Пара 105: масштаб линейки 19,64 пикс/мм (по картинкам 19,67), найдены все три картинки, они сходятся в пределах 0,13 мм, рамка слоя C05 ложится на печать, а нижний левый угол очищающего
  прямоугольника — во внутренний угол угольника. Линейка на 19 других реальных фото (фото из пар 84–104): на 4 фото линейки нет, и она не найдена; на остальных 15 найдена, и там, где масштаб известен по уже принятому
  выравниванию, совпадает в пределах 0,2–3,2 % (пары 88, 90–93, 102); на фото пар 103 и 104 шаг делений прочитан вдвое меньше (поэтому пробуется и удвоенный масштаб); на фото пары 89 линейка лежит в плоскости
  стола, а пластина в рамке выше, масштаб другой, и этим путём такая работа не ищется. Пары с картинками (88, 93) этот путь не принимает: портреты в цвете слабо похожи на исходную картинку, их находит прежний путь.

### 0.17.0: виды фотогравировки и работы, где часть векторная, а часть фото (REQ-053, REQ-054, DEC-095)

- **Какие бывают фотогравировки.** Для 11 режимов слоя-изображения LightBurn (градации серого, порог, упорядоченный, Аткинсон, дизеринг, Стаки, Джарвис, газета, полутон, эскиз, 3D-слайс) платформа
  знает, что в нём задаёт серый уровень (мощность, плотность точек, края, глубина), какие настройки слоя важны и что она умеет предсказывать. Это видно на проверке снимка и в предпросмотре.
  Из файла читаются Min и Max мощность, негатив, «сквозной» режим, число ячеек и угол полутона.
- **Состав работы.** Проверка пары разбирает файл по слоям в порядке прожига: очищающий прямоугольник, цветные заливки (Scan), слой-изображение (Image), линии (Cut). Показано, сколько площади занимает
  только заливка, только фото и оба вместе, и сколько каждого слоя остаётся видно. Если картинка лежит поверх заливок (≥ 5 % площади), так и написано.
- **Заливка и фото в одной работе.** Слой-изображение бьёт только там, где его картинка непрозрачна, а не по всему прямоугольнику. Раньше вырез в картинке не учитывался, и все заливки под ним
  назывались «на 100 % гравируются повторно». На вашем Джокере раньше не измерялась ни одна из 7 заливок, теперь измеряются все 7; цвет слоя-изображения перестал загрязняться фигурой (L* 48 → 84).
  Где картинка действительно лежит поверх заливок (девушка в стиле ар-деко, Лана), заливки остаются неизмеренными, и проверка объясняет почему: слой, режим, доля площади.
- **Тональный профиль без прозрачных пикселей.** Дыры в картинке больше не попадают в белый уровень профиля. На «Девушке на мотоцикле» профиль не изменился (тот же rho 0,898).
- **Насколько гравировки повторяются.** У измеренного цвета слоя показан разброс по пикселям, а у кривой «мощность → цвет» — расхождение независимых гравировок в ΔE. В предпросмотре сказано, какая доля
  картинки лежит там, где гравировки расходятся больше 5 ΔE, и какая — там, где измерила только одна. На «Девушке на мотоцикле» это 52,5 % картинки и 26,2 % (до 39,3 ΔE).
- **Прогноз для режимов точек.** Режимы Аткинсон, Джарвис, Стаки, дизеринг, газета, полутон и упорядоченный больше не отклоняются: их тон предсказывается по тональным профилям, снятым в том же режиме
  при тех же настройках и той же мощности точек. Кривая идёт по темноте серого, ползунков Min и Max нет. Растрирование не моделируется. Порог, эскиз и 3D-слайс по-прежнему отклоняются с причиной:
  у них нет тонов, которые можно измерить. Профили, снятые поверх векторных заливок, не используются: их цвет — заливка, смешанная с точками.
- **Что остаётся допущением.** Простая фигура на слое-изображении (рамка) ничего не гравирует; порог режима «порог» — середина серого; в градациях серого белое бьётся на Min (так сказано в
  документации и на форумах, но не измерено). Реальной пары в режиме точек в базе нет, поэтому этот прогноз проверен только на синтетических работах.

### 0.16.0: замена цвета в редакторе, откуда известен цвет, файл для LightBurn без переворота и лишних линий (REQ-051, REQ-052, DEC-093, DEC-094)

- **Заменить цвет прямо в редакторе.** На вкладке «Цвета» у каждого исходного цвета есть кнопка «Заменить»: открывается то же окно выбора, что и в таблице, цвет ставится вручную, а «Автоматически»
  возвращает выбор автоматике. Над строками объяснено: исходный цвет — цвет области на вашей картинке, справа цвет титана, которым он будет выгравирован.
- **«Не гравировать» вместо «Исключить».** Кнопка так и называется, подсказка говорит, что все области этого цвета не попадут в файл и останется только чистка; строка пишет «не гравируется»,
  а вернуть цвет можно кнопкой «Гравировать». То же для выделенных областей.
- **Откуда известен цвет.** У каждого цвета показано, из каких гравировок он известен: «3 гравировки: 2 теста, 1 работа». Тест — плата, проверка лазера или матрица параметров; работа — векторная
  работа или любая готовая гравировка (в том числе загруженный файл). Для каждой гравировки есть ссылки на эксперимент, разбор и, для векторной работы, на саму работу. То же видно на карте цветов.
- **Насколько цвет стабилен.** «Проверен повтором» (две гравировки и больше совпали), «одна гравировка, не повторялась» или «сомнительный» (гравировки расходятся). На образцах палитры зелёная
  точка — проверен повтором, красная — сомнительный.
- **Окно выбора цвета.** Порядок: ближайшие к исходному, самые стабильные, самые быстрые; флажок «Только проверенные повтором»; если текущий цвет не проверен повтором, сверху предложены проверенные
  цвета, ближайшие к нему («Стабильнее и похоже на текущий цвет»). Выбранный цвет показывает все свои гравировки.
- **Файл для LightBurn открывается ровно.** Раньше картинка в LightBurn стояла вверх ногами (рот выше очков), и её приходилось переворачивать вручную. Файл векторной работы теперь записан с `MirrorY`,
  как файлы плат; координаты не менялись. Новый экспорт нужен, чтобы увидеть результат: старые файлы остаются прежними.
- **Прямые линии через лицо.** Причина найдена: у четырёх кривых Безье (слои 15 и 27 рядом с точкой 56 × 72 мм) был записан только один «хвост»; LightBurn подставляет вместо второго начало
  координат, и кривая уходила к левому верхнему углу и обратно. Теперь у каждой кривой записаны оба хвоста; форма границ не изменилась (проверено на вашей работе: те же 718 областей).

### 0.15.1: проверка фото не измеряет слои, которых на фото нет там, где их рисует файл (REQ-050, DEC-092)

- **Слой остался на старом месте.** Если в LightBurn картинку уменьшили и сдвинули, а слой скрыт («Показать» выключено), инструменты LightBurn его пропускают, и он стоит там, где его оставил
  файл работы, а все остальные слои уехали. Проверка сравнивает ваш файл с последним экспортом работы, находит сдвиг и масштаб, которые разделяют остальные слои (по каждой оси, с учётом
  отражения), и называет слои, оставшиеся на месте. Они не измеряются, не двигают окно привязки и не рисуются на наложении; в замечаниях сказано, какие это слои и до скольких процентов
  уменьшен остальной файл. Слой, который вы поменяли руками (его фигуры не совпали ни со старым местом, ни с новым), и файл, в котором ничего не сдвигали, не трогаются.
- **Вывод слоя выключен.** Слой с выключенным «Вывод» не гравировали, поэтому его не измеряют и не записывают в знания (раньше он записывался как голый титан с настройками этого рецепта).
- На вашем файле «Inna + Boris = <3» (работа 22): C18 оставлен на месте и скрыт, у C28 ещё и выключен вывод; остальные 28 слоёв измеряются как раньше (расхождение до 0.8 ΔE).
  Чтобы увидеть это на уже загруженной фотографии, нажмите «Проверить заново».

### 0.15.0: карта цветов — уверенность, источники и фильтр сомнительных цветов (REQ-049, DEC-091)

### 0.14.0: работа над ошибками — результат гравировки против того, что обещал файл (DEC-090, REQ-047)

- **Зачем:** чтобы то, что вы видите в работе, совпадало с тем, что выгравировано. После каждого файла LightBurn, сделанного из работы, вы снимаете результат и принимаете фото как обычно;
  вывод записывается в саму работу.
- **Что запоминает работа:** при каждой выгрузке файла по каждому слою — настройки, цвет, который показывал предпросмотр, его основа, площадь и области. Раньше хранилось только число слоёв.
- **Сравнение:** слои гравированного файла и файла работы сопоставляются **по настройкам** (допуск на округление LightBurn), а не по номеру: гравировали не обязательно тот файл, который выгрузила
  работа (у проверки 77 «Inna + Boris 2» ни один из 16 слоёв не совпал с файлом «Inna + Boris», и экран так и пишет). По каждому слою: обещанный и измеренный цвет, ΔE, сдвиг светлоты,
  насыщенности и оттенка; слой «заметно отличается» от 5 ΔE (или от ошибки карты на этом фото, если она больше). Причины — только то, что видно по самим измерениям: блик выше белого
  квадрата, другая основа измерения, фото без карты, плохая карта, общий сдвиг почти всех слоёв (это про экспозицию или партию титана, а не про рецепты). Нет причины — не выдумывается.
- **Где смотреть:** вкладка «Результат» в работе (две картинки одной работы: «как обещал файл» и «как получилось»; слои строками, подробности по нажатию), строка в карточке работы в списке,
  блок «Вывод по работе» в отчёте по фото. При приёмке фото сообщение называет работу, в которую записан вывод.
- **Остальные работы:** после приёмки, перемера или удаления фото пересчитываются все работы этого лазера и линзы: сколько слоёв ушло от обещанного последним файлом больше чем на 5 ΔE.
  В списке — «⚠ Цвет N слоёв ушёл от обещанного», во вкладке «Результат» — слои «было → стало» и для каждого исходного цвета самая близкая измеренная замена с кнопкой «Заменить»
  и «Применить все замены». Замена — обычная правка работы с отменой; выгравированный файл и ваши ручные выборы система сама не трогает. Слой, рецепт которого работа больше не использует,
  не считается; работа, из которой файл не делали, ничего не обещала и не помечается.
- **Работы, выгруженные до 0.14.0:** обещание восстанавливается по слоям работы, пока раскраска не менялась после выгрузки, и помечено «приблизительно».
- **Допущения (не измерения):** порог 5 ΔE, выигрыш замены от 1 ΔE, «плохая карта» от 7 ΔE, общий сдвиг от 3 L* на 75 % слоёв. Слой измеряется целиком; цвет отдельных областей и
  изменение параметров лазера (мощность, скорость) здесь не предлагаются: заменяется цвет другим измеренным, а не настройки.

### 0.12.0: уверенность в цвете настроек (REQ-045, DEC-083)

У каждых настроек (тот же лазер, линза, титан и рецепт) теперь есть **уверенность в цвете**, и программа предпочитает более уверенные цвета.

- **Повторилось и совпало — уверенность растёт.** Гравировки с отличием цвета не больше ΔE 5 считаются совпавшими. Две совпавшие дают 0,50, три 0,60, четыре 0,67 и так далее. Одна гравировка не повторялась: уверенность «не оценена», а в выборе она стоит между цветом, который менялся, и цветом, который повторялся.
- **Менялось — уверенность падает.** Каждая гравировка, не совпавшая с остальными, снижает уверенность. Если совпала не больше половины гравировок (например, одна гравировка жёлтая, другая тёмно-коричневая), настройки помечены «цвет менялся при тех же настройках»: автоматические режимы их не берут, пока повторная гравировка не прояснит цвет, а вручную выбрать можно.
- **Старый цвет заменяется новым.** Цветом настроек считается тот, на котором совпало больше всего гравировок; при равенстве побеждает группа с самой новой гравировкой. Была жёлтая, переделали тёмно-коричневой — цвет теперь тёмно-коричневый (уверенность низкая); ещё одна коричневая — цвет подтверждён. Одна выбивающаяся гравировка среди совпавших цвет не двигает: раньше цвет был средним арифметическим всех, то есть оттенком, которого никто не снимал.
- **Лучшее измерение заменяет худшее.** Если те же настройки измерены и по эталонной карте, и по чистому титану снимка, и «как снято», в палитре работы остаётся (для автоматики) измерение по эталонной карте; остальные помечены «заменён», но остаются в списке, и сохранённые работы продолжают на них ссылаться.
- **Внутри допуска ΔE более уверенный цвет берётся раньше более быстрого** (прежде внутри допуска побеждал самый быстрый).
- **Где это видно.** Палитра работы (колонка «Уверенность»: число, «2 из 3 совпали», пометки «цвет менялся» и «заменён»; в окне выбора цвета то же), поиск на «Карте цветов» (расстояние считается до согласованного цвета настроек, а не до ближайшего единичного измерения), страница знания («Совпали по цвету»). **На карте цветов диаметр кружка зависит от уверенности**: одиночная гравировка — средний кружок, повторы с тем же цветом крупнее, цвет, который менялся, мельче; подсказка кружка называет уверенность.
- Измерения не меняются (REQ-001): уверенность и согласованный цвет считаются при каждом чтении.
- На ваших данных (копия базы): из 539 рецептов на карте 23 повторялись, у 11 из них гравировки расходятся на ΔE от 7 до 23; в палитре работы «Inna + Boris» из 505 цветов 3 помечены «цвет менялся» и 16 «заменён»; ΔE 5 — предположение модели (в данных повторы согласуются на 0,8–4,1, расхождения лежат от 7), его можно поменять в одном месте (`agreement.AGREEMENT_DE`).

Для автоматического совмещения фото можно добавить QR и четыре метки — тогда та же плата занимает 19 × 19 мм. Начальный предел всей платы — 25 × 25 мм, его можно изменить до создания. «Показать размер» сообщает фактический габарит и площадь очистки. Если квадраты не помещаются в заданный прямоугольник, приложение создаёт отдельные LightBurn-файлы, каждый с первым слоем локальной очистки; ссылки на все части появляются сразу после создания. Предел 100 × 100 мм остаётся только верхней границей.

На экране **AI-исследователь** выберите лазер с линзой, заготовку и измеримую цель. AI (`gpt-6.1-sol`) читает паспорт и накопленные результаты, предлагает следующий тест, по прямой просьбе создаёт один проверенный `.lbrn2` и даёт ссылку на скачивание. После гравировки загрузите фактически использованный файл и RAW-фото, проверьте наложение и примите измерения. Только после этого выводы о режимах получают ссылку на фото-доказательство. Проверка глубины, 3D-рельефа и сквозного реза требует дополнительных физических измерений; фото сверху их не доказывает.

Для AI нужен `OPENAI_API_KEY` в окружении или в локальном `.env.local` в корне репозитория. `.env.local` исключён из Git. Паспорт, контекст исследования, история вопросов и результаты инструментов отправляются в OpenAI API при запросе AI; сами фотографии остаются локальными в текущем рабочем процессе. Исключение одно: раскраска векторной работы с помощью AI отправляет уменьшенную копию фотографии (до 512 px) только после вашего разрешения для этой работы; без него уходят одни числа (цвета, доли, соседство, измеренные цвета титана).

## MCP

Те же операции доступны локальному MCP-клиенту через stdio:

```bash
.venv/bin/titanium-research-mcp --data-dir ~/.titanium-platform
```

Сервер предоставляет инструменты чтения лазеров/материалов и результатов, создания исследовательской сессии, предпросмотра и экспорта теста, совмещения загруженного фото и сохранения гипотезы. Он не управляет лазером и использует ту же SQLite-базу, что и браузерное приложение. При настройке внешнего MCP-клиента укажите приведённую команду как исполняемый stdio-сервер.

## Проверка

```bash
.venv/bin/python -m pytest -q
```

Экспорт проверяется обратным чтением `.lbrn2` собственным парсером. Перед физической гравировкой проверьте файл в установленной версии LightBurn. В приложении AI-предложения и результаты без эталонной цветовой карты остаются предварительными; стандартные цветовые рекомендации требуют принятых и скорректированных измерений.

Технические решения и требования: [документация проекта](docs/features/titanium-color-engraving-intelligence-platform/overview.md).
